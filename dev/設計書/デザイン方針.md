# デザイン方針

dev-docs の画面全体に通すデザインの方向性。

## 採用スタイル

| 項目 | 内容 | 補足 |
| --- | --- | --- |
| スタイル | 開発者ツール | - |
| 分類 | 業務系 | - |
| 明暗 | 両方 | 既定はシステムの設定に従い、利用者が固定できる |
| 見本（画面全体） | [dev/mock/styles/developer-tool/](../mock/styles/developer-tool/) | - |
| 見本（部品） | - | Storybook は部品設計で作る |
| 値の置き場所 | `dev/mock/assets/style.css` | `frontend/` を作る実装で同じ値を移す |
| 近い shadcn/ui のスタイル | Nova | 操作の高さ `h-8`・影なし。Vega（`h-9`・`shadow-xs`）ではない |
| 選んだ理由 | 技術 / プログラミングのサイトで、自分の端末で設計書を配信して読み書きする開発者が主。GitHub など手元の開発ツールと並べて違和感なく読める | - |

## 雰囲気のことば

実用・簡潔・落ち着き

## モチーフ・装飾

| モチーフ・装飾 | 使う場所 | 補足 |
| --- | --- | --- |
| 見出しの前の `#` | 本文の見出し 2 | 等幅で、補足の文字の色 |

## 色の役割

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・本文 | `--background` / `--foreground` | 無彩色 |
| 面 | トップバー・コード・補足の文字 | `--topbar` / `--code` / `--muted` / `--muted-foreground` | - |
| 線 | 区切り・入力欄の枠 | `--border` / `--input` | - |
| 差し色 | 主ボタン・リンク・フォーカス・選択中 | `--primary` / `--link` / `--ring` | 青 1 色 |
| 状態色 | 削除・エラー | `--destructive` | - |
| 差分 | 差分の追加・変更 | `--added` / `--changed` | - |
| 強調 | 検索の一致 | `--highlight` | - |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し | 端末のサンセリフ | 太さ 600。`--text-title` / `--text-h2` |
| 本文・操作・表 | 端末のサンセリフ | `--text-body` / `--text-control` / `--text-table` |
| 入力欄 | 端末のサンセリフ | `--text-input`。スマホで入力時に拡大されない 16px |
| 補足（パンくず・文書の情報・目次） | 端末のサンセリフ | `--text-meta` |
| コード・パス・ID | 等幅 | `--font-mono` / `--text-code` |

## 形状と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| ボタン・入力欄 | 小さめの角丸と線 | `--radius` は 0.375rem。影なし |
| 表・カード | 線で区切る | 影なし |
| 見出し 2 | 下線で区切る | - |
| メニュー・ダイアログ | 影で浮かせる | `--shadow-popover` |
| バッジ | ピル形の角丸と線 | - |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| ボタン・メニューの項目のホバー | 背景色だけを変える | - |
| メニュー・ダイアログの開閉 | 動きを付けずに出す | - |

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| グラデーション・光る影 | 開発ツールと並べて読む落ち着きとぶつかる | - |
| 2 色目の差し色 | 色は差し色の青と状態色・差分の色だけに使う | - |
| Web フォント | 端末の書体で、読み込みを待たずに出す | - |
