# デザイン方針

dev-docs の画面全体に通すデザインの方向性。

## 採用スタイル

| 項目 | 内容 | 補足 |
| --- | --- | --- |
| スタイル | 開発者ツール | - |
| 分類 | 業務系 | - |
| 明暗 | 両方 | 既定は端末の設定に従い、トップバーの切り替えで片方に固定できる |
| 見本（画面全体） | [dev/mock/styles/developer-tool/](../mock/styles/developer-tool/index.html) | - |
| 見本（部品） | - | Storybook は部品設計で作る |
| 値の置き場所 | `dev/mock/assets/style.css` | `## デザイントークン` のセクション |
| 選んだ理由 | 技術（開発者向けのドキュメント閲覧とレビュー）のサイトで、利用者は設計書を読み、エージェントの変更を `?diff=` でレビューする開発者。GitHub の画面に近い密度と配色で、表・コード・差分の強調を読み慣れた見た目に揃える | [確認事項](https://github.com/shuhei1101/dev-docs/pull/12#discussion_r4379696802) |

## 雰囲気のことば

落ち着いた・読み慣れた・正確・道具らしい

## モチーフ・装飾

持たない。

## 色の役割

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・本文 | `--bg` / `--fg` | - |
| 地の区切り | トップバー・表の見出し・コードの地 | `--chrome-bg` / `--table-head-bg` / `--pre-bg` | - |
| 補助の文字 | 説明・件数・日時 | `--fg-muted` | - |
| 線 | 枠・区切り | `--border` / `--border-strong` | - |
| 差し色 | リンク・主ボタン・フォーカス | `--link` / `--accent` / `--focus` | 強い色は操作・選択・差分にだけ使う |
| 選択中 | 選んだタブ・メニューの行 | `--selected-bg` / `--hover-bg` | 無彩色の地で示す |
| 差分 | 追加・変更・削除の行 | `--added-bg` / `--changed-bg` / `--removed-bg` / `--removed-line` | 色に加えて行頭のラベルと削除の取り消し線で示す |
| 補足 | 補足のコールアウト | `--info-bg` / `--info-border` | - |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し | 端末標準のゴシック（太字） | 本文と同じ書体で太さだけを変える |
| 本文 | 端末標準のゴシック | - |
| 識別子 | 等幅 | コード・リビジョン・パス・キー |

## 形状と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| ボタン・入力欄 | 小さめの角丸と線 | - |
| メニュー・検索のポップオーバー | 角丸と線と影 | 影を持つのは浮かせる要素だけ |
| 表 | 線で区切る | - |
| サイドバー・目次 | 線で区切る | - |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| メニュー・検索の開閉 | 動かさずに出す | - |
| 明暗の切り替え | 動かさずに切り替える | - |

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| グラデーション・背景画像 | 表とコードを読む画面の密度とぶつかる | - |
| 操作・選択・差分以外の強い色 | 差し色の意味が薄れる | - |
| 明朝・装飾の書体 | 道具の画面として読み慣れた見た目から外れる | - |
