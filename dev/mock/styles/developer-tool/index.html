ファイル管理する値

キー一覧

6 件

表示する列

キー論理名型既定値説明
version設定のバージョン整数—サーバーが読めるバージョンと比べる
sources[].id配信元の ID文字列—画面の URL と source 引数に使う
sources[].config配信元の設定ファイルパスの配列—上から順にマージするし、同じキーは後のファイルで上書きする
sources[].enabled配信するか真偽値truefalse の配信元は起動時に読まない
sources[].scope.read読み取りの範囲glob の配列—当たるパスなら文書の MCP で読める
sources[].scope.write書き込みの範囲glob の配列[]当たるパスなら文書の MCP で書き込める。worktrees に当たるパスなら読み書きをそのワークツリーへ向ける

sources:

    config: [./dev-docs.yaml, ./dev-docs.local.yaml]
    scope:
