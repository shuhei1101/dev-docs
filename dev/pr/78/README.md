# shared/version.py・shared/schema_check.py のモジュール構成の設計書を作る

## 概要

開発ドキュメントサーバーの `src/dev_docs/shared/version.py`・`src/dev_docs/shared/schema_check.py` のモジュール構成の設計書を作り、この 2 ファイルの要素を使う設計書からつなぐ。

## 背景

[#71](https://github.com/shuhei1101/dev-docs/issues/71) の要望。
テンプレート『モジュール構成』は 1 設計書 = 1 物理ファイルを求めるが、この 2 ファイルに当たる設計書が無い。
[#70](https://github.com/shuhei1101/dev-docs/pull/70)（[#57](https://github.com/shuhei1101/dev-docs/issues/57)）のレビューで対象外の逸脱として報告され、#70 のスコープ外として切り出された。
