## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ER 図の出し方（#59） | `render_diagram` の `er` の分岐を、mdmark の ER 図の部品（`<!-- er -->` の JSON）を返す関数に替える | テーブルの `x`・`y`・`w` は変換が格子に配置する |
| ER 図の列（#59） | 実体が `columns` を持たないときは、同じ文書の `tables[]` のうち `title` が実体の `name` に当たるテーブルの `columns` から列（名前・型・`PK`・`FK`・`NN`）を作る | 当たるテーブルが無い実体（他の分類のテーブル）は列なしで出す |
| ER 図の関連（#59） | Mermaid の多重度の書き方（`||--o{` など）を、両端の `fromCard`・`toCard`（`1`・`0..1`・`1..n`・`0..n`）に読み替える | 読み替えられない多重度の扱いは設計で決める |
| ER 図の関連の端の列（#59） | 片方の実体の列のうち、外部キー（テーブルの列の `foreign_key.table`、実体の列の `key: FK` と `comment` の `参照: {実体}.{列}`）がもう片方の実体の列を指す列と、指される列を `fromColumn`・`toColumn` にする | 端の列が決まらない関連は図から除外し、図の元データの表にだけ残す |
| 往復編集の読み込み（#91） | `load_roundtrip` の `YAML()` に `preserve_quotes = True` を設定する | 引用符つきで読んだ値は元の引用符で書き出され、`_represent_str` は引用符なしの文字列だけに当たる |
| 本文の `id:` のリンク（#97） | `rewrite_text` で、コードの外の `[名前](id:{文書の ID})` を `link_reference` と同じリンク先に書き換える | 当たらない ID のリンクはそのまま出す |
| 項目のアンカー（#97） | `#{項目のパス}` を、リンク先の文書の項目の見出しのアンカーへ対応づけて付ける | 見出しにならない項目はアンカーなし。型 `ref` の値のリンクにも同じアンカーを付ける。対応づけの持ち方はモジュール構成で決める |
| 既存機能への影響 | 文書の取得・試しの変換・文書の書き込みの API の形は変えない。変わるのは `markdown` の中身と、書き込んだファイルの引用符だけ | - |
