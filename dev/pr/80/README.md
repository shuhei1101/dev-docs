# 画面の物理ファイルのうち設計書の無いもののモジュール構成の設計書を作る

## 概要

画面（`frontend/src/`）の物理ファイルのうち設計書の無い 9 ファイルと `testing/setup-tests.ts` のモジュール構成の設計書を作り、設計書の対象から外すファイルを分類の設計書に明記する。

## 背景

[#79](https://github.com/shuhei1101/dev-docs/issues/79) の要望。
テンプレート『モジュール構成』は 1 設計書 = 1 物理ファイルを求めるが、画面の 9 ファイルに当たる設計書が無い。
[#78](https://github.com/shuhei1101/dev-docs/pull/78)（[#71](https://github.com/shuhei1101/dev-docs/issues/71)）の受付で、同じ型の逸脱をリポジトリ全体から探して見つかった。
