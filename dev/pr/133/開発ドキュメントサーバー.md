## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MCP の応答の文言 | `要件.md` の単語ごとの置き換えで、エラー・注記・Markdown の応答の見出し・列名・マーカーを置き換える | 置き換え以外の言い回しと、`path`・`rule` の識別子（`ids.format` など）は変えない |
| 配信元の検査の分類名 | `describe` の警告・`check_project` の応答・起動時のログで同じ分類名にする | `main.py` のログはこの分類名だけを変える |
| 設計書 | インターフェース定義・モジュール構成・シナリオのうち、修正する文言と同じ文を持つ項目を同じ置き換えにする | 地の文は #95 の範囲 |
| テスト | 修正する文言を照合する単体・結合・E2E テストの期待値を修正後の文言にする | 照合が無い文言は、モジュール構成設計で照合の要否を決める |
| 入出力 | MCP のツールの名前・引数・応答のキーは変えない | - |
