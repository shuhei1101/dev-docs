# 要件

## 要望

次の範囲の文言を、knowledge の AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`）に合わせて修正する。

| 範囲 | 対象 |
| --- | --- |
| MCP の応答の文言 | `src/dev_docs/` が MCP のツールの応答として返却する、エラーの `rule`・`fix`・`message`・`next_steps`、注記の `notes`、Markdown の応答の見出し・列名・取得済みの文書のマーカー |
| 配信元の検査の分類名 | `describe` の警告・`check_project` の応答と同じ分類名を持つ、起動時のログの分類名（`main.py`） |
| 文言を共有する設計書 | 修正する文言と同じ文を持つインターフェース定義・モジュール構成・単一ユースケースのシナリオの項目 |
| 文言を照合するテスト | 修正する文言を照合する単体・結合・E2E テスト |

終わりの条件は、上の範囲で対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が 0 件になること。
置き換え先は対応表の `ok` の単語にし、PR #116 で決めた置き換え（`読み込める`・`再読み込み`・`除外した理由`・`確認できません`・`記載できません`）と統一する。

単語ごとの置き換えは次のとおり。
箇所ごとの修正前後は、モジュール構成設計で確定する。

<!-- table: data -->

| 単語 | 置き換え | 例 |
| --- | --- | --- |
| 読む（値・設定・文書を解釈する） | 読み込む | `正規表現として読めません` → `正規表現として読み込めません` |
| 読む（エージェントが文書を取得した） | 参照する | `この会話で読んだ記録がありません` → `この会話で参照した記録がありません` |
| 読み直す・取り直す（文書を取得し直す） | 再取得する | `view: ids で取り直してください` → `view: ids で再取得してください` |
| 直す（違反を直す） | 修正する | `違反を直してから` → `違反を修正してから` |
| 直す（呼び直す・つなぎ直す） | 再実行する・再接続する | `/mcp でつなぎ直して` → `/mcp で再接続して` |
| 見る | 確認する | `使える配信元を見てください` → `使用できる配信元を確認してください` |
| 使う | 使用する | `使い方` → `使用方法` |
| 渡す | 指定する | `from を渡してください` → `from を指定してください` |
| 返す | 返却する | `（この会話で返し済み）` → `（この会話で返却済み）` |
| 確かめる | 確認する | `check_project で確かめられます` → `check_project で確認できます` |
| 当たる | 該当する | `どの文書にも当たらない関連` → `どの文書にも該当しない関連` |
| 当てる | 適用する | `操作を当てられません` → `操作を適用できません` |
| 外す | 除外する・削除する（設定から値を取り除く） | `exclude から外してください` → `exclude から削除してください` |
| 消す | 削除する | `参照も外して消せます` → `参照も除外して削除できます` |
| 書く | 記載する（ファイルへ書き込んだ結果は `書き込む`） | `nav を書きました` → `nav を書き込みました` |
| 置く | 配置する | `置き場所` → `配置先` |
| 語 | 単語 | `語の増減` → `単語の増減` |
| 形 | 形式 | `{fmt} の形にしてください` → `{fmt} の形式にしてください` |

<!-- /table -->

`形` の置き換え先は対応表の `ok`（スキーマ・構造）ではなく `形式` にする。
`ids.format` の値の書式を指す文で、スキーマ・構造では意味が通らないため。
