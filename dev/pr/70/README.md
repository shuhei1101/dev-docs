# モジュール構成の設計書を物理ファイルごとに分け、コードのパスへ置き直す

## 概要

`dev/設計書/モジュール構成/開発ドキュメントサーバー/` の設計書を 1 設計書 = 1 物理ファイルに分け、コードのパス（`{container}.yaml`）へ置き直す。

## 背景

[#57](https://github.com/shuhei1101/dev-docs/issues/57) の要望。
テンプレート『モジュール構成』は 1 設計書 = 1 物理ファイルを求め、書くツール（`write_design_doc_module`）は「物理ファイルが 2 つ以上あります」で書き込みを拒む。
[#54](https://github.com/shuhei1101/dev-docs/pull/54) では、この違反のため `文書のストア.py.yaml` を YAML の直接編集で修正した。
