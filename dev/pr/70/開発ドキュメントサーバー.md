## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き場所 | `dev/設計書/モジュール構成/開発ドキュメントサーバー/{container}.yaml` | `features/admin/` などと同じ |
| `title` | `開発ドキュメントサーバー / {分類名} / {物理ファイルの名前}` | 分類名は元の設計書の分類名（例 `文書のストア`） |
| 要素 | `data_models`・`classes`・`enums`・`constants`・`functions` などを `container` ごとに分けて移す。中身は変えない | |
| `directory`・`diagrams`・`lead` | 物理ファイルごとに作り直す。`diagrams` は分けた設計書の要素だけで描き、他の物理ファイルの要素はその設計書を指す | |
| `test_files` | 物理ファイルに当たる単体テストのファイル 1 つ。無ければ持たない | |
| `refs`・`notes` | 当たる要素を持つ設計書へ移す。複数に当たるものは、それぞれへ置く | |
| `__init__.py` | 再エクスポートだけのものは設計書を作らない | 要素を持たない。`src/dev_docs/__init__.py` は `DIST_NAME` を持つので `__init__.py.yaml` を作る |
