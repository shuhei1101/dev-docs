# documents[] の行に、paths[] に当たったファイルを名前で除外する指定を持たせる

## 概要

利用者は `dev-docs.yaml` の `documents[]` の行で、`paths[]` に当たったファイルのうち特定の名前のファイル（目次の `README.md`・`index.yaml` など）を文書から外せるようになる。

## 背景

[Issue #26](https://github.com/shuhei1101/dev-docs/issues/26) の要望。
今の `documents[]` の行は `paths[]` の glob に当たったファイルを全て文書にし、同じフォルダの中で特定のファイルだけを外す指定が無い。
shuhei1101/alias-inject#35 では先頭の文字の否定（`[!R]*.md`・`[!i]*.yaml`）で外しており、`R`・`i` で始まる文書や後から追加したページが検査で検出されずに配信から漏れる。
`paths[]` で行を判定する箇所は、読み込み・変更の一覧・画面の文書のページ・書き込みの置き場所に分かれている（[扱いの判断](https://github.com/shuhei1101/dev-docs/issues/26#issuecomment-6477409241)）。
