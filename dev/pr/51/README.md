# mdmark を jsDelivr から master で読み、リリースに自動で追従する

## 概要

画面が jsDelivr の master ブランチから mdmark を読み、mdmark のリリースに設定の変更なしで追従できるようになる。

## 背景

[Issue #15](https://github.com/shuhei1101/dev-docs/issues/15) の要望（TH-754）。
画面は mdmark の `v0.8.0` のタグを固定して jsDelivr から読んでいる（[PR #12 の確認ログ](https://github.com/shuhei1101/dev-docs/blob/develop/dev/pr/12/%E7%A2%BA%E8%AA%8D%E3%83%AD%E3%82%B0.md) の「mdmark の読み込み元」、[PR #36](https://github.com/shuhei1101/dev-docs/pull/36) で実装）。
mdmark のリリースのたびに読み込み先のタグを書き換える手間をなくすため、リリースのたびに `dist/` が入る master を読む。
