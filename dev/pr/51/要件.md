# 要件

## 要望

画面が読む mdmark を、jsDelivr の master ブランチ（`https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@master/dist/index.js`・`dist/index.css`）に切り替える。

- 読み込み先の URL にバージョンのタグを持たず、mdmark のリリースが master へ入ると、設定を変えずに画面がそのリリースを読む
- ブランチを読むと中身が変わるため、integrity（SRI）を付けない（今の実装も付けていない）
- 外部ライブラリ『mdmark』の設計書と非機能要件に、master を読むこと・jsDelivr のキャッシュ（CDN 12 時間・ブラウザ 7 日。`cache-control: public, max-age=604800, s-maxage=43200`）・すぐ届けたいときの purge.jsdelivr.net での削除を記載する
- 単体テストが差し替える mdmark の URL を新しい URL に揃え、画面の成果物（`src/dev_docs/screen/`）をビルドし直す
