## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| プロンプトの YAML の置き場所 | リポジトリ直下の `content/prompts/` に置く。サーバーは起動のときに `DEV_DOCS_PROMPTS_DIR`（無ければクローンの直下の `content/prompts/`）から読む | 環境変数は、結合テストが違反する YAML の一時フォルダへ向けるのに使う |
| SessionStart の注入文 | `content/prompts/session-context.yaml`（`kind: hook`）に、配信元の行・配信元が無いとき・警告の部品と、使い分けは文書の MCP の instructions にある旨の 1 行を置く。サーバーは配信元と警告を変数に渡して描画する | 配信元が無いときの文は今の `SETUP_GUIDE` の文を移す |
| 注入文の字数 | `CONTEXT_MAX_CHARS` を 1,000 にする。超えたときは、配信元の説明を省いた値で描画し直し、それでも超えるときは配信元を末尾から減らして残りの件数を変数で渡す | 省き方は今の `_context_text` のまま |
| 文書の MCP の instructions | `content/prompts/mcp/docs/instructions.yaml`（`kind: instructions`）に、扱う作業・使う場面と grep・Read が向く場面の表・ツール間の順序・タグの付け方を置く | 場面の表は Issue #48 の A-41 の候補を元にする |
| ツールの description | ツールごとに `content/prompts/mcp/docs/tools/{ツール名}.yaml`（`kind: tool`。ツール名の `_` を `-` にした名前）を置き、何をする・いつ使う・いつ使わない・何を返さない・今の引数の説明を書く | - |
| 管理の MCP | 管理の MCP のツールの description も `content/prompts/mcp/admin/tools/{ツール名}.yaml` へ移す（文は今のまま） | - |
| 実行時の描画 | プロンプトの YAML を読み、`lang` の本文の部品のうち `when` が真のものを Jinja2 で描画してつなぐ `PromptSet.render` を `prompt_doc/runtime.py` に置く（画面用のマーカーは付けない） | Environment は画面の変換と同じ（`StrictUndefined`・`trim_blocks`・`lstrip_blocks`）にし、画面の字数と注入する文の字数を揃える |
| 読み込みと検査 | サーバーの起動時に `content/prompts/` の YAML を読み、`templates/prompt.schema.yaml` に通し、`id` とパスの一致と `example` での描画を確かめる。サーバーが使う ID の YAML が無いときも含め、違反があれば終了コード 4 で起動を止め、ファイルとキーのパスと理由を標準エラーに出す | フォールバックの文は持たない |
| 言い回しの検査 | 単体テストで、`content/prompts/` の本文に MUST・必ず・禁止の語が無いことを確かめる | |
| converters[] の cache | `converters[]` の行に任意のキー `cache`（既定 `true`）を設ける。`cache: false` の行は `_run_converter` で控えを読まず、書かずにスクリプトを動かす | `validators[]`・`generators[]` には設けない |
| 設定のスキーマ | 2 つのスキーマで `converters[]` の行を `$defs/scripts` から分け、`cache` を持つ行の定義にする | 設定のバージョン（`SOURCE_CONFIG_VERSION`）は、任意のキーの追加なので上げない |
| 変換の時間 | `cache: false` の変換も `script_timeout_sec` の中で終わる | 既存の制限時間のまま |
| 既存機能への影響 | ツールの名前・引数・返り値は変えない。SessionStart の応答の `sources`・`warnings`・`forgotten` は変えない。`cache` を書かない配信元の変換の控えの挙動は変えない | - |
