# 要件

## 要望

`tests/unit/dev_docs/features/search/test_service.py` の `test_search_when_records_fields` を、共通のキー（`METADATA_KEYS`）でない要素の項目で絞る条件にする。

- 要素のスキーマ（`templates/files.schema.yaml` のコピーの `files.items.properties`）に共通のキーでない項目（`owner: {type: string}`）を追加し、要素ごとに値を持たせる
- 条件をその項目で絞る形にし、期待値は当たる要素 1 件だけにする
- スキーマは、nav・admin の同じ型のテストが使う `tests/unit/dev_docs/conftest.py` の `records_files_schema` で作る
- 直したテストが、今の実装で通り、ファイル全体のスキーマ（`files.items` でなく全体）から項目を作る実装で失敗することを確かめる
- モジュール構成 `features/search/service.py` の単体テストの行 `test_search_when_records_fields` の条件・期待値を合わせる
