# test_search_when_records_fields を共通のキーでない要素の項目で絞るテストにする

## 概要

`test_search_when_records_fields` を、共通のキーでない要素の項目で絞る条件にし、ファイル全体のスキーマから項目を作る実装で失敗するテストにする。

## 背景

[#61](https://github.com/shuhei1101/dev-docs/issues/61) の要望。
[#54](https://github.com/shuhei1101/dev-docs/pull/54) で追加したこのテストは条件の項目に共通のキー `path` を使っていて、`known_fields` がスキーマに依らず返すため、ファイル全体のスキーマから項目を作る実装でも通る。
[#50](https://github.com/shuhei1101/dev-docs/pull/50) のレビューで reviewer が対象外の逸脱として報告した（[報告](https://github.com/shuhei1101/dev-docs/pull/50#discussion_r4431193004)）。
