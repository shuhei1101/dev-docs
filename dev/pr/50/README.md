# エイリアスの取り込み・nav のタグの式・作業範囲の外の参照・ガイドのタグの行・default_ref からの読み込み・metadata のタグの取り出しを入れる

## 概要

エージェントは、エイリアスの語で用語を引け、作業範囲の外の配信元を参考に読め、`describe` でブランチとワークツリーを引け、オブジェクトの配列のタグ（`tags[].name`・`main`）で文書を絞れる。
利用者は、タグの式で絞った文書の一覧を画面のナビゲーションから開け、本文の用語にツールチップが出る。
端末の設定はメインのリポジトリを指したまま、`default_ref` の設定・スキーマ・スクリプトで配信される。

## 背景

[Issue #49](https://github.com/shuhei1101/dev-docs/issues/49) は、計画の行 [#11](https://github.com/shuhei1101/dev-docs/issues/11)・[#16](https://github.com/shuhei1101/dev-docs/issues/16)・[#40](https://github.com/shuhei1101/dev-docs/issues/40)・[#41](https://github.com/shuhei1101/dev-docs/issues/41)・[#42](https://github.com/shuhei1101/dev-docs/issues/42)・[#43](https://github.com/shuhei1101/dev-docs/issues/43) を 1 つの作業として進める束。

- #11: エイリアスの共通のスキーマを alias-inject が正本として持つと決め（D-120・D-165）、dev-docs はそれを取り込んで検証・検索・画面に使う
- #16: タグで毎回絞り込む手間を省くため、絞り込みを `nav` に保存して押すだけで開けるようにしたい（TH-757）
- #40: `scope` の外の配信元は一時的な参照もできず、`scope.read` を広げると作業範囲と誤解させる（D-178）
- #41: タグの付け方を knowledge の規約に集めたが、dev-docs は knowledge の無い環境にも配るため、最初に出すガイドに要点を自前で持つ（D-182）
- #42: 端末の設定がメインのリポジトリを指すと設定・スキーマが master から読まれ、develop のワークツリーを指すと `worktrees[]` がほかのワークツリーに当たらない
- #43: knowledge の規約はタグを `{name, main}` のオブジェクトの配列で持ち、今の `metadata` の対応ではタグで引けない（claude-balancer#205）
