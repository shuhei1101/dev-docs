# id を持たない文書の ID を拡張子付きのパスにし、どの文書にも当たらない related[].to を check_project で知らせる

## 概要

メタデータに `id` を持たない文書の ID を拡張子付きのパスにし、同じ名前で拡張子の違うファイルがそれぞれ文書になるようにする。
`related[].to` が配信元のどの文書の ID にも当たらない行を `check_project` で知らせる。

## 背景

[#72](https://github.com/shuhei1101/dev-docs/issues/72) の要望。
`loader.py` は `id` を持たない文書の ID を、拡張子を除いたパス（`_stem`）で作るため、同じフォルダに同じ名前で拡張子の違うファイルがあると ID が重なり、片方が文書にならない。
[shuhei1101/ai-monitor#3117](https://github.com/shuhei1101/ai-monitor/pull/3117) で `files.yml` に `src/` のコードと `docs/` の Markdown を載せたときに見つかった。
正式な利用の前のため、ID の決まりを 1 つにする方向（拡張子付きのパス）で直す（[ユーザーの回答](https://github.com/shuhei1101/dev-docs/issues/72#issuecomment-6550120442)）。
