## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の強調 | URL に `base` があるときは、`baseMarkdownQueryOptions` で取った比較元の本文を `mount` の `baseMarkdown` に渡す。同じ文書で比較元が変わったら `update(markdown, {baseMarkdown})`、`base` を外したら `null` を渡す | 比較元の本文にも先頭の見出し 1 の除去と隠す列の書き込みを当て、本文と同じ変換で比べる |
| 列の出し入れ | `mount` の `onColumnsChange` が渡す `tableIndex` を、`+columns` の表のキーだけを出る順に並べた中の番号として引き、`hidden` を `view-put_columns` で保存する。保存の失敗の通知と表を切り替えたままにする振る舞いは変えない | `.mdmark-columns-menu` の DOM を参照する処理は削除する |
| コメントの修正・削除 | `commentStore` に `update({docId, id, body})`・`remove({docId, id})` を渡し、コメントの置き場所の `update`・`remove` を呼ぶ。パネルで修正・削除したら、本文の `reloadComments()` を呼んで本文のマーカーを描き直す | |
| コメントの場所への移動 | パネルで場所を選んだコメントは、そのコメントの文書を描き終えた後に `focusComment(id)` を呼ぶ | `findCommentMark` と `MutationObserver` の探索は削除する |
| 読み込み元 | jsDelivr の `mdmark@master` のまま変えない | mdmark#222 を含むリリースが master に入るまで、結合テストと E2E を確定できない |
| 既存機能への影響 | 目次の変更のマーカー（`changedSections`）は変えない | 本文の強調で代えるかは [#88](https://github.com/shuhei1101/dev-docs/issues/88) |
