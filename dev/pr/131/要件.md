# 要件

## 要望

配信元の設定の先頭のファイルの置き方ごとに、次のとおり配信する。

| 先頭のファイルの置き方 | 設定の参照先 | 文書・種類のスキーマ・スクリプトの参照先 | 配信元のフォルダ |
| --- | --- | --- | --- |
| Git の外のフォルダ | ディスク | ディスク | 先頭のファイルのフォルダ |
| Git の中で、`default_ref` に先頭のファイルがある | `default_ref` のリビジョン（今と同じ） | `default_ref` のリビジョン（今と同じ） | 先頭のファイルのフォルダ |
| Git の中で、先頭のファイルを `.gitignore` している（`dev-docs.local.yaml` など） | ディスク | `default_ref` のリビジョン | 先頭のファイルのフォルダ |
| Git の中で、先頭のファイルが `default_ref` に無く `.gitignore` もしていない | 今と同じく「`{default_ref}` に `{パス}` がありません」で配信しない | - | - |

端末の設定と状態の置き場の既定を、次のとおりにする。

| 項目 | 既定 | 上書き |
| --- | --- | --- |
| 端末の設定 | `${XDG_CONFIG_HOME:-~/.config}/dev-docs/settings.yaml` | 環境変数 `DEV_DOCS_CONFIG`（今と同じ） |
| 状態の置き場 | `${XDG_STATE_HOME:-~/.local/state}/dev-docs` | 環境変数 `DEV_DOCS_STATE_DIR`、端末の設定の `state_dir` |
| ログの置き場 | `{状態の置き場}/logs` | 端末の設定の `log_dir`（今と同じ） |

サーバー（`features/settings/query.py`）・管理用プラグインのフック（`hooks/session_start.py`）・global-setup スキルが、同じ規則で端末の設定のパスを決める。
`XDG_CONFIG_HOME`・`XDG_STATE_HOME`・`DEV_DOCS_STATE_DIR` を設定していない端末では、今と同じパスになる。

`決定`: 状態の置き場の `DEV_DOCS_STATE_DIR` と端末の設定の `state_dir` の優先順位（決めた段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `DEV_DOCS_STATE_DIR` → `state_dir` → 既定の順 | 判定フローチャート『設定値の置き場所』の「その実行だけ変える値を環境変数で上書きする」と合う。テストや 2 つ目のサーバーで端末の設定を変えずに置き場を分けられる | - |
| B | `state_dir` → `DEV_DOCS_STATE_DIR` → 既定の順 | 端末の設定に記載した値が常に有効になる | 環境変数で一時的に置き場を変えられない |

推奨: A

`DEV_DOCS_CONFIG`・`DEV_DOCS_PORT` も環境変数が端末の設定より優先され、同じ並びになる。
