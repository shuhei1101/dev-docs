## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 端末の設定のパス | 環境変数 `DEV_DOCS_CONFIG`、無ければ `${XDG_CONFIG_HOME:-~/.config}/dev-docs/settings.yaml`。`XDG_CONFIG_HOME`・`XDG_STATE_HOME` が空の文字列か相対パスなら未設定として扱う（XDG Base Directory Specification） | - |
| 状態の置き場 | 環境変数 `DEV_DOCS_STATE_DIR` → 端末の設定の `state_dir` → `${XDG_STATE_HOME:-~/.local/state}/dev-docs` の順 | - |
| ログの置き場 | 端末の設定の `log_dir`、無ければ決まった状態の置き場の `logs` | 今と同じ |
| 先頭の配信元の設定 | Git の中で `default_ref` に先頭のファイルが無いとき、`git check-ignore` で無視していればディスクの設定を参照し、文書・種類のスキーマ・スクリプトは `default_ref` を参照する。無視していなければ今と同じエラー | 設定を `default_ref` から参照しないため、`default_ref` は先頭のディスクの設定の値をそのまま使用する |
| Git の外の先頭の設定 | 今と同じくディスクを参照し、先頭のファイルのフォルダを配信元のフォルダにする | 単体テストで確認する |
| 既存機能への影響 | XDG の環境変数・`DEV_DOCS_STATE_DIR` が無い端末と、`default_ref` に先頭の設定がある配信元は今と同じ動き | - |
