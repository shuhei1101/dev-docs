# 汎用の描画を表し方の規約に沿って修正する（図を mdmark の部品で描く・キーの羅列を表にする・コードブロックのずれ）

## 概要

利用者が、変換器を持たない YAML の文書を、図・表を優先した表し方（knowledge の規約『表し方の優先順位』）で画面で読めるようになる。

## 背景

[Issue #55](https://github.com/shuhei1101/dev-docs/issues/55) の要望。
aituber の全 364 ページを描いて数えたところ、汎用の描画（`features/convert/markdown.py`・`diagrams.py`）が原因で、コードブロックのずれ（42 ページ）・図が出ない（73 ページ・262 個）・見出しとリードの重複・キーと値の羅列・図の下の元データの表・外部キーの `2 件`・内部向けの値の表示が起きている。
図は Mermaid のコードブロックで出しているが、画面が使う mdmark は Mermaid を描かない。
ER 図は [#59](https://github.com/shuhei1101/dev-docs/issues/59)、サイドバーは [#58](https://github.com/shuhei1101/dev-docs/issues/58) へ分けた。
