## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 複数行の値 | 値が改行を含むか `` ``` `` で始まるとき、`**{title}**` を 1 行にし、値を次のブロックに置く | - |
| 図の出し方 | `render_diagram` を図の種類ごとの関数に分け、flow 系と `state` は mdmark のフロー図の部品の JSON、`er` は今の Mermaid を返す | 箱は段に分けて格子に置く（`flow_layout.py`） |
| 手で書く Mermaid | `sequenceDiagram`・`flowchart` の文字列を mdmark のシーケンス図・フロー図の部品にする | 読み取るのは箱の宣言・線・相手の宣言・メッセージだけで、それ以外の行を含む図は Mermaid のまま（`mermaid.py`） |
| 図の元データの表 | `<!-- table: data closed -->` で出し、ID・形の列を持つ表だけ、ID の列を先頭から移して `+columns hide=` にその表にある ID・形の列名を記載する | 先頭は `label`・`name` の列、隠すのは `id`・`shape` の列の `title`（`markdown.py`） |
| 見出し・リードのキー | 見出し・リードに使った値のキーを本文の組み立てから除外する | 見出しは `title`・`name`、リードは `lead`・`description` の最初に値を持つキー |
| スカラーの並び | 子にスカラーが並ぶオブジェクトと `attributes` を「項目 / 値」の表にし、100 文字を超える値は折りたたみに入れる | - |
| `x-hidden` | スキーマに `x-hidden: true` を持つキーを組み立てない | - |
| セル | オブジェクトの配列のセルは中身を出す。真偽の値は ✓ と空欄 | `table`・`column` を持つオブジェクトを `[{table}.{column}](#{table})` にする |
| リンク | `関連` の参照・Issue 番号をリンクにする | 変換が配信元の文書の ID・パスからタイトルを引く（`service.py`・`inline.py`） |
| D-209 の残り | 値の選択肢のバッジ・ファイルツリー・対応テストの折りたたみ・シナリオの主な流れのステップ・リクエスト例とレスポンス例のタブを出す | 値の形（選択肢・罫線・番号付きの箇条書き）と、キーの名前（`test_file`・`*_example`）で判別する |
| 既存機能への影響 | 文書の取得・試しの変換の API の形は変えない。変わるのは `markdown` の中身だけ | - |
