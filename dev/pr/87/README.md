# SessionStart の文に、設計書から調査する案内と、作業場所の外の配信元を outside_scope で参照する案内を追加する

## 概要

SessionStart で追加する文に、コードや不具合の調査も設計書から参照することと、作業場所の外の配信元を `outside_scope` で参照できることを追加し、エージェントが設計書を軸に調査できるようにする。

## 背景

[#86](https://github.com/shuhei1101/dev-docs/issues/86) の要望。
SessionStart の文（`content/prompts/session-context.yaml`）は使える配信元の一覧と「使い分けは MCP の instructions にある」だけを伝えるため、エージェントはコードや不具合をソースコードの grep・Read だけで調査し、設計書を読まない。
共有ファイルの同時書き込みの不具合では、コードだけの調査で、並列化の設計書の排他にする状態の一覧からそのファイルが漏れていたことを見落とした。
作業場所の外の配信元を `outside_scope: true` で読む仕組みは [#40](https://github.com/shuhei1101/dev-docs/issues/40) で入ったが、SessionStart の文に記載が無く、外の配信元の ID を知る手段（`describe(outside_scope: true)` で引くと決めた引き方）も実装されていない。
