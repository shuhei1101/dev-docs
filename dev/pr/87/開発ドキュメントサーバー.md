## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| SessionStart の文 | `session-context.yaml` の `omitted` の後ろに、設計書から調査する案内と、作業場所の外の配信元を `source` と `outside_scope: true` で参照する案内のパーツを、`usage` と同じ条件（`sources` が 1 件以上）で追加する | 文言は起点 Issue の例を元に、配信元の ID・リポジトリ名を固有の値で含めず、instructions と重ねない |
| 字数の上限 | 追加後も、既存の単体テスト（40 件の配信元）の条件で 1,000 字以内に収まることを確かめる | 収まらない場合は、追加の文を短くする |
| 作業場所の外の配信元の ID | `source` を省いた `describe(outside_scope: true)` で、使える配信元の一覧に加えて `outside_sources[]`（`id`・`description`）を返す。要求のログには残さない | `outside_scope` を省いた引数なしの一覧と SessionStart の一覧は変えない |
| モジュールの分割 | 外で読める配信元の選び出しは `access/service.py` の `outside_readable_sources`、一覧の行は `describe/types.py` の `OutsideSource`、表は `describe/render.py` が受け持つ | 0 件は markdown で `なし`、json は `outside_sources` のキーを持たない |
| 既存機能への影響 | `sources`・`warnings`・`forgotten`・`loading` の応答の項目と、配信元が無いとき・読み込み中の文は変えない | |
