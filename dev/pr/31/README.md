# search_docs・list_changes に、文書ごとの当たった数・本文の一部の取得・not・glob・変更の中身での検索を加える

## 概要

エージェントが grep・Read・git でやっていた探し方（当たった数で並べる・本文の一部だけ読む・束ごとの否定・パスの glob・語が入った・消えた変更を引く）を、`search_docs`・`list_changes` のオプションでできるようになる。

## 背景

[Issue #28](https://github.com/shuhei1101/dev-docs/issues/28) の要望。
grep・jq など普段の検索の手段を `search_docs` に移すとできなくなることを突き合わせた結果（話し合いの L-86）、ツールは増やさず既存のツールのオプションで埋めると決めた。
不具合に近い正規表現の行単位・抜粋の判定・抜粋の行番号は [PR #30](https://github.com/shuhei1101/dev-docs/pull/30)（[#27](https://github.com/shuhei1101/dev-docs/issues/27)）で先に入り、この PR はその抜粋の判定を前提に `@matches` を数える。
`filter` の `not` は、後ろへ回した [#16](https://github.com/shuhei1101/dev-docs/issues/16)（画面の `nav` のタグの式）が使う。
