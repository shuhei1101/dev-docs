## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| フックが返却する文言 | [要件](./要件.md) の `## 要望` の修正前後のとおりに置き換える | 分岐・関数・定数名は変えない |
| 設計書 | 修正後の文を引用し、案内の中身を指す項目は `つなぎ直し` を `再接続`、`取り直せる` を `再取得できる`、`返し済みの記録` を `返却済みの記録` に置き換える | 修正する項目以外の文言は変えない |
| テスト | 照合する部分文字列を `再接続して`（結合）・`再接続`（E2E）に置き換え、記録の削除の失敗の照合に `再取得できます` を追加する | |
