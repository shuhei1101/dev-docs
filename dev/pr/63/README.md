# スラッシュ無しの /mcp・/_admin/mcp への POST が 405 になり MCP に接続できないのを修正する

## 概要

Claude Code のプラグインが、接続先 `/mcp`・`/_admin/mcp`（スラッシュ無し）で dev-docs の文書の MCP と管理の MCP に接続できるようになる。

## 背景

[Issue #62](https://github.com/shuhei1101/dev-docs/issues/62) の不具合。
[PR #36](https://github.com/shuhei1101/dev-docs/pull/36)（[58048a5](https://github.com/shuhei1101/dev-docs/commit/58048a5)）で、`build_app` が全てのパスに当たる画面の配信のルーター（`GET /{path:path}`）を最後に登録した。
`/mcp`・`/_admin/mcp` はマウント（`/mcp/...` に当たる）に当たらず画面の配信のルートに当たり、POST は GET だけを受けるルートで 405 になる。
2026-10-31 の時点で、全てのセッションで dev-docs の MCP に接続できず、[shuhei1101/ai-monitor#3093](https://github.com/shuhei1101/ai-monitor/issues/3093) が止まっている。
