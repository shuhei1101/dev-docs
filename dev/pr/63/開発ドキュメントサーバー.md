## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MCP のルーティング | スラッシュ無しの `/mcp`・`/_admin/mcp` への POST を、リダイレクトを挟まずに文書の MCP・管理の MCP へ届けて 200 を返す | `要件.md` の `## 要望` の案 A。ルーティングの前にスラッシュ無しのパスを MCP のマウントへ届ける |
| 画面の配信 | `/_api/`・`/mcp`・`/_admin/` 以外のパスで、今のまま `index.html` と `assets/` を返す | - |
| 結合テスト | スラッシュ無しの `/mcp`・`/_admin/mcp` へ initialize を POST し、リダイレクトを挟まずに 200 で返ることを確かめる | `httpx` のリダイレクトの追従を切って確かめる |
| 既存機能への影響 | スラッシュ付きの `/mcp/`・`/_admin/mcp/` への POST と、画面の API `/_api/` の応答を変えない | 既存の結合テストで回帰確認する |
