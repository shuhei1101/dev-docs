# dev-docs のプロジェクトを立ち上げる

## 概要

汎用の開発ドキュメントサーバー dev-docs のリポジトリに、要件・構成方針・設計の土台と、Python（uv）のパッケージ・`docs/`・マーケットプレイスの雛形を置く。

## 背景

[Issue #2](https://github.com/shuhei1101/dev-docs/issues/2) の要望。
各リポジトリが YAML の正本で持つ開発ドキュメントを、人には画面で、AI には MCP（HTTP）で出すサーバーを、ai-monitor の開発ドキュメントサーバーの汎用の部分を土台に新しく作る。
リポジトリは [README.md](https://github.com/shuhei1101/dev-docs/blob/develop/README.md) と [docs/README.md](https://github.com/shuhei1101/dev-docs/blob/develop/docs/README.md) だけを持つ。
機能はこの立ち上げの後に [Issue #3](https://github.com/shuhei1101/dev-docs/issues/3)（サーバー本体）と [Issue #4](https://github.com/shuhei1101/dev-docs/issues/4)（管理用のプラグイン）が作る。
