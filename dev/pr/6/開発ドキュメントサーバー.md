成立。MCP の Python SDK 2.3.0（`MCPServer`）で、プロジェクトごとの session manager をアプリ全体の task group の中で開始・停止すれば、lifespan の外でも足す・外す・ref のパスを立てることができる。

核心部（[server.py](https://github.com/shuhei1101/dev-docs/blob/7bcaa54/poc/mcp-per-project/server.py) の `Registry._start`）:

```python
manager = build_server(key).session_manager
cancel_scope = anyio.CancelScope()

async def run() -> None:
    try:
        with cancel_scope:
            async with manager.run():
                started.set()
                await anyio.sleep_forever()
    finally:
        stopped.set()

self._task_group.start_soon(run)
await started.wait()
```

diff の見どころ: `App.__call__` が `/{name}(@{ref})?/mcp` を正規表現で受けて session manager の `handle_request` へ渡し、外すときは `cancel_scope.cancel()` の後に `stopped` を待つ。
