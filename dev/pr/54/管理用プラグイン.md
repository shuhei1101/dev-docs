## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `CONTEXT_TIMEOUT_SEC` | session-context の応答の時間を測り、規約『資源の値の決め方』で決めた値にする | `未確定`（`要件.md` の `## 要望`。決める段: インターフェース定義設計） |
| `hooks.json` の SessionStart の `timeout` | `CONNECT_TIMEOUT_SEC` と `CONTEXT_TIMEOUT_SEC` の和より長くする | 値は `CONTEXT_TIMEOUT_SEC` と同じ段で決める |
| 打ち切ったときの文 | 「dev-docs の文脈を取れませんでした」の文に、打ち切った秒数（`CONTEXT_TIMEOUT_SEC`）を入れる | 打ち切り以外の失敗（接続の拒否・応答の読み取りの失敗）の文は変えない |
| `/dev-docs:setup` の手順 | スキーマのコピーと `records: files` の行の作り方を、決めた当て方に合わせる | 案 A なら手順は変えず、案 B なら 1 行のスキーマのテンプレートをコピーする |
