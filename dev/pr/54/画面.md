## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 相対リンクの解決の基準 | `doc.bodyPath` があればそれを、無ければ `doc.path` を基準に相対リンクを解決する | 通常の文書（ファイル 1 つが 1 文書）は今の解決のまま |
| 画面の API の生成 | サーバーの `DocumentResponse` の項目の追加に合わせて orval で生成し直す（型・zod・MSW のモック） | `src/dev_docs/screen` のビルドの成果物も lefthook がビルドし直す |
| 解決したパスの行き先 | 解決したパスをそのまま文書のルート（`/$source/$`）に渡す | サーバーの引き方は `未確定`（`要件.md` の `## 要望`。決める段: インターフェース定義設計） |
