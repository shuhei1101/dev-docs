# タグのマスター（dev-docs.yaml の tags）とタグの検査をやめ、使われているタグの集計と正規化にする

## 概要

配信元は `dev-docs.yaml` にタグのマスターを持たずにタグを自由な文字列で付け、エージェントは `search_docs` の `group_by: tags`（横断は `source: *`）で使われているタグを件数つきで見て、同じ意味のタグを使い回せるようになる。

## 背景

[Issue #25](https://github.com/shuhei1101/dev-docs/issues/25) の要望。
今の `dev-docs.yaml` の `tags` はタグのマスターのファイルを指し、マスターに無いタグを検査で違反にする（#12 で導入）。
話し合い（knowledge の `tmp/mcpベストプラクティス検討` の D-169）でタグのマスターを持たないと決め直した。リポジトリごとにマスターを持つとプロジェクトの間で語彙がずれ、保守の手間もかかる。
文書の外に保存したタグの条件が 0 件に当たるようになったときの警告は、条件を作る #16 で行う（[書き直しの判断](https://github.com/shuhei1101/dev-docs/issues/25#issuecomment-6477285027)）。
