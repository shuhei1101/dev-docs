## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の検証 | スキーマから `tags` を外し、`tags` を書いた設定を「知らないキー」の違反にする。マスターのファイルの有無の検査をなくす | 違反は今の `additionalProperties: false` の違反と同じ形 |
| 配信元の読み込み | `SourceConfig.tags`・`ServedSource.tag_master`・`_tag_master` を削除する | - |
| 文書の検査 | 『文書の検査』から『タグの検査』を外し、`check_tags` を削除する | `tags` の型は種類のスキーマが検査する |
| 設定のバージョン | `SOURCE_CONFIG_VERSION` を `"3"` にし、`migrations/dev-docs/3/steps.yaml` に `tags` を削除する手順を置く。雛形の `version` も `"3"` にする | `value` を持たない `delete` で、破壊的な手順として `--allow-destructive` で当てる |
| `group_by` の集計 | どの項目も値を `normalize`（NFKC と `casefold`）でまとめてから数え、1 つの文書の同じ値は 1 件と数える。件数の降順・値の昇順の並びは変えない | 返す表記は付いている文書が最も多い元の表記（同数なら値の昇順で先） |
| SessionStart の使い方 | 1 行目を「`describe(source)` で種類と書き方を確かめる」にし、タグは `search_docs` の `group_by="tags"` で使われているタグを見て同じ意味のタグを使い回す案内にする | `CONTEXT_MAX_CHARS` に収める |
| ツールの説明 | `search_docs` の説明に、タグを付ける前に `group_by: tags`（横断は `source: "*"`）で使われているタグを引くことを追加する | - |
| 既存機能への影響 | 検索の条件の比較・`nav` の `auto` の `group_by` は変えない | `nav` の扱いは要件.md の `## スコープ外` |
