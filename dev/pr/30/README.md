# search_docs の正規表現を行単位にし、抜粋を条件と同じ判定で探して行番号を付ける

## 概要

エージェントが `search_docs` の正規表現で行の先頭・末尾に当てて探し、当たった行を行番号つきの抜粋で受け取れるようになる。

## 背景

[Issue #27](https://github.com/shuhei1101/dev-docs/issues/27) の要望。
grep・jq など普段の検索の手段を `search_docs` に移すとできなくなることを突き合わせた結果（話し合いの L-86）、不具合に近い 2 つと抜粋の行番号を先に直すと決めた（ツールは増やさず `search_docs` のオプションで埋める）。
`search_docs` は [Issue #3](https://github.com/shuhei1101/dev-docs/issues/3) の決定（D-141〜D-143）で作り、[PR #12](https://github.com/shuhei1101/dev-docs/pull/12) で入った。
今は `op: regex` で当てた文書の抜粋が空になり、正規表現が本文 1 つを丸ごとの文字列として当たるため `^`・`$` が行に当たらず、抜粋に行番号が無い。
後続の [#28](https://github.com/shuhei1101/dev-docs/issues/28)（当たった数・本文の一部・`not`・glob・変更の中身）はこの PR を前提にする。
