# content/prompts/ のプロンプトの YAML を変数の表・テンプレート・例ごとの描画のタブで画面に配信する

## 概要

利用者は、`content/prompts/` に置いたプロンプトの YAML を、dev-docs の画面で変数の表・テンプレート・例ごとに描画した結果を、言語の切り替えつきで読めるようになる。
`/dev-docs:setup` は `content/prompts/` を見つけたら、そのプロンプトを配信する documents の行を候補に出す。

## 背景

[Issue #47](https://github.com/shuhei1101/dev-docs/issues/47) の要望。
プロンプト（LLM の呼び出し・フックの注入文・MCP の instructions・ツールの description）を `content/prompts/` の YAML に置く形を knowledge で決めた（shuhei1101/knowledge#128。スキーマは knowledge の `schemas/prompt.schema.yaml`）。
プロンプトは利用者も読むため、dev-docs の画面で配信する（D-193〜D-197）。
画面は #17（PR #36）で React の SPA になっており、変換が出す Markdown を mdmark で描く。
dev-docs 自身のプロンプトを `content/prompts/` へ移す作業は #48 が扱う。
