# 要件

## 要望

`content/prompts/` に置いたプロンプトの YAML（スキーマは knowledge の `schemas/prompt.schema.yaml`、キーは A-42）を、dev-docs の文書の画面で読めるようにする。

| 要件 | 終わりの条件 |
| --- | --- |
| プロンプトの YAML（標準入力）から Markdown（標準出力）を出す変換を dev-docs が持つ | 各配信元が変換のスクリプトを書かずに、documents の行の `converter` で指して使える |
| 見出し | `name`・`kind`・`lang`・`description` が本文の頭に出る |
| 変数の表 | `vars` の入れ子（`items`・`properties`）を `traits[].name` のようなパスで展開し、型・必須・例・説明・出どころを 1 つの表に並べる |
| テンプレート | 部品ごとのセクションに `id`・`role`・`when` の見出しと Jinja2 の本文が出る。本文の `{{ 変数 }}` に、説明・型・例のツールチップが付く |
| 例 | 「既定の例」（各変数の `example`）と `examples[]` の組ごとのセクションに、`when` が真の部品だけを描画した結果が出る。`kind: llm` は `role` ごとのメッセージに分ける。使わなかった部品と字数を出す |
| 言語の切り替え | `parts[].texts[]` の言語をセクションごとのタブで切り替えて表示する。タブ名は言語コードだけにし、注入する言語（トップレベルの `lang`）はバッジと字数の行で示す。言語が 1 つの文書はタブを出さない |
| 描画できない組 | 未定義の変数・型の合わない値の組は、その組のセクションにエラーを出し、他の組は描画する |
| 字数の注意 | `kind: hook` の描画結果が 1,000 字を超えた組のセクションに注意を出す |
| setup の候補 | `/dev-docs:setup` が、配信元の直下とプラグインのルートの `content/prompts/` を見つけたら、documents の行（`paths`・`schema`・`converter`・`metadata`）を候補に出す |
| `metadata` の対応 | `name`・`description`・`tags` を共通のキーへ対応づけ、`kind` でサイドバーを種類ごとにまとめる |
| 完了条件 | A-42 の例 1（`kind: hook`）と例 2（`kind: llm`）を配信し、画面で変数の表・テンプレート・例のセクション・言語の切り替えが出る。`/dev-docs:setup` で `content/prompts/` を持つリポジトリの documents の行が作られる |

例の組の見せ方は、変数の表・テンプレート・例を `##` のセクションで並べ、テンプレートの部品と例の組を `###` のセクション（例の組の 2 つ目以降は閉じた状態）にし、各セクションの中に言語のタブを置く（[確認ログ](./確認ログ.md)）。
mdmark（v0.8.0）はタブの入れ子を描けない（[reviewer の再現](https://github.com/shuhei1101/dev-docs/pull/56#discussion_r4430567991)）。

変換は dev-docs のパッケージに置き、配信元の `converters[].run` から CLI のサブコマンドとして呼ぶ。`templates/` には `converters[]` と documents の行の雛形を置く（[確認ログ](./確認ログ.md)）。
setup は knowledge の `schemas/prompt.schema.yaml` を配信元の `schemas/` へコピーし、documents の行の `schema` はそのパスを指す（[確認ログ](./確認ログ.md)）。
本文の見せ方はモックの c-a43 の案にする（タグ・出力の行、部品の role・tags・when のバッジ、例の代入値のマーカーとツールチップ。[確認ログ](./確認ログ.md)）。

「`kind` を種類の列へ」は、setup が `nav` の `auto` に `group_by: kind` を付けた候補を出し、サイドバーを種類ごとにまとめる（単一ユースケース設計で決定）。
共通のキーに種類のキーは無く、A-42 の `kind` の説明は「本文の書き方の検査と画面の並びに使う」で、画面の並びに使えれば足りる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| dev-docs 自身の SessionStart の注入文・MCP の instructions・ツールの description を `content/prompts/` へ移す | 要望に含まれない。この PR の変換を前提に別の Issue で扱う | #48 |
| setup がコピーしたスキーマが古くなる問題 | 要望に含まれない。files の行のスキーマのコピーと同じ問題 | #39 |
| 分岐ごとに例のタブを自動で作る | D-196 で見送った（分岐を見せたいときは書き手が `examples[]` の組を追加する） | 予定なし |
