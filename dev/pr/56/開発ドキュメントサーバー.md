## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変換の置き場所 | 変換を dev-docs のパッケージに置き、配信元の `converters[].run` から CLI のサブコマンド `dev-docs prompt-doc`（[インターフェース定義](https://github.com/shuhei1101/dev-docs/blob/chore/templates/prompt-yaml-converter/dev/設計書/インターフェース定義/開発ドキュメントサーバー/プロンプトの文書の変換.yaml)）として呼ぶ | [確認ログ](./確認ログ.md) |
| 変換の入出力 | 標準入力にプロンプトの YAML 1 件、標準出力に Markdown。読めない YAML・スキーマに合わない YAML は 0 以外で終わり、標準エラーに理由を出す | 今の `converters[]` の約束（`docs/リファレンス/設定.md`）のまま |
| 見出し | `name` を見出しに、`kind`・`lang` をバッジに、`description` を段落に出し、タグ・出力の行を置く | mdmark のバッジ。見せ方はモックの c-a43（[確認ログ](./確認ログ.md)） |
| 本文の構成 | 見出しの下に、変数の表・テンプレート・例を `##` のセクションで並べ、その下に部品・組の `###` のセクションを置く。タブにするのは各 `###` のセクションの中の言語だけにする | mdmark はタブの入れ子を描けない（[確認ログ](./確認ログ.md)） |
| 変数の表 | `vars` を深さ優先で辿り、配列の要素は `{名前}[].{キー}`、オブジェクトのキーは `{名前}.{キー}` のパスで 1 行にする。列は変数・型・必須・例・説明・出どころ | 例は YAML のフロー形式の 1 行 |
| テンプレート | 部品ごとの `###` のセクションに `id` の見出しと `role`・`tags`・`when` のバッジと本文を出し、本文の `{{ 変数 }}` を `data-hint`（説明・型・例）付きの要素にする | 部品のセクションごとに言語のタブを置く。埋め込んだ HTML のヒントは PoC 検証で画面のホバー・フォーカスと幅を確かめる |
| 例の組 | 「既定の例」（各変数の `example`）と `examples[]` の組（省いた変数は `example`）ごとの `###` のセクション（2 つ目以降は `<!-- section: closed -->`）に、`when` が真の部品を Jinja2 で描画してつなぐ。`kind: llm` は `role` ごとのメッセージに分ける。描画した結果の変数の値をマーカーで囲み、変数のパスと説明のツールチップを付ける。使わなかった部品の `id` と、描画した結果の字数を出す | Jinja2 は `StrictUndefined`・`trim_blocks`・`lstrip_blocks` の Environment で描画し、未定義の変数を誤りにする。この設定はプロンプトを実際に描画する側と揃え、字数の注意が注入文とずれないようにする。組はタブにしない |
| 言語の切り替え | セクションごとに `<!-- tabs: group=lang -->` の言語のタブを置く。タブ名は言語コードだけにし、注入する言語はバッジと字数の行（`注入する本文（en）`）で示す。言語が 1 つの文書はタブを置かず中身だけを出す | 同じ `group` のタブ群はタブ名で揃って切り替わり、選んだ言語を文書をまたいで覚える |
| 描画できない組 | 未定義の変数・`type` に合わない値の組は、その組のセクションに `[!CAUTION]` の注意書きで変数と理由を出し、他の組のセクションは描画する | 型は `vars` の `type`・`items`・`properties` で確かめる |
| 字数の注意 | `kind: hook` で描画した結果が 1,000 字を超えた組のセクションに `[!WARNING]` の注意書きを出す | 1,000 字は Issue の値 |

| 長い行の折り返し | 文書の画面の CSS で、埋め込みの HTML の `pre`（`.mdmark-html pre`）を折り返す | mdmark は埋め込みの HTML の `style` を落とすため、変換の出力では折り返せない（[確認ログ](./確認ログ.md)） |

設計へ持ち込む点:

- 変数を含まない部品の `<pre>` は、axe の `scrollable-region-focusable`（スクロールする領域にキーボードで届かない）に当たった。変換は `<pre>` に `tabindex="0"` を付ける
- Jinja2 の `{% for %}` の後に空行が残った。変換は `trim_blocks`・`lstrip_blocks` を付けた Environment で描画する

最小再現コードの要点（[convert.py](https://github.com/shuhei1101/dev-docs/blob/68562dfb891dc91d1da86cf6f4a6f3891f764c25/poc/prompt-doc/convert.py)）:

```python
def template_html(text, paths):
    """部品の本文を、変数にヒントを付けた <pre> の HTML にする。"""
    aliases = {m.group(1): m.group(2) for m in FOR_PATTERN.finditer(text)}  # for の変数 → 配列の名前
    out, last = [], 0
    for m in EXPR_PATTERN.finditer(text):  # {{ 式 }} ごと
        out.append(html.escape(text[last : m.start()]))
        hint = hint_for(m.group(1), paths, aliases)  # 説明・型・例
        token = html.escape(m.group(0))
        out.append(f'<span data-hint="{html.escape(hint)}">{token}</span>' if hint else token)
        last = m.end()
    out.append(html.escape(text[last:]))
    return "<pre><code>" + "".join(out) + "</code></pre>"


def lang_tabs(doc, body_of):
    """言語のタブを出す（同じ group で全てのセクションを揃える）。"""
    lines = ["<!-- tabs: group=lang -->", ""]
    for lang in languages(doc):  # 注入する言語が先頭
        name = f"{lang}（注入）" if lang == doc["lang"] else lang
        lines += [f"#### {name}", "", *body_of(lang), ""]
    return lines + ["<!-- /tabs -->", ""]
```
