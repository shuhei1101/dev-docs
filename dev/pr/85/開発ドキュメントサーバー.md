## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 型の検査 | `expand_array_keys` で集めた共通のキーのうち、`data`・`set`・`add_to`・`remove_from` に渡した値が、要素が全て文字列のリストかを、操作を当てる前に確かめる | `unset` は名前を受けないので対象外 |
| エラー返却 | 違反は `path` が `operations[{index}].{項目}.{共通のキー}`、`rule` が名前（文字列）の配列で渡すことを示す文言の `Violation` にし、他の違反と合わせて `InvalidArgumentError` で送る | 違反があれば配列の書き戻しを当てない |
| 既存機能への影響 | 文字列の配列を渡したときの書き戻し・選んだ要素のキーの違反は変えない | |
