# write_docs の tags・main_tags に文字列の配列でない値を渡したときに引数の誤りとして返す

## 概要

`tags[].name` の対応を持つ種類へ `write_docs` で `tags`・`main_tags` に文字列の配列でない値を渡したとき、エージェントが名前の配列で渡し直せるよう、引数の誤り（`InvalidArgumentError`）として返す。

## 背景

[#84](https://github.com/shuhei1101/dev-docs/issues/84) の要望（依頼元 [shuhei1101/knowledge#140](https://github.com/shuhei1101/knowledge/issues/140)）。
`tags` をオブジェクトの配列（`[{"name": "scope:dev", "main": true}]`）で渡すと、`features/write/apply.py` の `_rebuild` が dict を辞書のキーに使って `TypeError` で落ち、エージェントには `Error executing tool write_docs` しか返らない。
`tags[].name` の対応は [#43](https://github.com/shuhei1101/dev-docs/issues/43) で入った。
