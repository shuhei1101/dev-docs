# 汎用の開発ドキュメントサーバー（文書の MCP・設定・検査・変換と画面の API）を作る

## 概要

利用者が端末の設定に並べた配信元の YAML の文書を、エージェントは文書の MCP で読み書きでき、#17 の画面が使う API も配れるようになる。

## 背景

[Issue #3](https://github.com/shuhei1101/dev-docs/issues/3) の要望。
立ち上げの [PR #6](https://github.com/shuhei1101/dev-docs/pull/6) で置いたのは設計の土台と `dev-docs` コマンドの入口だけで、サーバーの機能はまだ無い。
土台は ai-monitor の開発ドキュメントサーバーと設計書の MCP で、汎用の部分を切り出す（D-101）。
本文は 2026-10-26 に今の設計（`/mcp` の 1 つ・`sources[]` と作業場所ごとの権限・6 つのツール）へ書き換えられ、`aliases[]` の部分は [#11](https://github.com/shuhei1101/dev-docs/issues/11) に切り出された。
管理の MCP・フック・スキルは [#4](https://github.com/shuhei1101/dev-docs/issues/4) が作る。
