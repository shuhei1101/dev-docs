# 画面（文書・設定・見つからない画面）を React（Vite + shadcn/ui）の SPA で作る

## 概要

利用者が、文書の画面・設定画面・見つからない画面を、React（Vite + shadcn/ui）の 1 つの SPA で使えるようになる。

## 背景

[Issue #17](https://github.com/shuhei1101/dev-docs/issues/17) の要望。
#3 の作業 PR #12 は画面を Jinja2 + バニラ TS で作っていたが、[確認事項](https://github.com/shuhei1101/dev-docs/issues/17#issuecomment-6454476829) で案 B に決まり、#3 から画面を外してこの PR で最初から React で作る。
develop には #3 が作った画面の API（`/_api/`）があり、画面と `index.html` の配信は無い。
従う規約は shuhei1101/knowledge#79・shuhei1101/knowledge#80（React・ui）と shuhei1101/knowledge#84（API の名前・エラー・JSON のキー）で決まった。
