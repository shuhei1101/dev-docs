## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| operationId | `FastAPI(generate_unique_id_function=...)` で `{tag}-{関数名}` にし、画面の API の `APIRouter` に `tags` を 1 つずつ置く | shuhei1101/knowledge#84 |
| JSON のキー | 画面の API の入出力の基底に `ConfigDict(alias_generator=to_camel, validate_by_name=True, serialize_by_alias=True)` を置き、キーを camelCase にする | クエリのパラメータ名は変えない |
| エラー返却 | Problem Details の拡張メンバー（`next_steps`・`errors[]` 等）を camelCase にし、`register_error_handlers` を `register_exception_handlers(app)` にして例外から HTTP へのマップをこの 1 か所に置く | `RequestValidationError` も同じ形にそろえる |
| 画面の配信 | ビルドした `index.html` と静的ファイルを配り、`/_api/`・`/mcp`・`/_admin/` 以外の画面のパスには `index.html` を返す | ビルドの配り方は要件の `未確定` |
| 既存機能への影響 | 画面の API の利用者はこの PR の画面だけで、JSON のキーの変更を互換なしで行う | 公開済みのインターフェースは無い |
| 動作環境 | 非機能要件の `動作環境` の 2 行（対応ブラウザ・画面幅）の決定値を、knowledge の規約『対応ブラウザ』と画面の設計で決める | 画面設計で決めた |
