# サイドバーをフォルダで束ね、再起動の停止時間を短くし、sources[].config を配列で書き、mdmark v0.9.0 と setup の exclude に合わせる

## 概要

利用者がサイドバーでフォルダごとに束ねた文書を読め、再起動の間も MCP と画面へ早くつなぎ直せ、設定画面・目次・選択のコメントボタン・`/dev-docs:setup` の突き合わせが期待どおりに動くようにする。

## 背景

[#75](https://github.com/shuhei1101/dev-docs/issues/75) の束（[#58](https://github.com/shuhei1101/dev-docs/issues/58)・[#65](https://github.com/shuhei1101/dev-docs/issues/65)・[#66](https://github.com/shuhei1101/dev-docs/issues/66)・[#67](https://github.com/shuhei1101/dev-docs/issues/67)・[#73](https://github.com/shuhei1101/dev-docs/issues/73)）。

- #58: nav の `auto` にフォルダで束ねる指定が無く、サイドバーが平らになる。手で書いた `page` が指す文書は `auto` にもう 1 回出る
- #65: 再起動のたびに、待ち受けの前の配信元の読み直しと検査で約 100 秒 MCP と画面に接続できない（[#62](https://github.com/shuhei1101/dev-docs/issues/62) の反映作業で再起動のスクリプトが打ち切った）
- #66: 設定画面から保存すると要素 1 つの `sources[].config` が文字列で書かれ、E2E が fail する
- #67: mdmark の master に v0.9.0 が入った後、目次の現在の見出しと選択の「コメント」ボタンが動かず、結合テストと E2E が fail する
- #73: `/dev-docs:setup` の突き合わせが行の `exclude` を `dev-docs files` に渡さず、`check_project` と候補が食い違う
