## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の調査 | mdmark の v0.8.0 と v0.9.0 の差分から、目次と選択のコメントに触れる変更を特定する | 目次は mdmark#166（右側の目次と節の開閉）を起点に調べる |
| 目次の現在の見出し | v0.9.0 の描く本文の構造に合わせて、現在の見出しを判定する | |
| 選択の「コメント」ボタン | v0.9.0 の `mount` の設定・コメントの機能の有効化に合わせる | mdmark 側の不具合なら mdmark へ起票し、この PR の依存を置き直す |
| 読み込み元 | jsDelivr の master を読む今の方式を保つ | 固定するのはユーザーの確認を取ったときだけ |
| 外部ライブラリの設計書 | `mdmark.yaml` の `latest`・`version` を v0.9.0 にし、動作確認の記録を v0.9.0 で確かめた内容へ書き換える | |
