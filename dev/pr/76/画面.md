## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 目次の現在の見出しの原因 | mdmark v0.9.0 が、描く先の要素の幅が 48rem 未満のとき `.mdmark-content [id]` に `scroll-margin-block-start: calc(var(--mdmark-sticky-top, 0px) + 3.5rem)` を当てる。画面の `scroll-padding-top: 6rem` と足されて、見出しへ移った後の上端が 152px になり、144px の線を越えない | 結合テストの調査で、移った後の `関連` の上端が 151.7px |
| 目次の現在の見出し | `useActiveHeading` のスクロールでの判定で、見出しごとの線に、その見出しの `scroll-margin-top` を足す | |
| 選択の「コメント」ボタン | 画面は変えない。結合テストの `addComment` と E2E の文字列を選ぶ手順は、mdmark がコメントの部品を付け終えた印（`#mdmark-comment-hint` が文書に入る）を待ってから文字列を選ぶ | mdmark は部品のモジュールを読み込み、`store.load` を待った後に `selectionchange` を受け始めるため、それより前に選んだ文字列ではボタンが出ない。並列で回して読み込みが遅れたときだけ fail する（2026-11-01 にこの worktree で、単独では 6 回とも pass、ファイル全体では 101 件中 1 件 fail） |
| 読み込み元 | jsDelivr の master を読む今の方式を保つ | 固定するのはユーザーの確認を取ったときだけ |
| 外部ライブラリの設計書 | `mdmark.yaml` の `latest`・`version` を v0.9.0 にし、動作確認の記録を v0.9.0 で確かめた内容へ書き換える | |
