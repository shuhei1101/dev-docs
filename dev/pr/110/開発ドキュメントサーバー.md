## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表の外部キーのセル | 分類を付けない外部キーのテーブル名を、同じ文書の `tables[]` の `title` か `name` に当て、当たったテーブルの見出しのアンカーへのリンクにする。どちらにも当たらなければ値の文字のまま | `未確定`（物理名を引く範囲。要件.md の `## 要望`。決める段: モジュール構成設計） |
| 既存機能への影響（変換） | 論理名で書いた外部キーのリンク・他の分類の文書へのリンク・参照のリンクは今と同じ結果にする | 推奨の案 A のとき |
| エラー返却（画面の配信） | `EXCLUDED_PREFIXES` の下の、どのルートにも当たらないパスへの要求は、メソッドによらず 404 の problem+json を返す | `未確定`（不在の判定。要件.md の `## 要望`。決める段: インターフェース定義設計） |
| 既存機能への影響（画面の配信） | `/mcp`・`/_admin/mcp` の MCP、`/_admin/session-start`、`/_api/` のルートへの要求は今と同じ入口が応える | 推奨の案 C のとき |
| 反映作業の確認 | #103 の確認スクリプトと確認方法を、決めた判定に合わせる | 案 C なら 404 の判定のまま |
