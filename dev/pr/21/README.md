# 管理用のプラグイン dev-docs（起動のフック・管理の MCP・スキル・設定の移し替え）を作る

## 概要

利用者は dev-docs のプラグインをユーザースコープで入れるだけで、どの作業場所でも dev-docs の起動・文書の MCP への接続・配信元の登録と管理ができるようになる。

## 背景

[Issue #4](https://github.com/shuhei1101/dev-docs/issues/4) の要望。
サーバー本体（文書の MCP・設定・検査・変換）は [PR #12](https://github.com/shuhei1101/dev-docs/pull/12)、文書のメタデータと管理用の YAML は [PR #20](https://github.com/shuhei1101/dev-docs/pull/20) で入っている。
管理の MCP `/_admin/mcp` はセッションを張れるだけでツールを持たず、プラグインは `plugin.json` だけで、フック・`.mcp.json`・スキルが無い。
SessionStart のフックでサーバーを切り離して起動できること（直後のセッションは `/mcp` のつなぎ直しが要る）は [PR #9](https://github.com/shuhei1101/dev-docs/pull/9)（PoC）で確かめた。
