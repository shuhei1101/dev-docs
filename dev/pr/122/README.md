# Git フック（lefthook）から lint・型検査のジョブを削除し、画面のビルドのジョブだけを残す

## 概要

`lefthook.yml` の `pre-commit` から lint・型検査のジョブを削除し、画面のビルドのジョブだけを残す。

## 背景

[Issue #121](https://github.com/shuhei1101/dev-docs/issues/121) の要望。
lefthook の `pre-commit` は [PR #36](https://github.com/shuhei1101/dev-docs/pull/36) で入れた lint・型検査を実行し、AI Monitor の手順で planner が実行して reviewer が確認する lint と重なっている。
規約の側は [shuhei1101/knowledge#227](https://github.com/shuhei1101/knowledge/issues/227) で、Git フックと CI に生成・配布に当たるものだけを記載する決まりにする。
