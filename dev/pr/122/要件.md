# 要件

## 要望

`lefthook.yml` の `pre-commit` から lint（`frontend-lint`）と型検査（`frontend-typecheck`）のジョブを削除し、画面のビルド（`frontend-build`。ビルドの成果物を `src/dev_docs/screen/` へ戻してステージする）のジョブだけを残す。
lefthook を前提にした設計書と README の記載を、削除した後のフックに合わせる。

終わりの条件は次のとおり。

| 対象 | 削除した後の状態 |
| --- | --- |
| `lefthook.yml` | `pre-commit` のジョブが `frontend-build` だけで、`npx lefthook validate` が通る |
| `frontend/` を含む commit | lint・型検査が実行されず、ビルドし直した `src/dev_docs/screen/` がステージへ戻る |
| 設計書・README | フックが lint・型検査を実行するという記載が残っていない |

`package.json` の `prepare: lefthook install` と lefthook の依存は、`frontend-build` のために残す。
