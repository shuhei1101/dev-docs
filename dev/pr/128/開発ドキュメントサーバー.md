## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ノードの種類 | `NODE_KINDS` を新しいスキーマの `kind` からの対応表にし、`shape` の対応を削除する。`NodeKind` に `start`・`question`・`action`・`result` を加える | 古いキーは参照しない（[要件](./要件.md)） |
| 説明・詳細・線の種類 | ノードの `hint`、辺の `tip`・`line` を中間データに持たせ、mdmark の定義の `hint`・`tip`・`line` に出す | - |
| 枠 | `frame` を中間データに持たせ、配置した中のノードを余白つきで囲む mdmark の `frame` にする。戻る線の帯と図の端は枠の外に取る | 寸法は AI Monitor の生成と同じ値 |
| 状態遷移 | 始点・終点のノードを配置し、状態を `action` にする。`全状態`・`元の状態` を `representative` の状態との 1 本にし、元と先が同じ遷移を `loop` にする | 今の「初期状態」「終了状態」の補足の文言を置き換える |
| ER 図の関連 | 関連の `from_column`・`to_column`・`from_cardinality`・`to_cardinality` をそのまま mdmark の定義にする。`ER_CARDINALITIES`・`ER_CARDINALITY`・外部キーから両端の列を推定する処理を削除する | 実体の列（`columns` か同じ文書の `tables[]` の列）の作り方は変えない |
| 図の元データの表 | `DIAGRAM_HIDDEN_KEYS` から `shape` を削除し、新しいキーで隠す列を決める | - |
| 外部ライブラリ『mdmark』 | 最新を v0.10.0 にし、ER 図の部品・判定のノードの種類・枠・説明・詳細を master にあるものとして修正する | 読み込み先の切り替えは [#127](https://github.com/shuhei1101/dev-docs/issues/127) |
