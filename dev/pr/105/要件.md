# 要件

## 要望

次の範囲の文言を、knowledge の規約『文章の書き方』（`docs/rule/convention-writing-style.yaml`）の確認表と、AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`）に合わせて修正する。

| 範囲 | 対象 |
| --- | --- |
| 画面の文言 | `frontend/src/` が画面に出す文字列（表示の文言・ヒント・エラーと通知の文言・読み上げ名） |
| プロンプトの文言 | `content/prompts/` の MCP の instructions とツールの description |
| 画面の文言を記載した設計書 | 画面設計（`dev/設計書/画面設計/`）・部品設計（`dev/設計書/部品設計/`）・モジュール構成（`dev/設計書/モジュール構成/画面/`）のうち、画面に出す文字列を引用している箇所 |
| 画面の文言を引用した公開ドキュメント | `docs/使い方/画面で読む.md` の状態名 |
| 文言を参照するテスト | 画面の文言・プロンプトの描画結果を照合する単体・結合・E2E テストと Storybook のストーリー |
| 配信する画面のビルド | `src/dev_docs/screen/assets/` を修正後の `frontend/` からビルドし直す |

終わりの条件は、上の範囲で対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が、下の例外を除いて 0 件になること。
置き換え先は対応表の `ok` の単語にする。
検索の 0 件・スイッチのヒント・状態名のように、規約『入力と文言』が型を定める文言は、置き換え先をその型で決める。
対応表の置き換え先では名称が決まらず、対応表に無い単語で画面の名称を新しく決める箇所は、規約『ユーザー確認が必須な事項』の「ユーザーの目に触れる語彙を決める」に当たるため、ユーザーへ確認する。

`未確定`: 状態 `pending_reload` の名称と、それを使う文言（決める段: 画面設計）

対応表の置き換え先（`直す` → 修正、`読む` → 参照）では名称が決まらず、規約『入力と文言』は状態名を名詞の型（`未〇〇`・`〇〇中`・`〇〇待ち`・`〇〇済み`・`完了`・`要〇〇`）で記載すると定めるため、ユーザーへ確認する。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `再読み込み待ち`（`〇〇待ち`）。注記 `ファイルにありますが、まだ再読み込みしていません。`、通知 `端末の設定を保存し、配信元を再読み込みしました。` | 再読み込みの操作（保存・`reload`）を待っている状態を表す。注記・通知に同じ単語を使用できる | - |
| B | `未反映`（`未〇〇`）。注記 `ファイルの内容をまだ反映していません。`、通知 `端末の設定を保存し、配信元に反映しました。` | 短い | 何を反映していないかを注記で補う必要がある |

推奨: A

`再読み込み` はブラウザ・エディタで定着した操作名で、対応表の `allow` にある `読み込` の範囲に入る。設定ファイルを読み込み直す処理の中身とも一致する。

`未確定`: 同じバッジの状態 `not_served` の名称 `配信していない`（決める段: 画面設計）

対応表にはヒットしないが、規約『入力と文言』の状態名の型（名詞）に当たらない。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 本 PR では修正しない | Issue の範囲（対応表の置き換え）に収まる | 同じバッジの中で、名詞の状態名と名詞でない状態名が並ぶ |
| B | `配信停止` に修正する | 同じバッジの状態名が全て名詞になる | 対応表の置き換えの外の変更で、見つからない画面などの関連する文言も確認が要る |

推奨: B

同じバッジの 4 つの状態名のうち、`pending_reload` だけを名詞にすると型が統一されない。
案 A を選んだ場合は、画面設計の `配信停止` と、`## 更新ドキュメント`・`## 影響するユースケース` の `配信していない` の記載を元に戻す。

例外として、次の箇所は修正しない。

| 箇所 | 理由 |
| --- | --- |
| トップバーの `読み書き` / `読み取りだけ` | `読み書き` は権限を表す IT の分野で定着した単語で、規約『文章の書き方』の「文章でない所の用語の選び方」に当たる。設計書・公開ドキュメント全体で配信元の権限の用語として使っている |
| 画面設計・部品設計の `ごみ箱のアイコン` | アイコンの一般名称で、`箱` の比喩ではない |
| 画面設計・部品設計のキー名（`読み上げ名`・`読み上げ` など） | `dev/テンプレート/` のスキーマが定めるキー名で、文言ではない（`## スコープ外`） |
