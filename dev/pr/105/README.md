# 画面の文言とプロンプトの文言を、knowledge の規約『文章の書き方』と AI slop の単語の対応表に合わせて修正する

## 概要

利用者に表示する画面の文言と、エージェントが参照する MCP の instructions・ツールの description を、knowledge の規約『文章の書き方』と AI slop の単語の対応表に合わせて修正する。

## 背景

[Issue #93](https://github.com/shuhei1101/dev-docs/issues/93) の要望。
[knowledge#135](https://github.com/shuhei1101/knowledge/issues/135) で単語の対応表が YAML になり、[knowledge#159](https://github.com/shuhei1101/knowledge/issues/159) で確認表と対応表を各プロジェクトの文書に適用する方針になった（[ユーザーの回答](https://github.com/shuhei1101/knowledge/issues/159#issuecomment-6604460873)）。
受付判断（[task-planner の判断](https://github.com/shuhei1101/dev-docs/issues/93#issuecomment-6609515573)）で、`docs/`・`dev/` の文書は [#95](https://github.com/shuhei1101/dev-docs/issues/95) の手順 4 へ移管し、画面の文言とその画面設計・`content/prompts/` の文言・文言を参照するテストが本 PR の範囲になった。
