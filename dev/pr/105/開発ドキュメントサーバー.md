## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| プロンプトの文言 | 対応表の `pattern` にヒットする単語を `ok` の単語へ置き換え（使う → 使用する、読む → 参照する、返す → 返却する、書く → 記載する、確かめる → 確認する、消す → 削除する、外す → 除外する、語 → 単語、見る → 確認する、を行う → する）、確認表に当たる文を修正する | 置き換え以外の言い回しは変えない |
| 見出し | instructions の `使う場面:`・`使い方:` を、置き換え後の見出しにし、照合するテストを統一する | - |
| 他の作業 PR との重なり | #92（`instructions.yaml`・`describe.yaml`）・#89（`write-docs.yaml`）と同じファイルを書き換える。後からマージする側が base を取り込んで解消する | `session-context.yaml` は #92 が削除するため対象から除外する |
| 入出力 | ツールの名前・引数・応答は変えない | - |
