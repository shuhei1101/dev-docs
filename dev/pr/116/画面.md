## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 生成物 | サーバーの docstring を修正した後に、OpenAPI の書き出しと orval の生成を実行する | 生成物は手で編集しない |
| OpenAPI の書き出し | `frontend/scripts/export_openapi.py` が偽物の Handlers のプロンプトの描画（`MagicMock`）を MCP のツールの description に渡して失敗するため、描画の戻り値を空の文字列にする | develop でも失敗する。画面の API の OpenAPI には MCP のツールが出ないため、出力は変わらない |
| 配信する画面のビルド | ビルドし直しても `src/dev_docs/screen/assets/` は変わらない | zod の `describe` は画面のバンドルに含まれない |
| 画面の文言 | 画面の文言は変えない（サーバーの `rule` は設定画面・見つからない画面が値のまま表示する） | 画面のクライアントの検査の `既に使用されています` とサーバーの文言が統一される |
