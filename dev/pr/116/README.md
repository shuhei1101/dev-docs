# サーバーが返し画面が表示するエラーの文言と生成した zod の describe を、AI slop の単語の対応表に合わせて修正する

## 概要

`src/dev_docs/` が返却し画面が表示するエラーの文言と、生成元のサーバーの説明から生成した `frontend/src/shared/api/generated/` の型の説明・zod の `describe` を、knowledge の AI slop の単語の対応表に合わせて修正する。

## 背景

[Issue #107](https://github.com/shuhei1101/dev-docs/issues/107) の要望。
[PR #105](https://github.com/shuhei1101/dev-docs/pull/105)（起点 [Issue #93](https://github.com/shuhei1101/dev-docs/issues/93)）は画面の文言と `content/prompts/` の文言を対応表に合わせて修正し、サーバーの文言は [レビューの指摘](https://github.com/shuhei1101/dev-docs/pull/105#discussion_r4470213809) で別の Issue にした。
PR #105 の後、設定画面のクライアントの検査は `既に使用されています`、サーバーの保存の失敗は `既に使われています` を表示し、同じ画面の文言が統一されていない。
