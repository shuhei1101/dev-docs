# 要件

## 要望

次の範囲の文言を、knowledge の AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`）に合わせて修正する。

| 範囲 | 対象 |
| --- | --- |
| 画面が表示するサーバーの文言 | `src/dev_docs/` が返し、画面がそのまま表示する違反の `rule`・エラーの `message`（設定画面の保存の失敗のまとめ・配信元の状態の `errors[]`・見つからない画面の除外した理由・画面の API のエラーの `detail`） |
| 生成元のサーバーの説明 | 画面の API のモデルの docstring（OpenAPI の `description` になり、`frontend/src/shared/api/generated/` の型の説明と zod の `describe` に生成される） |
| 生成物 | `frontend/openapi.json`・`frontend/src/shared/api/generated/` を修正後のサーバーから再生成し、`src/dev_docs/screen/assets/` を再ビルドする |
| 文言を共有する設計書 | 修正する文言・説明と同じ文を持つインターフェース定義の項目の `description` と、モジュール構成の `summary`・`title`・`message` |
| 文言を照合するテスト | 修正するサーバーの文言を照合する単体・結合テスト（照合が無い文言は、照合を追加する） |

終わりの条件は、上の範囲で対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が 0 件になること。
置き換え先は対応表の `ok` の単語にし、PR #105 で画面の文言に決めた置き換え（`既に使用されています`・`読み込める`・`再読み込み`・`除外した理由`）と統一する。
対応表の置き換え先では名称が決まらず、対応表に無い単語で画面の名称を新しく決める箇所は、規約『ユーザー確認が必須な事項』の「ユーザーの目に触れる語彙を決める」に当たるため、ユーザーへ確認する。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| MCP の応答だけが返すエラー・ヒントの文言（`features/access/service.py`・`features/search/filters.py`・`features/view/nav.py` など） | 画面に表示しない文言で、Issue #107 の範囲（画面が表示する文言）に入らない | [#117](https://github.com/shuhei1101/dev-docs/issues/117) |
| ログの文言（`配信元を読み直した（…外した数…）` など） | 画面にも MCP の応答にも出ない | 予定なし |
| 設計書の地の文（`外した理由`・`読めるバージョン` などを使う説明・シナリオ・リファレンス） | `docs/`・`dev/` の文書の修正は #95 の範囲。本 PR は修正する文言と同じ文を持つ項目だけを修正する | [#95](https://github.com/shuhei1101/dev-docs/issues/95) |
| `src/dev_docs/` の docstring・コメントのうち、OpenAPI の説明にならないもの | 画面にも生成物にも出ない | 予定なし |
| `tests/integration/server/test_write_docs.py` の `test_normal_when_tool_description` が develop でも fail する | PR #105 の `write-docs.yaml` の文言の修正に結合テストの期待値が追随していない不具合で、今回の要望（画面が表示するサーバーの文言）に含まれない | [#113](https://github.com/shuhei1101/dev-docs/issues/113) |
