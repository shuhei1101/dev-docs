## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| リンク先の決め方 | 配信元の設定に記載した話し合いの記録のフォルダで ID が 1 つに決まる検討事項の文書を、dev-docs の画面の URL へのリンクにする | [要件](./要件.md) の案 C（確認ログで確定） |
| `decisions` の描画 | `decisions` の要素を、リンク先が決まればリンク、決まらなければ ID の文字のまま出す。表のセル・箇条書きで同じ出し方にする | 他の文字列の並びの出し方は変えない |
| 描画の文脈 | 話し合いの記録のフォルダで 1 つに決まる検討事項のリンク先を `RenderContext` に持たせ、変換の呼び出し元が指定する | - |
| 検討事項の文書の画面 | 話し合いの記録のフォルダの `.mindstella/docs/{ID}.md` を、dev-docs の画面の URL で描く | 配信の範囲の外のファイルを参照する経路 |
