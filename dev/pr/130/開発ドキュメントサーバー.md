## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| リンク先の決め方 | 検討事項の ID から、話し合いの記録の検討事項の文書のリンク先を決める | `未確定`（[要件](./要件.md)。決める工程: インターフェース定義設計） |
| `decisions` の描画 | `decisions` の要素を、リンク先が決まればリンク、決まらなければ ID の文字のまま出す。表のセル・項目の属性・箇条書きで同じ出し方にする | 他の文字列の並びの出し方は変えない |
| 描画の文脈 | 話し合いの記録のフォルダで 1 つに決まる検討事項のリンク先を `RenderContext` に持たせ、変換の呼び出し元が指定する | - |
| 検討事項の文書の画面 | 話し合いの記録のフォルダの `.mindstella/docs/{ID}.md` を、dev-docs の画面の URL で描く | 配信の範囲の外のファイルを参照する経路。`未確定`（[要件](./要件.md)） |
