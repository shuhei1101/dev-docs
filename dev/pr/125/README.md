# dev-docs のサーバーの再起動の反映作業で、新しいサーバーの待ち受けと配信元の読み込みの終わりを待ってから確認する

## 概要

反映作業『dev-docs のサーバーの再起動』のスクリプトが、新しいサーバーの待ち受けと配信元の読み込みの終わりを十分な上限まで待ってから確認するようにし、以後の再起動の反映作業で同じ失敗を繰り返さないようにする。

## 背景

[#124](https://github.com/shuhei1101/dev-docs/issues/124) の要望。
[PR #120](https://github.com/shuhei1101/dev-docs/pull/120) の反映作業『dev-docs のサーバーの再起動』を回したところ（[#119 の報告](https://github.com/shuhei1101/dev-docs/issues/119#issuecomment-6712107443)）、実行スクリプトは新しいサーバーの待ち受けまでの約 78 秒を 60 秒の上限で待ちきれず、確認スクリプトは起動後の配信元の読み込み（約 6 分。[#123](https://github.com/shuhei1101/dev-docs/issues/123)）の間に件数の検索を送って 85 秒で打ち切られた。
読み込みが終わった後の同じ検索は 13.4 秒・3.1 秒で応答し、#120 の修正そのものは効いている。
