## 要望

次の範囲の文言を、knowledge の AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`）に合わせて修正する。

| Issue | 範囲 | 終わりの条件 |
| --- | --- | --- |
| [#139](https://github.com/shuhei1101/dev-docs/issues/139) | `src/dev_docs/` の `Field` の `description`（MCP のツールの入力スキーマと、`POST /_admin/session-start` の応答の説明）と、ツールの説明（`content/prompts/mcp/**/tools/*.yaml`） | `src/dev_docs/` の `Field` の `description` のうち、対応表の `pattern` にヒットするもの全てを修正し、置き換えを PR #133 と統一する。ツールの説明と instructions（`content/prompts/mcp/**`）を含めるか別の Issue にするかを、着手の前に決める |
| [#140](https://github.com/shuhei1101/dev-docs/issues/140) | CLI のヘルプ（`__main__.py`）・エラー（`features/migrate/service.py`）・移し替えの手順の説明（`migrations/**/steps.yaml`。`--plan` と破壊的な手順のエラーに出る）と、`prompt-doc` が生成する文書の文言（`features/prompt_doc/markdown.py`） | CLI だけが出す文言と、`prompt-doc` が生成する文書の文言のうち、対応表の `pattern` にヒットするもの全てを修正し、置き換えを PR #133 と統一する |
| 両方 | 修正する文言と同じ文を持つインターフェース定義・モジュール構成・単一ユースケースのシナリオの項目と、修正する文言を照合する単体・結合・E2E テスト | 上の範囲の修正に合わせる |

ツールの説明は、`Field` の `description` と同じくエージェントへ入力スキーマとともに表示されるため、この PR に含める。
instructions（`content/prompts/mcp/docs/instructions.yaml`）は対応表の `pattern` にヒットする文言を持たない（`探す` は対応表に無い）ため、修正しない。

終わりの条件は、上の範囲で対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が 0 件になること。
置き換え先は対応表の `ok` の単語にし、PR #133 で決めた置き換え（`読み込む`・`参照する`・`返却する`・`指定する`・`該当する`・`適用する`・`使用する`・`記載する`・`除外する`・`削除する`・`配置する`・`単語`）と統一する。
`出どころ` は対応表の `ok` の `出典` にする。

箇所ごとの修正前後は次のとおり（`src/dev_docs/` からのパス。`content/` と `migrations/` はリポジトリの直下からのパス）。
