## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の削除のエンドポイント | `cwd` を受けず、`session_id`・`agent_id`・`reason` を受けて、`reason` が `clear`・`compact` なら `seen.forget` を呼び、削除したかだけを返す。画面の API のスキーマに載せない | `POST /_admin/session-start`（設計書『セッションの開始』。『セッションの文脈』を改名する） |
| 文の描画 | `_render`・`_context_text`・`CONTEXT_MAX_CHARS`・`SESSION_CONTEXT_PROMPT_ID` と `session-context.yaml` を削除する | |
| 警告 | `_collect_warnings` を `describe` の側へ移し、引数なしの応答の markdown・json の両方に載せる | `describe` は読み込みを待って答えるため、読み込み中の案内は持たない |
| instructions | 「使える配信元は、引数なしの `describe()` の一覧にあります。」に修正し、設計書から調査する案内と `outside_scope` の案内を追加する。4,096 字以内に収める | |
| 既存機能への影響 | `describe` の `source`・`kind` を渡したときの応答は変えない | |
