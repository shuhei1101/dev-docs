## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 待ち受けているとき | 文脈を取得せず、`additionalContext` を出力しない | |
| `/clear`・圧縮 | `source` が `clear`・`compact` のときだけ、`POST /_admin/session-start` を呼ぶ | `startup`・`resume`・`fork` では HTTP の要求を送信しない |
| 記録の削除の失敗 | 理由と `repeat_seen: true` で取り直せる案内を `additionalContext` に入れ、終了コード 0 で戻る | |
| 落ちているとき | 起動・起動できないときの通知・`/mcp` の再接続の案内は今と同じ | |
| 打ち切りの秒数 | `FORGET_TIMEOUT_SEC` を仮に 3 秒、`hooks.json` の `timeout` を 6 秒にする | 実装の後に応答の時間を測って決め直す |
| 前のバージョンのフック | 互換のエンドポイントを残さず、反映作業でサーバーの再起動と同じ時期にプラグインを更新する | 更新するまで、前のフックは文脈を取れなかった案内を出す |
