## 色の役割

<!-- table: data -->

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |

| 面 | トップバー・本文の外のコード・補足の文字 | `--topbar` / `--code` / `--muted` / `--muted-foreground` | - |
| 線 | 区切り・入力欄の枠 | `--border` / `--input` | - |

| 状態色 | 削除・エラー | `--destructive` | - |
| 差分 | 差分の追加・変更 | `--added` / `--changed` | - |
| 強調 | 検索の一致 | `--highlight` | - |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し（本文の外） | 端末のサンセリフ | 太さ 600。`--text-title` / `--text-h2` |
| 文書のタイトル | mdmark の見出し 1 と同じ | 大きさ・太さは mdmark の値（`text-doc-title`・`font-doc-title`）。下に区切り線 |
| 本文（mdmark が描く範囲） | mdmark の書体 | 画面の文字・色のトークンと Tailwind の Preflight を当てず、単独の mdmark と同じ見た目にする |
| 操作・本文の外の文章と表 | 端末のサンセリフ | `--text-body` / `--text-control` / `--text-table` |
| 入力欄 | 端末のサンセリフ | `--text-input`。スマホで入力時に拡大されない 16px |
| 補足（パンくず・文書の情報） | 端末のサンセリフ | `--text-meta` |
| 本文の外のコード・パス・ID | 等幅 | `--font-mono` / `--text-code` |

## 形状と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| ボタン・入力欄 | 小さめの角丸と線 | `--radius` は 0.375rem。影なし |
| 本文の外の表・カード | 線で区切る | 影なし |
| 本文（mdmark が描く範囲）の見出し・表 | mdmark の値 | 単独の mdmark と同じ |
| メニュー・ダイアログ | 影で浮かせる | `--shadow-popover` |
| バッジ | ピル形の角丸と線 | - |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| ボタン・メニューの項目のホバー | 背景色だけを変える | - |
| メニュー・ダイアログの開閉 | 動きを付けずに出す | - |

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| グラデーション・光る影 | 開発ツールと並べて読む落ち着きとぶつかる | - |
| 2 色目の差し色 | 色は差し色の青と状態色・差分の色だけに使う | - |
| Web フォント | 端末の書体で、読み込みを待たずに出す | - |
