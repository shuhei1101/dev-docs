## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| project-index の呼び出し | 文書の一覧から `excluded` を、検索から `excludedCount`・`excluded` を型に取り込み、検索に `include_excluded` を渡せるようにする | 項目が無い応答は空・`false`・0 として扱う |
| メタデータの取得・編集中の変更の直コミット | #321 の扱いが決まってから決める | `未確定`（[要件](./要件.mark.md) の #321 の扱い。決める工程: 承認確認） |
| 文書の取得 | サイドバーの文書の項目に `excluded` を加える | - |
| 画面の検索 | `include_excluded` を受けて project-index へ渡し、応答に `excludedCount` と各結果の `excluded` を加える | 既定は除外したまま |
