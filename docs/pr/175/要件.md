# 要件

## 要望

`frontend/src/`（`shared/api/generated/` の生成コードを除く）のコード内のコメント（docstring・インラインコメント・CSS のコメント）と開発者向けの例外の文言を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)に合わせて修正する。

終わりの条件は、対象のコメントと例外の文言に対応表の `pattern` を当てたヒット（`allow` に当たるものを除く）が 0 件で、lint・型検査・単体テストが全て pass すること。

[#88](https://github.com/shuhei1101/dev-docs/issues/88)（作業 PR [#174](https://github.com/shuhei1101/dev-docs/pull/174)）は `use-active-heading.ts` などを削除する。
#174 が先にマージされた場合、base を取り込んで削除されたファイルを対象から外す。
