## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| Mermaid の `click` の参照の解決 | `render_mermaid` が読み取れない図を Mermaid のまま返却するとき、`click {ノード} href "id:{ID}#{項目のパス}"` と `click {ノード} "id:{ID}#{項目のパス}"` の参照を、`inline.py` の参照の解決（`_target`）で同じ配信元の文書のページの URL にする。どの文書の ID にも該当しない参照は書き換えない | ノードをリンクにするのは mdmark#570 の対応（[要件](./要件.md)） |
| 移し替えの送信するキー | `_sent_row` が行の外部の読み取りを `outside_read` で送信する。ほかの送信するキー（`id`・`config`・`enabled`・`scope`）は変えない | - |
| 外部 API の設計書 | `API-155-1` の `PUT /settings/sources` の行のキーを、本物の project-index（develop の `7177d39` 以降）の `outside_read` に合わせ、`GET` の応答の `outsideRead` と区別して記載する | - |
| 移し替えのテスト | 単体テストの `SEND_KEYS` と偽物の project-index の `_saved_row` を `outside_read` にする。移し替えの保存を本物の project-index に対する結合テストで確認する | 結合テストで起動する本物の project-index（`tests/integration/server/conftest.py` の `PROJECT_INDEX_COMMIT`。今は `f36ba69`）を、保存の `expectedVersion` を受け付ける `7177d39` 以降へ上げる |
| 反映作業「端末の設定の移し替え」 | #183 の作業をこの作業 PR の反映作業に移し、疎通確認と実行の前提確認で、稼働中の project-index のサーバーが `PUT /settings/sources` の `expectedVersion` を受け付けるバージョンかを確認する | 受け付けないときの扱いは `未確定`（[要件](./要件.md)） |
| 反映作業「dev-docs のサーバーの再起動」 | #183 の作業をこの作業 PR の反映作業に移す。#196 の変換の変更も、この起動し直しで稼働中のサーバーで有効にする | - |
