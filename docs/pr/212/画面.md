## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| mdmark のバージョン | `use-mdmark.ts` の jsDelivr のタグを、mdmark#550（`v0.13.0` に入った）と mdmark#570 を含むタグへ上げる | `package.json` の `devDependencies` の mdmark も同じタグへ上げる。タグは mdmark#570 を含むタグが打たれた後に実装で決める |

| Mermaid の図のノードのリンク | 文書の画面で、`click` の参照を持つ Mermaid の図のノードから、参照が指す文書のページへ移れることを結合テストで確認する | ノードをリンクにするのは mdmark#570 の対応。mdmark#570 を含むタグを読み込む（[要件](./要件.md)） |
