## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本物の project-index の固定 | `conftest.py` に `matchCount` を返却する commit（develop の `2588d67`）の定数と、その commit のクローンを用意するフィクスチャを加える | ほかのテストの `PROJECT_INDEX_COMMIT` は変えない |
| 一致した行の数の結合テスト | 一致する行の数が文書ごとに違う配信元を本物の project-index で配信し、画面の検索の `items[].matchCount` が文書ごとの一致した行の数になることを確かめる | `matchCount` を持たない応答で `null` になるケースは固定の応答のテストで保つ |
| 外部 API の設計書 | `GET /sources/{source}/search` の行の未リリースの記載を、`2588d67` と照合した `matchCount` の意味に書き換え、`verification` に照合した commit と結合テストのログを追記し、`version` を照合した commit にする | - |
| 食い違いの修正 | 照合で食い違いが見つかったら、IF-155-16・モジュール構成から直し、単体テスト・実装を合わせる | 食い違いがあればタスク一覧の該当する設計の工程を `todo` へ戻す |
