# 要件

## 要望

設定画面のダイアログを開いたストーリーで、`detect_screen_issues`（`target: story`。1280x800・390x844）の `layout-transition` の検出を 0 件にする。

- `transition: height` を出している要素とスタイル（自前のクラス・依存の `@base-ui/react`・`tw-animate-css`・Storybook の側のどれか）を特定し、計画書の `## 実装` に記載する
- 出典が自前のコードか上書きできるスタイルなら、規約『表示の安定』に沿って高さの遷移を止める
- 上書きできない場合は、検出の対象から外す理由を出典の部品のモジュール構成の設計書へ記載する
