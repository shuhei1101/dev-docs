## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出典の特定 | ダイアログを開いたストーリーを配信し、ダイアログの中の要素と読み込まれたスタイルシートから `transition-property` に `height` を含むもの（`all` を含む）を引く | 特定した要素・スタイル・ファイルを `## 実装` に記載する |
| 解消 | 出典のクラスかスタイルを、高さを動かさない指定（`transition-colors` 等の対象を絞った指定）へ直す | 依存のスタイルは、共有の部品の側でクラスを上書きする |
| 解消できない場合 | 検出の対象から外す理由を出典の部品のモジュール構成の設計書へ記載する | タスク一覧の `ドキュメント修正` で行う |
| 確認 | 直した後、同じストーリーを `detect_screen_issues`（`target: story`。1280x800・390x844）にかけて `layout-transition` が 0 件であることを確かめる | 他の検出が増えていないことも確かめる |

## 実装

| 項目 | 内容 |
| --- | --- |
| 特定した出典 | sonner（2.0.8）が読み込み時に `<head>` へ差し込む `<style>` の `[data-sonner-toast] { transition: transform 0.4s, opacity 0.4s, height 0.4s, box-shadow 0.2s }`。ストーリーの全てのスタイルシートで、`transition` に `height` を含む記述はこの 1 つだけだった。ダイアログ（`dialog-overlay`・`dialog-content`）の `transition-property` は既定の `all` だが、`height` の記述は持たない |
| 対象の要素が付かない理由 | ストーリーにトーストの要素は描かれず、検出は差し込まれた記述から出ている。設定画面は `queries.ts` で sonner を読み込むため、ダイアログを開いたストーリーで出る。同じストーリーでも出る回と出ない回がある |
| 直したこと | `frontend/src/index.css` で、詳細度の高い `[data-sonner-toaster] [data-sonner-toast]` の `transition` を `transform 400ms, opacity 400ms, box-shadow 200ms` に上書きし、高さの遷移を除外した。上書きの後、トーストの要素の `transition-property` が `transform, opacity, box-shadow` になることを確かめた |
| 検出を除外する理由 | sonner は差し込みを止める設定を持たず、上書きの後も差し込まれた記述は残るため、検出は消えない（上書きの後も `detect_screen_issues` で EditOutsideRead などに出る回がある）。高さは上書きで動かないため、この検出を対象から除外する理由を [sonner](../../library/LIB-155-19.yaml) の制限事項に記載した |
| 引けなかったガイド | なし（UI の型を足していないため `search_web_guidance` は引いていない） |
| 足した・直したストーリー | なし（部品を足しも変えもしていない） |
