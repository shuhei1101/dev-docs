## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ノードの高さ | mdmark の `labelLineCount`・`isWide` と同じ式で、名前の行数から高さを決める | `NODE_HEIGHT` は最小の高さにする |
| ランクを飛ばす線 | 間のランクごとに幅 0 の通り道を置き、ノードを横切らない経路にする | ai-monitor の `MOD-3044-215` の `layout_flow` に合わせる |
| 戻る線 | 元のノードの入口の辺から出て先のノードの出口の辺へ入る経路にし、`LOOP_BAND` を削除する | 元と先が同じ線は `ROW_GAP` の半分の輪 |
| 枠の外のノード | 全てのランクの枠の中のノードの最も遠い端より先に並べる | - |
| 入出力の形 | `layout_flow` の引数と返す値のキーは変えない | 呼び出し元 `diagrams.py` は変えない |
| ずれの確かめ方 | 文書の取得の結合テストで、返った Markdown を `mdmark check --text -` にかけ、フロー図の検査の 5 種（`diagram_invalid`・`diagram_node_overlap`・`diagram_node_overflow`・`diagram_wire_crosses_node`・`diagram_label_too_long`）が 0 件になることを確かめる | mdmark は `devDependencies` に v0.10.0 で固定する |
