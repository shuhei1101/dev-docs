# 要件

## 要望

`src/dev_docs/features/convert/flow_layout.py` の `layout_flow` が返すフロー図の定義を、mdmark の定義の検査（`mdmark check`）で `diagram_wire_crosses_node`・`diagram_label_too_long`・`diagram_node_overflow` が 0 件になる配置へ修正する。
配置は ai-monitor#3356 のモジュール構成 `docs/module/MOD-3044-215.py.yaml` の `layout_flow` に合わせる。

- ランクを 2 つ以上飛ばす線と戻る線に、間のランクごとに幅 0 の通り道を置き、横切る区間はランクの間の隙間だけを通す
- 戻る線は元のノードの入口の辺から出て、先のノードの出口の辺へ入る（戻りの帯 `LOOP_BAND` を使わない）。元と先が同じ線は `ROW_GAP` の半分の輪にする
- ノードの高さを、mdmark の文字の収まりの判定（`labelLineCount`・`isWide`）と同じ式で名前に合わせて決める（固定の `NODE_HEIGHT` をやめる）
- 枠の外のノードを、全てのランクの枠の中のノードの最も遠い端より先に並べる

`layout_flow` の引数と返す値の形（`title`・`scope`・`updated`・`width`・`height`・`frame`・`nodes`・`wires`）は変えない。

ずれが 0 件になることは、mdmark を `package.json` の `devDependencies` に `github:shuhei1101/mdmark#v0.10.0` で固定し、文書の取得の結合テストで返った Markdown を `mdmark check --text -` にかけて確かめる（ai-monitor#3356 と同じ）。
