# 要件

## 要望

`item_heading` が項目のパスを段に分けるとき、`[...]` の中の `[` と `]` の対応を数え、最も外側の `[` からそれに対応する `]` までを 1 つの `[{値}]` として読む。

- `request[operations[].fields]` は、`request` の `x-key` の値が `operations[].fields` の要素を指し、見出しは `operations[].fields`
- `[` を閉じない・対応する `[` の無い `]` を含む項目のパスは、見出しにならない（`None`）
- `[` `]` を含まない今の項目のパス（`flow`・`scenarios[正常シナリオ]`）の見出しは変わらない
