## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 項目のパスの分解 | `ITEM_STEP` の正規表現を、先頭から 1 文字ずつ `[` と `]` の対応を数えて段に分ける処理に置き換える。`[]` の外の `.` で名前を区切り、最も外側の `[` から対応する `]` までを 1 つの `[{値}]` にする | `[` `]` の対応の数え方は [shuhei1101/project-index#169](https://github.com/shuhei1101/project-index/pull/169) の `resolve_ref_path` と同じ。`[{値}]` の直後は `.` か末尾だけを受け付け、`resolve_ref_path` が受け付ける `[a][b]` は `None` にする |
| 対応の取れないパス | `[` を閉じない・対応する `[` の無い `]` を含む項目のパスは `None` を返却する | 例外は送出しない（今の `item_heading` が解けないパスを `None` で返すのに揃える） |
| 既存機能への影響 | `[` `]` を含まない項目のパスの見出しは変わらない | 既存の `test_item_heading` 系の 3 件で確認する |
