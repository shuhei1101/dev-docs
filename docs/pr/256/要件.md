# 要件

## 要望

AI Monitor の配布物を v0.3.0 から v0.4.0 へ追従する。
完了の条件は次のとおり。

- `ai-monitor-version.ini` の先頭行が `v0.4.0` になっている
- `project-index.yaml` の設計書の種別の行（`architecture`・`nonfunctional`・`scenario`・`interface`・`module`・`screen`・`component`・`config`・`api`・`library`・`test_procedure`・`dev_command`・`index`）と管理用の YAML の行（`files_root`・`files_guide`・`files_mock`）の `schema` が、knowledge のスキーマの参照（`source: knowledge`・`path`・`ref: design-schemas/v8.1.0`）を指している。指す `path` は反映作業『各プロジェクトのスキーマの参照への移行』の `common.py` の `COPIES` の対応に従う
- `schemas/` に AI Monitor から配られたスキーマのコピー（設計書の種別のスキーマ・`common.schema.yaml`・`files.schema.yaml`・`phase.schema.yaml`）と、設計書の変換（`conversions/`）が無い
- `docs/architecture/ARCH-155-1.yaml` に `line: reply` が無い
- dev-docs の全ての設計書が、knowledge のスキーマの参照で project-index の検査に合格する（`describe()` の dev-docs の配信元に警告が出ない）
- `pyproject.toml` の lint・型検査の除外に、削除した `schemas/conversions` を指す行が無い
- v0.3.0..v0.4.0 で変わった規約・判定フローチャート・チェックシート・テンプレートのうち、dev-docs の成果物が従っていない箇所が無い（改めて参照して見つけた箇所は、この PR で修正するかスコープ外へ回す）
- `反映作業/index.yaml` の配布先の反映作業が全て済になっている

`line: reply` は、AI Monitor の変換（`python -m ai_monitor.design_docs convert --from v0.3.0 --to v0.4.0`）を実行せず、2 つの行を手で削除する。
v0.4.0 の変換は dev-docs では `ARCH-155-1.yaml` の 2 つの行だけを対象にし（[#161](https://github.com/shuhei1101/dev-docs/issues/161) の背景）、実行すると `docs/module/` の ID 名の設計書を物理ファイルのパス名へ改名する（[shuhei1101/ai-monitor#3357](https://github.com/shuhei1101/ai-monitor/issues/3357)。open）。

反映作業『各プロジェクトのスキーマの参照への移行』の実行スクリプトは配信元の設定を `dev-docs.yaml` に決め打ちしており、`project-index.yaml` の dev-docs では前提確認で止まる（[shuhei1101/ai-monitor#3472](https://github.com/shuhei1101/ai-monitor/issues/3472)。open）。
この PR では、同じ書き換え（`common.py` の `rewrite`・`copies`）を `project-index.yaml` と `schemas/` に当て、確認スクリプトと同じ観点（設計書の種別の行がコピーを指さず、コピーが無い）で結果を確認する。
