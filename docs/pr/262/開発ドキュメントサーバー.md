### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 使用できる項目 | `DocumentRow` に行の `metadata`（共通のキー → 列名）を持たせ、nav の `auto.filter` の使用できる項目に、そのキーを対応付けた列の型（列がスキーマに無ければ `string`）で加える。条件の照合では、`METADATA_KEYS` に無いキーの値を `data` の対応付けた列から取得する | 原因: `row.schema`（`records` の 1 要素のスキーマ）にも `METADATA_KEYS` にも `category` が無く、`check_filter` が知らない項目としてタブを空にしていた（observability の `files_guide` の応答で確認）。project-index の検査も同じ条件で「知らない項目です（category）」を返すため、project-index 側はスコープ外へ回す |
| 共通のキー | `METADATA_KEYS` を project-index の `METADATA_KEYS` に統一する（`visibility` を追加する） | `get_field` など `METADATA_KEYS` を参照する他の箇所の振る舞いも確認する |
| 単体テスト | `metadata` で `category` を対応付けた行と `auto.filter` の `category` の条件で、タブに文書が並ぶことを確認する | - |
