# フロー図の click の id: のリンクを、mdmark のフロー図のノードのリンクにする

## 概要

利用者が文書の画面でフロー図のノードを押すと、`click` の `id:{文書の ID}#{項目のパス}` が指す同じ配信元の文書（とその項目）を開けるようになる。

## 背景

[#98](https://github.com/shuhei1101/dev-docs/issues/98) の要望。[#97](https://github.com/shuhei1101/dev-docs/issues/97) で本文の `id:` のリンクを解決したが、フロー図の `click` はリンクにならないため切り出された。

develop では、`x-diagram` の flow 系の値の `clicks` を描かず、手で記載する Mermaid のフローチャートは `click` の `id:` を解かないまま mdmark の map の範囲へ指定している。
mdmark は `id:` のスキームを許可しないリンク先として捨てるため、どちらもノードを押しても開けない。
