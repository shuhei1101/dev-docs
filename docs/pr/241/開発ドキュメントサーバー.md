## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `x-diagram` の flow 系の `clicks` | `clicks[]` ごとに、`id` のノードへ `click {Mermaid のノードの ID} "{リンク先}"` の行を出す。`href` が `id:` ならリンク先を `_target` で解決する | `nodes` にも `edges` の端にも無いノードを指す要素は `click` の行を出さない（図に無いノードを `click` のためだけに増やさない） |
| 手で記載する Mermaid のフローチャート | map の範囲に入れる前に、`click` の行の `id:` を `_target` で解決したリンク先へ書き換える | map の範囲に入れるシーケンス図・ER 図・状態遷移図は `click` を持たないため対象にしない |
| リンク先の解決 | #97 の `_target`（同じ配信元の文書への相対パスと項目の見出しのアンカー）を使用する。該当しない `id:` の `click` の行・`clicks` の要素は出さない（mdmark は `id:` のリンク先に書き方の警告を出すため） | #212 の `_link_clicks` が先に develop へ入れば、それを使用する |
| 画面 | 変えない。mdmark がノードのリンクを `a` 要素で描き、文書の画面の本文の相対パスのリンクの処理で同じ配信元の文書へ移る | - |
| mdmark | バージョンを変えない（v0.13.0 がノードのリンクを持つ） | - |
