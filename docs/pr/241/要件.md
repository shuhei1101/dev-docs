# 要件

## 要望

文書の画面の変換で、フロー図のノードの `click` のリンク先の `id:{文書の ID}`・`id:{文書の ID}#{項目のパス}` を、#97 と同じ解決（同じ配信元の文書への相対パスと、項目の見出しのアンカー）でリンク先にし、mdmark のフロー図のノードのリンクとして描く。

| 対象 | 完了の条件 |
| --- | --- |
| `x-diagram` の flow 系（`flowchart`・`dataflow`・`architecture`）の値の `clicks` | `clicks[]` の `id` のノードに `href` のリンクが付き、ノードを押すとリンク先の文書（項目があればその見出し）を開く |
| 手で記載する Mermaid のフローチャート（mdmark の map の範囲に入れる図）の `click {ノード} "id:…"`・`click {ノード} href "id:…"` | 同上 |
| どの文書の ID にも該当しない `id:` | 書き換えずに mdmark へ指定する（#97 の本文のリンクと同じ） |

mdmark#310（フロー図のノードのリンク先）は mdmark v0.10.0 から入っており、develop が固定する v0.13.0 で map のフローチャートが `click` をノードのリンクとして解釈する。mdmark のバージョンは上げない。

[#212](https://github.com/shuhei1101/dev-docs/pull/212)（#196）が、読み取れずコードブロックのまま出す Mermaid の `click` の `id:` を解く処理を入れる。#212 が先に develop へ入れば、その処理をフローチャートにも使用する。
