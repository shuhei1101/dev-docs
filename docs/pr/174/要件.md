# 要件

## 要望

文書の画面の独自の目次を削除し、mdmark が描く右側の目次（`.mdmark-side-toc`）だけを出す。

| 対象 | 修正後 |
| --- | --- |
| 目次（`DocToc`） | 削除する。文書の画面の右の列に独自の目次を置かない |
| 目次の変更のマーカー（`changedSections`） | 削除する。比較元からの変更箇所は、#44 でつないだ mdmark の差分の強調で示す |
| 目次のための処理（`toc.ts`・`use-active-heading.ts`・本文から見出しを返す `onHeadings`） | 使用する箇所が無くなるものを削除する |
| 比較元の本文の取得（`baseMarkdownQueryOptions`） | 残す（本文の差分の強調が使用する） |

目次の変更のマーカーは、mdmark の右側の目次に代わりが無いまま削除する（画面設計で決定）。
mdmark の右側の目次は変更のあった見出しにマーカーを出す機能を持たず（画面が読む mdmark の master の `src/interact/side-toc.ts`）、`baseMarkdown` だけを指定したときは本文の変わったブロックを色分けするだけで、差分のミニマップは出ない（ミニマップは `diffSource` の差分の表示の中だけ）。
長い文書で変わったセクションを探せるよう、右側の目次に変更のマーカーを出す機能を [mdmark#518](https://github.com/shuhei1101/mdmark/issues/518) へ起票した。
