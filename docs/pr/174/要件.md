# 要件

## 要望

文書の画面の独自の目次を削除し、mdmark が描く右側の目次（`.mdmark-side-toc`）だけを出す。

| 対象 | 修正後 |
| --- | --- |
| 目次（`DocToc`） | 削除する。文書の画面の右の列に独自の目次を置かない |
| 目次の変更のマーカー（`changedSections`） | 削除する。比較元からの変更箇所は、#44 でつないだ mdmark の差分の強調で示す |
| 目次のための処理（`toc.ts`・`use-active-heading.ts`・本文から見出しを返す `onHeadings`） | 使用する箇所が無くなるものを削除する |
| 比較元の本文の取得（`baseMarkdownQueryOptions`） | 残す（本文の差分の強調が使用する） |

`未確定`: 目次の変更のマーカーの代わり（決める段: 画面設計）

mdmark の右側の目次は、変更のあった見出しにマーカーを出す機能を持たない（画面が読む mdmark の master の `src/interact/side-toc.ts`）。
mdmark の差分は、本文の変わったブロックの強調と、ページの右端の差分のミニマップで示す。

| 案 | 内容 |
| --- | --- |
| A | mdmark の差分の強調とミニマップで代わりになるとし、目次のマーカーを削除する |
| B | 目次のマーカーを削除し、mdmark へ右側の目次に変更のあった見出しのマーカーを出す Issue を起票する |

推奨: A

ミニマップが文書のどこが変わったかを示し、本文の強調がどう変わったかを示すため、見出しのマーカーが無くても変更箇所へ移れる。
