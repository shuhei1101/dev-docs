## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の画面の右の列 | `DocToc` を置いていた列を削除し、本文の幅を広げる。目次は mdmark が本文に描く右側の目次だけにする | 本文の最大幅は画面設計で決める |
| 目次の変更のマーカー | 削除する | mdmark の右側の目次のマーカーは [mdmark#518](https://github.com/shuhei1101/mdmark/issues/518) |
| 見出しの受け渡し | `doc-body.tsx`・`doc-main.tsx` の `onHeadings` と、`doc-view-screen.tsx` の `headings` の状態を削除する | - |
| `toc.ts`・`doc-toc.tsx`・`use-active-heading.ts` | ファイルごと削除し、対応するモジュール構成と単体テストも削除する | - |
| `baseMarkdownQueryOptions` | 残し、説明から目次の変更のマーカーを外す | 本文の差分の強調が使用する |
| 結合テスト | `目次`・`目次の変更のマーカー` の describe を、mdmark の右側の目次が 1 つだけ出ることを確かめる内容に置き換える | - |
| 画面のビルド | `src/dev_docs/screen/assets/` を作り直す | - |
