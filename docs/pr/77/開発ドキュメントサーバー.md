## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 準備 | スキーマを `records_files_schema("owner", "string")` で作り、要素を `{path: a.md, owner: alice}`・`{path: b.md, owner: bob}` にする | `load_yaml` で読み込んで `schemas` に渡す |
| 条件 | `Condition(field="owner", op="eq", values=["alice"])` | nav の `OWNER_FILTER` と同じ項目 |
| 期待値 | `total_count` が 1、`items` の ID が `notes/a`、`notes` が空 | 今と同じ |
| 失敗の確認 | 行のスキーマとしてファイル全体のスキーマを渡す実装（項目が `files.owner` になる）で `InvalidArgumentError` になり失敗することを、手元で確かめて完了報告に書く | 実装は変えない |
| モジュール構成のテストの行 | 条件を、要素 `{path: a.md, owner: alice}`・`{path: b.md, owner: bob}`、要素のスキーマに `owner` を追加、`filter` が `owner = alice` に、期待値を `a.md` の要素 1 件にする | 書くツールの `replace` |
