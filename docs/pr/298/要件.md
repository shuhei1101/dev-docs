### #294 の要件

mdmark は、文書の全ての見出しに見出しの文字から作った ID を付け、同じ ID が 2 つ目以降に出たら `-1`・`-2` を付ける（mdmark の `src/render/syntax/headings.ts` の `slugify`）。
連番のアンカーがあるため、mdmark への起票は要らない。

- 本文の `[名前](id:{ID}#{項目のパス})`・参照のリンク・Mermaid の `click` の `id:` のリンクが、指す見出しのアンカーへ飛ぶ。アンカーは、リンク先の文書の変換した Markdown の中で、指す見出しより前にある同じ ID の見出しの数を `n` として、`n` が 0 なら `{見出しの ID}`、1 以上なら `{見出しの ID}-{n}` にする
- 数える見出しは、指す見出しと同じ項目の並びの要素に限らない（別の項目の見出しが同じ文字なら数に入る）
- 1 つ目の見出しを指すリンクのアンカーと、見出しにならない項目のパスのリンク（アンカーを付けない）は変わらない

`未確定`: 指す見出しより前にある同じ ID の見出しの数え方（決める工程: モジュール構成設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | リンク先の文書をスキーマ駆動の変換にかけた Markdown の見出しを、mdmark と同じ規則で前から数える | 変換が出す全ての見出し（先頭の `#`・`x-heading`・`sections`・タブの見出し）を漏れなく数えられる | リンク先の文書ごとに変換を 1 回実行する |
| B | `item_heading` が値とスキーマをたどるときに、変換が見出しを出す順を再現して数える | 変換を実行しない | 変換の見出しの出し方を 2 か所に持ち、片方だけ変わると数がずれる |

推奨: A

変換の見出しの出し方を 1 か所に保てて、数がずれない。

### #295 の要件

- 名前のステップ（`{キー}`）: 進んだ先の値が空（変換の `_is_empty`）か、キーのスキーマが `x-hidden: true` なら `None` を返却する
- 辞書の `[{キー}]` のステップ: 進んだ先の値が空か、子のスキーマが `x-hidden: true` なら `None` を返却する
- 途中のステップで該当した場合も、最後のステップで該当した場合も `None` にする（変換は飛ばした項目の中の見出しも出さない）
