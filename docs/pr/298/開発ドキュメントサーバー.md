## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 見出しを出さない子 | `item_heading` の名前のステップと辞書の `[{キー}]` のステップで、進んだ先の値が `_is_empty`、またはスキーマが `_is_hidden` なら `None` を返却する | 変換の `_Builder.object`・`_Builder.sections` が飛ばす条件と同じ関数を使用する |
| 同じ見出しの 2 つ目以降のアンカー | リンク先の文書の変換した Markdown で、指す見出しより前にある同じ ID の見出しの数 `n` を求め、1 以上ならアンカーを `{見出しの ID}-{n}` にする | 変換と同じ組み立てで、見出しを配置した組み立てのパスごとのアンカーの一覧（`heading_anchors`）を作り、`item_heading` が返却する組み立てのパスで引く。描画の文脈の `item_heading` を `item_anchor` にする |
| 既存機能への影響 | 1 つ目の見出しを指すリンクのアンカーと、見出しにならない項目のパスの扱いは変わらない | 既存の `test_item_heading` 系・`test_link_target`・`test_rewrite_text_when_id_link` 系で確認する |
