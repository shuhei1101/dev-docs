## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| インターフェース定義 | `docs/interface/` に `entry.kind: trigger` の設計書を新規に作り、`pages.yml` の起動の条件・権限・同時実行・job と step の流れ・タイムアウトを、IF-155-26 と同じ書式で記載する | `deploy` を通る正常系の起動のしかたは `未確定`（[要件](./要件.md)） |
| step の名前 | フローの図の step と E2E テストの突き合わせは workflow の step の `name` で行うため、`name` を持たない step に `name` を付ける | workflow の振る舞いは変えない。付けないと決めたら実装を `skipped` にする |
| E2E テスト | `flows[]` ごとに `tests/e2e/workflow/test_pages_yml.py` へテストの関数を作り、`tests/e2e/workflow/conftest.py` の fixture で起動する | 手元の E2E テストの層で回す |
| 同時実行 | `concurrency` の `group: pages`・`cancel-in-progress: false` のため、検証用のブランチの実行は develop の配信の実行と順に並ぶ | 待つ上限は conftest の値を使用する |
| 費用 | public のリポジトリの標準ランナーで回し、料金は発生しない | - |
