# 要件

## 要望

公開ページの配信の workflow `.github/workflows/pages.yml` のインターフェース定義と、フローごとの E2E テストを作成する。

| 要件 | 終了の条件 |
| --- | --- |
| インターフェース定義 | `docs/interface/` に `entry.kind: trigger` の設計書があり、テンプレート『インターフェース定義』の workflow の書き方（`overall_flow`・`flows[]`・`test_file: tests/e2e/workflow/…`）で記載され、全ての文書の検査に合格する |
| 目次 | `docs/interface/index.yaml` に新規作成したインターフェース定義の行がある |
| E2E テスト | `flows[]` ごとに、`flows[].test` の名前のテストの関数が `tests/e2e/workflow/` にあり、規約『GitHub Actions の workflow のテスト』の手順で本物の GitHub Actions を起動して全て pass する |

E2E テストは検証用のブランチで起動し、develop で起動しない（公開ページを再配信しない）。
配信の job（`deploy`）が成功する正常系のフローは、develop への push で起動した直近の実行の結論と step を確認する。
`deploy` の job が使用する環境 `github-pages` は `develop`・`gh-pages`・`master` 以外のブランチの配信を拒否するため、検証用のブランチで起動したときに拒否されるフローを異常系として確認する。
