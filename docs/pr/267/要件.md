# 要件

## 要望

- nav の `auto.group_by` に共通のメタデータ（`METADATA_KEYS` のキー。`main_tags`・`tags` など）を指定すると、文書の `metadata` の値ごとの `group` に分ける
- 行の `metadata` で対応付けたキー（`category` など）を指定すると、対応付けた列の値ごとの `group` に分ける
- 値は `auto.filter` と同じ `field_values` で引く。今の項目のパスの指定（`tags.lang`・`kind` 等）と `'@folder'` は今と同じ結果になる
- 値が配列（`tags`）の文書は、要素ごとの `group` に入れる（今の項目のパスの配列と同じ）。値が無い文書は `その他` に入れる
