## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 値の取得 | `_auto` の `group_by` の値を、`METADATA_KEYS` のキーなら `document.metadata`、行の `metadata` で対応付けたキーなら `get_field(document.data, 対応付けた列)`、それ以外は今と同じ `get_field(document.data, group_by)` で取得する | `field_values` は `kind` を行の ID で返し、今の `group_by: kind` の結果を変えるため使わない |
| 配列と値なし | 配列は要素ごと、値が無ければ `その他` の `group` にする | 今の振る舞いのまま |
| 単体テスト | `group_by: kind`（文書の YAML の `kind`）の結果が変わらないこと、`group_by: main_tags`（`metadata` の値）と、行の `metadata` で `category` を対応付けた `group_by: category` で、値ごとの `group` に分かれることを確認する | - |
