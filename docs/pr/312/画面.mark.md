## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | iPad の Safari（Playwright の WebKit の iPad の端末設定）で、mdmark が使用する見出し行を留める方式と、読み込む mdmark に [shuhei1101/mdmark#705](https://github.com/shuhei1101/mdmark/pull/705) が入っているかを確認し、MindStella のプレビューの指定と比べる | 原因が mdmark の側なら mdmark へ起票し、要件.yaml のスコープ外の行の `plan` をその番号にする |
| 固定の位置 | 見出し行が固定され始める位置と固定後の上端を、トップバーと種類のタブの下端（`--mdmark-sticky-top`）に一致させる | 修正する箇所（CSS 変数・スクロールする要素・`mount` の設定）は切り分けの結果で決める |
| レスポンシブ対応 | iPad の縦・横の画面幅と、デスクトップの画面幅で、固定の位置が同じ下端に一致する | デスクトップの既存の振る舞いを変えない |
| 既存機能への影響 | 右側の目次のブロックの上端と目次から移った見出しの止まる位置（同じ `--mdmark-sticky-top` を使用する）が変わらない | - |
