# 要件

## 要望

iPad（Safari）で文書の画面を開き、本文をスクロールしたとき、表の見出し行は、見出し行の上端がトップバーと種類のタブの下端（`--mdmark-sticky-top`）に達した時に固定され始め、それより前は表の中の元の位置のまま動く。
固定された見出し行の上端は、トップバーと種類のタブの下端に一致する。

原因は次の 2 点を確認して切り分け、dev-docs の側（mdmark に指定するスクロールする要素・上端の位置、文書の画面の `sticky` の指定）にあれば dev-docs で修正する。
mdmark の側にあれば、mdmark へ起票し直す（要件.yaml のスコープ外の行）。

| 確認すること | 材料 |
| --- | --- |
| iPad の Safari で、mdmark が見出し行を留める方式（`timeline` / `script`）のどちらを使用するか | [shuhei1101/mdmark#683](https://github.com/shuhei1101/mdmark/issues/683) |
| dev-docs が読み込む mdmark に [shuhei1101/mdmark#705](https://github.com/shuhei1101/mdmark/pull/705) が入っているか | 画面が jsDelivr から読み込む mdmark のバージョン |
