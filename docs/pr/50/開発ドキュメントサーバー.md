## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エイリアスのスキーマの取り込み（#11） | alias-inject の「エイリアスの元の行」のスキーマを `v0.3.0` のタグから取り込み、取り込み元のタグを記録する | 置き場所は `要件.md` の `未確定` |
| エイリアスのキーの検証（#11） | `alias_type` を持つ行の文書の `metadata` のエイリアスのキーを取り込んだスキーマで検証し、違反を `check_project` と起動時の警告に出す | `alias_type` を documents の行に置く今の書き方と Issue の `metadata` の書き方の差は、取り込むスキーマに合わせて設定設計で決める |
| 用語の検索（#11） | `search_docs` の用語の検索で、`alias_type` を持つ行の文書の `name` と `aliases` の値に照合する | - |
| `list_match_words`（#11） | 文書の MCP に、`alias_type` を持つ行の文書の照合する語の一覧を返すツールを加える | 新規のインターフェース定義 |
| 画面へのエイリアスの受け渡し（#11） | 文書の取得の応答に、配信元のエイリアスを mdmark へ渡せる形で載せる | 画面側は `画面.md` |
| `nav` の `auto` のタグの式（#16） | `auto` に `search_docs` の `filter` と同じ式を書け、`check_filter` で検証し `match_filter` で当たる文書を並べる | `document` を省いたときは配信元の全ての行を対象にする |
| `nav` を書くツール（#16） | 管理の MCP に `nav` の項目を追加・修正するツールを加え、書いた後にスキーマで検証する | スキーマは `要件.md` の `未確定` |
| 0 件の警告（#16） | `nav` の `auto` の条件が 0 件に当たると、`check_project` と起動時の検証が警告する | - |
| `outside_scope`（#40） | `describe`・`search_docs`・`trace_related`・`list_changes` に `outside_scope: bool = false` を加え、`true` のとき `scope` に当たらない配信元も `outside_read` が真なら読む | 書き込みのツールには加えない |
| 作業範囲の外の表示（#40） | 外から読んだ文書・一覧の行に「作業範囲の外（参考）」の表示を付ける | SessionStart の一覧・引数なしの `describe`・`source` を省いた検索には出さない |
| `outside_read`（#40） | 端末の設定の `sources[]` に `outside_read`（既定 `true`）を加える | 端末の設定のスキーマも変える |
| 要求のログ（#40） | 外から読んだ呼び出しの作業場所と配信元を要求のログに残す | - |
| タグの付け方の案内（#41） | SessionStart の注入文と文書の MCP の instructions のタグの行に、単語まで分ける・`action:`・`topic:`・`tool:`・配信元の規約に従うことを数行で加える | 注入文の 2,000 字の上限に収める |
| 設定とスキーマの読み元（#42） | Git の配信元では `dev-docs.yaml`・`documents[].schema` のスキーマを `default_ref` から読む | `default_ref` の決め方・読み直しの契機は `要件.md` の `未確定` |
| スクリプトの読み元（#42） | `validators`・`converters`・`generators` のスクリプトを `default_ref` から動かす | 動かし方は `要件.md` の `未確定` |
| コミットしていない設定の書き換え（#42） | 作業ツリー・ワークツリーを指して読むとき（`worktree` の引数）は、そのフォルダの設定を読み直す今の `load_source_at` の扱いを残す | - |
| ワークツリーの数え方（#42） | `worktrees[]` の相対パスを、`git rev-parse --git-common-dir` の親（メインのリポジトリの直下）から数える | - |
| ブランチとワークツリーの一覧（#42） | `describe(source)` の結果に `list_refs` と同じブランチ・タグと、`worktrees[]` に当たるワークツリーのパスと checkout しているブランチを載せる | 最近の commit は載せない |
| オブジェクトの配列の取り出し（#43） | `metadata` の項目のパスに `[]`（配列の全要素）を加え、`tags: tags[].name` で文字列の配列を取り出す | 今の `a.b[0].c` の書き方は変えない |
| `main` のタグ（#43） | `main: true` の要素の `name` で絞れるようにする | 持ち方は `要件.md` の `未確定` |
| タグの書き戻し（#43） | `write_docs` で `tags` を書いたとき、`add_to` は `{name: ...}` を追加し、`remove_from` は `name` が一致する要素を削除し、`set` は残る要素の `main` を保つ | - |
| 既存機能への影響 | `outside_scope` を渡さない呼び出し・`[]` を使わない `metadata`・`filter` を書かない `auto` は今のまま動く | Git でない配信元の読み元は変わらない |
