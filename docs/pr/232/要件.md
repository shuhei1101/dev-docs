# 要件

## 要望

dev-docs の文書の画面の本文（mdmark が描く範囲）の見た目を、同じ文書を単独の mdmark（`mdmark export` で書き出した HTML）で描いた見た目と同じにする。

- 比べる mdmark は、画面が読み込む版（`MDMARK_URL` のタグ）と同じ版にする
- 同じ文書を、`mdmark export` で書き出した HTML と dev-docs の画面とで、同じ画面幅・同じ明暗でスクリーンショットを並べ、違い（余白・文字・表の幅・色・見出し）を一覧にする
- 違いの一覧と原因を、スクリーンショットで利用者に確認してから直す
- 直した後に、一覧の全ての違いが同じ条件のスクリーンショットで無くなったことを確かめる
- 画面の枠（トップバー・種類のタブ・サイドバー・パンくず）の見た目は変えない
- 文書のタイトルは、並び（パンくず → タイトル → 文書の情報）を保ったまま、大きさ・太さ・区切り線を mdmark の見出し 1 と同じにする
- 本文の左端をパンくず・タイトルと同じ位置にする
- 本文の幅（サイドバーを表示したまま）は変えない
