この端末の `~/.config/systemd/user/dev-docs.service` は 2026-11-14 に dev-docs の外で作られた unit で、`Restart=on-failure` のためポートの使用中（終了コード 3）でも起動し直し続ける。

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| セッション開始のフック | ポートにつながらないとき、systemd --user の `dev-docs.service` があれば `systemctl --user start dev-docs.service` で起動し、無ければ今のとおり切り離して起動する | [要件](./要件.md) の起動の仕組みを 1 つにする方法の案 A |
| global-setup | systemd --user が使える端末では `dev-docs.service` を作って有効にし、ポートの使用中の終了コード 3 では起動し直さない（`RestartPreventExitStatus=3`）。使えない端末では今のとおり切り離して起動する | 同上 |
| フックの制限時間 | `systemctl --user start` を待たずに戻し、`hooks.json` の `timeout`（2 秒）の内に収める | 値はインターフェース定義設計で測って決める |
