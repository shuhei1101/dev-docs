## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ポートの使用中の理由 | `PortInUseError` の標準エラーに、ポートを持つプロセスの pid（取れなければ取れなかった旨）を添える。終了コード 3 は変えない | - |
| 同時の起動 | 待ち受けるのは 1 つで、もう片方は終了コード 3 と理由で終わることを、起動のインターフェース定義と結合テストに明記する | - |
| 起動し直し | `restart` の `os.execv` の経路は変えない。unit の `systemctl --user restart` で起動し直したときに、起動し直す前のプロセスが残らないことは、管理用プラグインの起動の仕組みの統一で満たす | `未確定`（[要件](./要件.md) の起動の仕組みを 1 つにする方法） |
