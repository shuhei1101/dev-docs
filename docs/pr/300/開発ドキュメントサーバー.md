## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 外部キーのリンクのアンカー | 同じ文書のテーブルへのリンクのアンカーを、そのテーブルの見出しを配置した組み立てのパスで `heading_anchors` と同じ規則の ID から引く | 文脈の `anchors` を「`title` から見出しの文字」から「`title` からアンカー」に替える。`schema_to_markdown` は、テーブルの `title` があれば一度組み立てて組み立てのパスごとの ID を作り、`anchors` を与えてもう一度組み立てる（ER の文書だけ組み立てが 2 回になる） |
| 既存機能への影響 | 前に同じ ID の見出しが無いときのアンカー・物理名の読み替え・他の分類のリンク・見つからないときの文字のままは変わらない | 既存の `test_schema_to_markdown_when_foreign_key` 系・`test_render_table_when_objects`・`test_render_table_when_physical_name` で確認する |
