# 要件

## 要望

同じ文書のテーブルへの外部キーのセル（`table` が `{分類}/` を持たない `{テーブル}.{カラム}`）のリンクが、そのテーブルの見出しに mdmark が付ける ID へ飛ぶ。

- アンカーは、変換した Markdown の中で、そのテーブルの見出しより前にある同じ ID の見出しの数を `n` として、`n` が 0 なら `{見出しの ID}`、1 以上なら `{見出しの ID}-{n}` にする（#298 の `heading_anchors` と同じ数え方）
- 数える見出しはテーブルの並びに限らない（別の項目の見出しや本文の値の中の見出しが同じ文字なら数に入る）
- 前に同じ ID の見出しが無いときのアンカー、物理名で記載したテーブルの論理名への読み替え、他の分類のテーブルへのリンク（`{分類}.yaml` の文書へのリンク）、参照先が見つからないときに値の文字のまま出すことは変わらない
