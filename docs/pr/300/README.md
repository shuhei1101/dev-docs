# 変換の同じ文書のテーブルへの外部キーのリンクを、mdmark がそのテーブルの見出しに付ける連番つきの ID へ飛ぶようにする

## 概要

同じ文書のテーブルへの外部キーのセルのリンクが、そのテーブルより前に同じ文字の見出しがあるときも、そのテーブルの見出しへ飛ぶようにする。

## 背景

[Issue #299](https://github.com/shuhei1101/dev-docs/issues/299) の要望。
[#298](https://github.com/shuhei1101/dev-docs/pull/298)（起点 Issue [#297](https://github.com/shuhei1101/dev-docs/issues/297)）のスコープ外から、今回の変更を前提にした後続として切り出した。
develop の `src/dev_docs/features/convert/markdown.py` の `_foreign_key` は、同じ文書のテーブルへのリンクのアンカーを `heading_anchor(見出し)` で見出しの文字列だけから作るため、前に同じ文字の見出しがあると、mdmark が付ける `-{n}` の連番を付けず 1 つ目の同じ見出しへ飛ぶ。
#298 で追加した `heading_anchors` は、変換と同じ組み立てで見出しを配置した組み立てのパスごとに mdmark と同じ規則のアンカーを返却する。
