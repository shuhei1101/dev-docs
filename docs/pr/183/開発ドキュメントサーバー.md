## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 契約 | 正本を shuhei1101/project-index の develop（`f36ba69`。[shuhei1101/project-index#46](https://github.com/shuhei1101/project-index/issues/46) をマージした commit）の IF-22〜IF-32 とし、API-155-1 をそれに合わせて書き換え、参照した版を記録する | - |
| 付け替え口 | `ProjectIndexClient` と応答の型を本物のパス・キー（camelCase）・状態コード・`application/problem+json` に合わせる | - |
| 利用側 | 付け替え口が返す型が変わる分だけ追従し、画面の API の入出力は変えない | 本物の API が返さない値の扱いは [要件](./要件.md) |
| 結合テスト | 文書の取得・差分・検索・リビジョンの一覧・端末の設定の取得と保存の正常系を、テストの中で子プロセスとして起動した本物の project-index に対して確かめる。つながらない・応答しない・500 を返す異常系と、それ以外のインターフェースはモックで確かめる | 起動のさせ方はモジュール構成設計で決める |
| 既存機能への影響 | 画面と管理の MCP の入出力は変えない | - |
