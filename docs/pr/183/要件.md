# 要件

## 要望

| 要望 | 終わりの条件 |
| --- | --- |
| 付け替え口の接続先の切り替え | 付け替え口（`src/dev_docs/integrations/project_index/`）が、shuhei1101/project-index の develop（`81f0e70`）のインターフェース定義 IF-22〜IF-32 の入出力で読み取り API と端末の設定の API を呼び、`docs/external-api/API-155-1.yaml` の `verification.detail` に挙げた食い違いが全て解消している |
| 結合テストでの確認 | 文書の取得・差分・検索・リビジョンの一覧・端末の設定の取得と保存の結合テストが、モックではなく本物の project-index に対して全て pass する |
| 反映作業 | 端末の設定の移し替え（`dev-docs migrate --project-index`）と、稼働中の dev-docs のサーバーの再起動を反映作業にし、マージの後に画面が本物の project-index から文書を表示する |

`未確定`: 本物の API が返さない値（文書の一覧の値・バージョン・読めなかったファイル、配信元の設定の解いた種類のスキーマ 等）の補い方（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | dev-docs の側で、本物の API の他のエンドポイント（文書の取得 等）の応答から組み立てる |
| B | project-index の読み取り API へ入出力を追加する Issue を起票し、追加されるまで該当の機能を止める |

推奨: A

規約『複数リポジトリのAPI契約』で提供する側の API は特定の使い手に寄せないため、組み立てられる値は使う側で補う。組み立てられない値だけを B で起票する。
