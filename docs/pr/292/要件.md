# 要件

## 要望

`item_heading` が、knowledge の共通の型 `ref` の `x-rules` の次の書き方の項目のパスの見出しを返却する。

- `[{値}#{順番}]`: `x-key` が `{値}#{順番}` に一致する要素が無く、末尾が `#{整数}` のとき、`x-key` が `{値}` の要素の `{順番}` 番目（1 始まり）へ進む。見出しはその要素の `x-key` の値（`functions[main#3]` は `main`）。順番が要素の数を超えるときは `None`
- 辞書の `[{キー}]`: `x-shape: sections` の辞書の値で、`[...]` の値をキーとして子へ進む。`.` や空白を含むキーも 1 階層にする。見出しは画面の変換（`sections`）が辞書の子に付ける見出しと同じ（子のスキーマの `x-heading`、無ければ `title`、無ければキー）
- `[{値}]` の直後に `[` が続くパス（`[a][b]`）も段に分けて読む（shuhei1101/project-index の `_split_ref_path` と同じ）
- 今の書き方（`flow`・`scenarios[正常シナリオ]`・`request[operations[].fields]`）の見出しと、記載方法の誤ったパスが `None` になることは変わらない
