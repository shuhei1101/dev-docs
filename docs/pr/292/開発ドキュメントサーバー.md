## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 項目のパスの分解 | `_item_steps` を、名前の段と `[...]` の段を並べる形に変え、`[{値}]` の直後に `[` が続くパスも読む | `[{値}]` の直後に名前が続く・閉じない `[`・対応する `[` の無い `]`・空の名前は今のまま `None` |
| `[{値}#{順番}]` | リストの値では、`x-key` が値に一致する要素があればその最初の要素、無ければ末尾の `#{整数}` を外した値の要素の順番目（1 始まり）へ進む。見出しは要素の `x-key` の値 | 選び方は shuhei1101/project-index の `_element_position` と同じ。順番が 0・要素の数を超えるときは `None` |
| 辞書の `[{キー}]` | `x-shape: sections` の辞書の値では、`[...]` の値のキーの子へ進む。見出しは子のスキーマの `x-heading`、無ければ `title`、無ければキー | 画面の変換の `sections` が辞書の子に付ける見出しと同じ。キーが無ければ `None` |
| 既存機能への影響 | 今の書き方の項目のパスの見出しは変わらない | 既存の `test_item_heading` 系で確認する |
