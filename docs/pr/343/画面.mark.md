## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計の `列の表示のメニュー` | `label` を、見出し行の右上の表のメニューのボタン、メニューの `テーブル設定` の項目、テーブル設定のパネルの列ごとの表示の切り替え、隠した列の数のバッジに書き換える | `visible_when`・`initial_value` と、列を文書ごとに記憶する振る舞いは変えない |
| 外部ライブラリ『mdmark』 | `onColumnsChange` の説明の列の出し入れの操作と、確認の記録を、mdmark の develop の表のメニューに合わせる | `onColumnsChange` の引数 `{tableIndex, hidden}` が変わっていないことを確かめる |
| 結合テストの `列の表示のメニュー` | 表のメニューのボタンを押し、メニューの `テーブル設定` からパネルを開いて列を出し入れする操作に替え、隠した列のバッジと読み上げ名を表のメニューのボタンで確かめる | 2 つ目以降の表の操作は、表ごとの表のメニューのボタンで指す |
| mdmark のバージョン | 固定せず、`develop` を読み込む | - |
