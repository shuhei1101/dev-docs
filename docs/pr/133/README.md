# MCP の応答だけが返却するエラー・ヒントの文言を、AI slop の単語の対応表に合わせて修正する

## 概要

`src/dev_docs/` が MCP の応答としてエージェントへ返却し、画面には表示しない文言を、knowledge の AI slop の単語の対応表に合わせて修正する。

## 背景

[Issue #117](https://github.com/shuhei1101/dev-docs/issues/117) の要望。
[PR #116](https://github.com/shuhei1101/dev-docs/pull/116)（起点 [Issue #107](https://github.com/shuhei1101/dev-docs/issues/107)）は、サーバーの文言のうち画面が表示するものを修正し、MCP の応答だけが返却する文言を #117 に切り出した。
PR #116 の後、同じ意味の文言が、画面に出るものは `読み込めない`、MCP の応答に出るものは `読めません` のように、サーバーの中で 2 通りになっている。
