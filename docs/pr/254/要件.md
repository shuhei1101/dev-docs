# 要件

## 要望

文書の画面の結合テスト `body_without_preflight` を、mdmark の develop の最新（shuhei1101/mdmark の [3730097](https://github.com/shuhei1101/mdmark/commit/373009769ef1444847b12c29f003f884125ef6ac) 以降）で pass させる。

- develop の最新の mdmark が map の凡例をどう出すかを確認し、閉じた凡例の `display` の確認の前提をそれに合わせる
- 確認の目的（mdmark が `hidden` を付けて表示する要素を、Preflight の `[hidden]` の `display: none !important` でなく mdmark の値で描く）は変えない
- 画面の CSS（本文に Preflight を適用しない）の他の確認（箇条書きの記号・見出し 4・コードブロックの書体・`box-sizing`）は今のまま成り立つ
- 画面のコード（CSS・`doc-body.tsx`・`use-mdmark.ts`）は変えない

閉じた凡例の確認は、本文の Markdown（map のシーケンス図）を変えず、算出値を取る前に閉じた凡例が描かれるまで待つ形にする。
develop の最新の mdmark も、map のシーケンス図に `hidden` を付けた凡例を出し、その `display` は `flex` になる。
fail は、map の図が見出しより後に描き終わり、テストが算出値を取る時点で凡例がまだ無いことによる（調べ方は [画面](./画面.md) の `## 現状`）。
