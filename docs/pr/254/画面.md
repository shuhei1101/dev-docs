mdmark の [3730097](https://github.com/shuhei1101/mdmark/blob/373009769ef1444847b12c29f003f884125ef6ac/src/parts/diagram.ts) の図のブロック（`figure.mdmark-diagram`）は、v0.13.0 と同じく凡例が空のときに `hidden="hidden"` を付けた `.mdmark-diagram-legend` を出す。
jsDelivr の `@develop` が mdmark の develop の最新（[ede22be](https://github.com/shuhei1101/mdmark/commit/ede22beb)）の dist を返すようになった時点で、テストを変えずに `body_without_preflight` を実行すると、develop でも同じ fail が出た（`調査/修正前の結合テスト.log`）。
同じ本文を開いて 1.5 秒待ってから出力を確認すると、`ul.mdmark-diagram-legend` は `hidden="hidden"` を持ち、算出値の `display` は `flex` だった（`調査/描き終わった後の凡例.log`）。
develop の最新の mdmark も閉じた凡例を出し、本文には Preflight の `[hidden]` を適用していない。
fail は、map の図が見出し「概要」より後に描き終わり、テストが見出しの表示だけを待って算出値を取るため、その時点で凡例がまだ無いことによる。

| 対象 | 方針 | 補足 |
