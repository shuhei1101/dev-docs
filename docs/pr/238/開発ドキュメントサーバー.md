## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `render_table` の表のマーカー | `{"kind": "data"}` に、`closed` なら `"collapse": {"open": false}`、隠す列は `"columns": {"{列名}": {"hidden": true}}`、`WIDE_KEYS` の列は `"columns": {"{列名}": {"width": {"mode": "nowrap"}}}` を足した JSON を `json.dumps(..., ensure_ascii=False)` で出す | 先頭の列は隠す列に入れない（mdmark の制約は変わらない）。空白を含む列名も記載する |
| `render_attributes`・`_Builder.test_files` の表のマーカー | `{"kind": "plain"}`、閉じた表は `{"kind": "plain", "collapse": {"open": false}}` | - |
| 表のキーの取り出し（`_strip_table_keys`） | 表のキーのマーカーと表の間にある表のマーカーの行（`<!-- table: … -->`）を、記載方法によらず読み飛ばす | `TABLE_DATA_MARKER` の完全一致をやめる |
| 結合テスト | `test_normal_when_diagrams_checked` の判定を `mdmark check` のずれ 0 件に戻す | IF-155-10 の制約の文も同じに戻す |
| 既存機能への影響 | 描かれる表の見た目は変えない。図の元データの表などの表のキーが、表のキーのマーカーの値に変わる | 保存済みの列の表示（図の元データの表）は引き継がれない |
