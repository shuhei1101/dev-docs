## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 列の表示の機能を持つ表の判定 | 表の直前のマーカーは、`<!-- table:` から次の `-->` まで（複数行を含む）を 1 つのマーカーとして読む。名前の後ろが `{` で始まるときは JSON として読み、`features.columns.enabled` が `false` でなく、かつ `features.columns` があるか、どれかの列の `hidden` が `true` の表を列の表示の機能を持つ表にする。前の記載方法のマーカーは今の `+columns` の判定のまま | mdmark `v0.13.0` の `onColumnsChange` の `tableIndex` の数え方（列の表示・非表示の機能を持つ表の出現順）に合わせる。JSON として読めないマーカーは機能を持たない表にする |
| 隠す列の書き込み | JSON のマーカーは、保存した設定がある表（保存した隠す列が空の場合を含む）で、マーカーの範囲の JSON の全ての列の `hidden` を保存した隠す列と一致させる（保存に無い列の `hidden` は削除する）。書き換えで `hidden` が `true` の列が無くなる表には `features.columns` の `{}` を追加し、列の表示の機能を残す。前の記載方法のマーカーは今の `hide=` の書き足しのまま | 変換が最初から隠した列も、利用者が表示に戻せば開き直しても表示される。`features.columns` を残さないと、その表が機能を持つ表から外れて `tableIndex` がずれる |
| 単体テスト（`tables.test.ts`） | 複数行の JSON のマーカーの表、`features.columns.enabled` が `false` で `hidden` が `true` の列を持つ表、最初から隠した列を保存した隠す列が空で表示に戻す表のケースを置く | - |
