## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 列の表示の機能を持つ表の判定 | マーカーの名前の後ろが `{` で始まるときは JSON として読み、`features.columns` があり `enabled` が `false` でないか、`columns` のどれかの列の `hidden` が `true` の表を列の表示の機能を持つ表にする。前の記載方法のマーカーは今の `+columns` の判定のまま | mdmark `v0.13.0` の `onColumnsChange` の `tableIndex` の数え方（列の表示・非表示の機能を持つ表の出現順）に合わせる。JSON として読めないマーカーは機能を持たない表にする |
| 隠す列の書き込み | JSON のマーカーは、保存した隠す列ごとに `columns.{列名}.hidden` を `true` にした JSON に書き換える。前の記載方法のマーカーは今の `hide=` の書き足しのまま | - |
