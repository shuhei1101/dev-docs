# 要件

## 要望

| Issue | 終わりの条件 |
| --- | --- |
| [#157](https://github.com/shuhei1101/dev-docs/issues/157) | `doc-view-screen.spec.ts` の「列の表示のメニュー」4 件（`columns_menu_visible`・`columns_menu_hidden_columns`・`columns_menu_save`・`columns_menu_save_failure`）が、mdmark v0.10.0 のボタン名 `テーブル設定` で pass する |
| [#170](https://github.com/shuhei1101/dev-docs/issues/170) | `npm run test:integration` の全件実行で、`search-dialog.spec.ts`・`topbar.spec.ts` が時間切れにならず pass する |

#157 の照合は、[PR #101](https://github.com/shuhei1101/dev-docs/pull/101)（[c639829](https://github.com/shuhei1101/dev-docs/commit/c639829)）で develop の `doc-view-screen.spec.ts` 715〜760 行が `テーブル設定`・`テーブル設定（1 列を非表示）`・`getByRole("dialog", { name: "テーブル設定" })` に置き換わっている。この作業 PR では照合を書き換えず、全件実行で 4 件が pass することを確かめる。fail した場合は照合を mdmark v0.10.0 の画面に合わせて直す。

#170 は、全件実行の時間切れの原因を、実行中の端末の負荷（load average・`free -m` の available・ほかの全件実行の有無）を記録して再現して特定し、テストの設定（`playwright.config.ts` の並列度）か待ち方（`support/storybook.ts` の `openStory`）を直す。単独実行で pass する spec の期待値は変えない。
