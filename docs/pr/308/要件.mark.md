# 要件

## 要望

文書の画面で文書の無いタブを選んだとき、パンくずを画面設計 `SCR-155-1` の `パンくず` の `visible_when` のとおり `{配信元の ID}` / `{タブ名}` にする。

| 状態 | 今のパンくず | 変更後のパンくず |
| --- | --- | --- |
| 文書のあるタブで文書を開いている | `{配信元の ID}` / `{タブ名}` / `{group}` / `{文書の名前}` | 変わらない |
| 文書の無いタブを選んでいる | `{配信元の ID}` / `{前の文書のタブ名}` / `{group}` / `{文書の名前}` | `{配信元の ID}` / `{選んだタブ名}` |

- 文書の無いタブでは、タブ名を末尾の項目（リンクにせず `aria-current="page"`）にする。そのタブに文書が無いため、タブ名のリンクの開き先が無い
- 配信元の ID のリンク（配信元のトップを開く）は今と同じ
