# 文書の画面で文書の無いタブを選んだとき、パンくずを配信元の ID とタブ名だけにする

## 概要

文書の画面で文書の無いタブを選んだとき、利用者がパンくずで配信元の ID とそのタブ名だけを参照できるようにする。

## 背景

[Issue #306](https://github.com/shuhei1101/dev-docs/issues/306) の不具合。
文書の無いタブを選ぶと、パンくずが前の文書の階層（`{配信元の ID}` / `{前の文書のタブ名}` / `{group}` / `{文書の名前}`）を出したままになる。
画面設計 [docs/screen/SCR-155-1.yaml](https://github.com/shuhei1101/dev-docs/blob/4e9542d/docs/screen/SCR-155-1.yaml#L79-L86) の `パンくず` の `visible_when` は、文書の無いタブでは `{配信元の ID}` / `{タブ名}` と定めている。
[作業 PR #304](https://github.com/shuhei1101/dev-docs/pull/304) のモック作成で見つかり、スコープ外として切り出された。
