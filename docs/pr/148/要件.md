# 要件

## 要望

`templates/` の次のファイルの `title`・`description`・`examples`・コメントの文言を、knowledge の AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`、develop）に合わせて修正する。

| ファイル | 中身 |
| --- | --- |
| `templates/prompt.schema.yaml` | プロンプトの YAML のスキーマ（knowledge の `schemas/prompt.schema.yaml` のコピー） |
| `templates/common.schema.yaml` | 種類をまたいで使用する型のスキーマ（knowledge の `schemas/common.schema.yaml` のコピー） |
| `templates/files.schema.yaml` | 管理用の YAML のスキーマ |
| `templates/settings.yaml` | 端末の設定の雛形 |
| `templates/dev-docs.yaml` | 配信元の設定の雛形 |

終わりの条件は、上のファイルで対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が 0 件になること。
キー・型・形式・`enum`・`const` の値は変えない。
置き換え先は対応表の `ok` の単語にし、PR #133・PR #143 で決めた置き換え（`参照する`・`使用する`・`指定する`・`該当する`・`適用する`・`記載する`・`除外する`・`配置する`・`単語`・`出典`）と統一する。

箇所ごとの修正前後は次のとおり（`templates/` からのパス）。
