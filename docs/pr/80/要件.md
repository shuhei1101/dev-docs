# 要件

## 要望

画面（`frontend/src/`）の物理ファイルのうち設計書の無いものに当たるモジュール構成の設計書を、[#70](https://github.com/shuhei1101/dev-docs/pull/70) の置き場所の決まり（`画面/{container}.yaml`）で作る。
書き方は [#78](https://github.com/shuhei1101/dev-docs/pull/78) に揃える。

- 次の 9 ファイルの設計書を作る
  - `features/docs/doc-view/components/doc-main.tsx`（`DocMain`）
  - `features/docs/doc-view/hooks/use-doc-navigation.ts`（`compareBase`・`useDocNavigation`）
  - `features/docs/not-found/components/missing-links.tsx`（`MissingLinks`）
  - `features/docs/not-found/hooks/use-missing-view.ts`（`useMissingView`）
  - `features/docs/shared/serving-sources.ts`（`ServingSource`・`servingSources`）
  - `features/settings/settings/components/source-skeleton.tsx`（`SourceSkeleton`）
  - `shared/components/skip-link.tsx`（`SkipLink`）
  - `shared/hooks/use-delayed-flag.ts`（`useDelayedFlag`）
  - `shared/hooks/use-media-query.ts`（`useMediaQuery`）
- `testing/setup-tests.ts` の設計書も作る（export を持たないので、準備することを `notes` に書く）。テストの共通の準備（相対 URL の `fetch` の書き換え・jsdom に無い `matchMedia` などの補い）を持ち、同じ `testing/` の `msw/handlers.ts` が設計書を持つため
- 次は設計書の対象から外し、分類の設計書の `directory` に `（設計しない）` と書く（`分類/アプリとルート.yaml` の生成物の行と同じ書き方）
  - `shared/components/ui/`・`shared/lib/utils.ts`（shadcn/ui が置くファイル）: `分類/共通.yaml`
  - `*.stories.tsx`（Storybook のストーリー。部品設計の `story` が持つ）: `分類/共通.yaml`・`分類/文書の画面.yaml`
- `title` は `画面 / {分類名} / {物理ファイルの名前}`（同じフォルダの他の設計書と同じ分類名）
- 条件分岐か振る舞いを持つ要素は `unit_tests` を持ち、`tests/unit/frontend/src/` の下に `container` と同じパスで単体テストのファイル（`{名前}.test.ts`・`{名前}.test.tsx`）を作って `test_files` に載せる。表示だけの `SourceSkeleton` と `testing/setup-tests.ts` は持たない（表示だけの `doc-skeleton.tsx` と同じ）
- 置き場所のフォルダの `index.yaml`・`README.md` に行を追加し、フォルダの `summary`（上の階層の目次の行を含む）に中身を加える。`not-found/` の下には `components/`・`hooks/` のフォルダを新しく作る
- 分類の設計書（`分類/文書の画面.yaml`・`分類/設定画面.yaml`・`分類/共通.yaml`）の `directory` に作った設計書のファイルを加える。`分類/アプリとルート.yaml` の `directory` に無い `app/initial-loading.tsx`・`app/pending.ts` も加える
- 対象のファイルの要素を使う設計書の処理の本文で、作った設計書の要素を論理名で指す
- 書くツール（`write_design_doc_module`）で作り、検査を通す

終わりの条件:

- `frontend/src/` の物理ファイルのうち、分類の設計書が `（設計しない）` と書くものを除く全てに、モジュール構成の設計書（`画面/{frontend/src/ からのパス}.yaml`）がある
- 分類の設計書の `directory` が、作った設計書のファイルと設計しないファイルを載せる
