# 配信元を選んだときの最初の表示を毎回短い時間で終わらせ、表示できないときは理由を画面に出す

## 概要

利用者が dev-docs の画面で配信元を選んだとき、どの配信元でも毎回短い時間で最初の文書を読める。表示できないときは、その理由を画面で知る。

## 背景

[Issue #225](https://github.com/shuhei1101/dev-docs/issues/225) の要望。利用者から、配信元を選んでも表示できないことが多く、安定しないと報告があった。

稼働中の dev-docs（develop の `abe2d81`）で 14 件の配信元の最初の画面を Playwright で 2 回ずつ開くと、1 回目は 3 件が 45 秒で開けず、開けた 11 件も 7〜42 秒かかった。2 回目は 14 件とも開けた（4〜28 秒）。
文書の取得（[IF-155-10](https://github.com/shuhei1101/dev-docs/blob/develop/docs/interface/IF-155-10.yaml)）は 1 回の要求の中で project-index へ配信元の設定・文書の一覧・文書・判断の一覧などを順に問い合わせ、project-index への問い合わせの制限時間は 45 秒（[NFR-155-1](https://github.com/shuhei1101/dev-docs/blob/develop/docs/nonfunctional/NFR-155-1.yaml) の NFR-14）。
画面には読み込み中の表示と、project-index に接続できないとき（503）の表示はあるが、取得が終わらないまま待ち続ける場合の表示は無い。
