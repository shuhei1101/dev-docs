# 要件

## 要望

1 つの作業 PR で、まとめた子 Issue 3 件を対応する。

| 子 | 終わりの条件 |
| --- | --- |
| [#328](https://github.com/shuhei1101/dev-docs/issues/328) | メタデータの画面の表のセルを押して編集を始めたとき、押した位置に入力位置が来る（`metadata-table.tsx` の `EditableCell`） |
| [#329](https://github.com/shuhei1101/dev-docs/issues/329) | メタデータの画面の表が、画面の横幅を使って広く表示される（`metadata-screen.tsx` の `<main>` の `max-w-6xl`。幅の上限は画面設計で決める） |
| [#327](https://github.com/shuhei1101/dev-docs/issues/327) | 文書の画面の左のサイドバーを閉じる・開く、境目をドラッグして幅を変える、`nav` のグループを折りたたむ（折りたためることが見た目で分かる）ことができる。開閉・幅の保存、最小・最大の幅、48rem 未満のドロワーの扱いは画面設計で決める（モック HTML の `--sidebar-w` も対象。必要なら利用者へ確認する） |

要件として言い直すと次のとおり。

- メタデータの画面で、修正できる行の値を押すと、入力欄の入力位置が押した文字の位置（文字の間を押したときはその間、値の右の余白を押したときは末尾）に来る
- メタデータの画面の本文（見出し・絞り込みの入力欄・種類のタブ・種類の表）を 72rem で絞らず、画面の横幅から左右の余白を除いた幅まで広げる（上限の有無と値は画面設計で決める）。絞り込みの入力欄の幅は今のまま
- 文書の画面の画面幅 48rem 以上で、サイドバーを閉じる・開くボタンを配置し、閉じると本文がサイドバーの幅だけ広がる
- 文書の画面の画面幅 48rem 以上で、サイドバーと本文の境目をドラッグしてサイドバーの幅を変えられる。最小・最大の幅を持ち、キーボードでも幅を変えられる
- 文書の一覧の group の見出しを開閉のボタン（開閉の状態を山形のアイコンで示す）にし、押すと配下の page を折りたたむ・開く。開いている文書を含む group は開いた状態で始める
- サイドバーの開閉の状態と幅は、明暗の設定と同じブラウザの設定（`localStorage`）に保存し、画面を開き直しても前の状態で始める
- 画面幅 48rem 未満の文書の一覧のドロワーは、開閉・幅を今のままにし、group の折りたたみだけをドロワーの中の文書の一覧にも適用する
- メタデータの画面の表の幅に上限を設けない
