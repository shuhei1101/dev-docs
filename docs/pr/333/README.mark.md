# メタデータの画面のセルの入力位置と表の幅、文書の画面のサイドバーの開閉・幅・グループの折りたたみ

## 概要

利用者が、メタデータの画面で行の値を押した位置から編集し、表を画面の横幅で参照できるようにする。
利用者が、文書の画面のサイドバーを閉じる・幅を変える・グループを折りたたむことができるようにする。

## 背景

[Issue #332](https://github.com/shuhei1101/dev-docs/issues/332) は、次の 3 件をまとめた親 Issue。

| 子 | 困っていること |
| --- | --- |
| [#328](https://github.com/shuhei1101/dev-docs/issues/328) | メタデータの画面の `EditableCell` は、押すと値の `<button>` を `<Input>` に差し替えてフォーカスするだけのため、入力位置が常に末尾に来る |
| [#329](https://github.com/shuhei1101/dev-docs/issues/329) | メタデータの画面の `<main>` が `mx-auto max-w-6xl`（72rem）で、広い画面で左右に余白が残り、説明などの長い列が折り返す |
| [#327](https://github.com/shuhei1101/dev-docs/issues/327) | 文書の画面のサイドバーは md 以上の幅で常に出て `w-60` の固定で、`nav` の group は見出しの `<p>` の下に文書を並べるだけで折りたためない |
