## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 行の値の入力位置 | 行の値を押したとき、押した座標から値の中の文字の位置を求め、入力欄にフォーカスした後にその位置へ入力位置を合わせる。位置を求められないとき（キーボードの Enter・Space で始めたとき）は末尾にする | 求め方（差し替えのまま位置を指定するか、編集前から入力欄で表示するか）はモジュール構成設計で決める |
| メタデータの画面の幅 | 本文の `max-w-6xl` を解除し、画面の横幅から左右の余白を除いた幅にする。絞り込みの入力欄は `max-w-sm` のまま | `未確定`（上限の有無。決める段: 画面設計） |
| サイドバーの開閉 | 画面幅 48rem 以上で、サイドバーを閉じる・開くボタンを配置する。閉じると本文がサイドバーの幅だけ広がる | ボタンの位置はモック作成で決める |
| サイドバーの幅 | サイドバーと本文の境目に、ドラッグで幅を変えるハンドルを配置する。最小・最大の幅を持ち、キーボードの矢印キーでも幅を変えられる | 最小・最大の幅の値は画面設計で決める。既定の幅は今の `w-60`（15rem） |
| 開閉・幅の保存 | `未確定`（決める段: 画面設計） | 案と推奨は要件の `## 要望` |
| group の折りたたみ | group の見出しを開閉のボタン（山形のアイコンで開閉の状態を示す）にし、押すと配下の page を折りたたむ・開く。開いている文書を含む group は開いた状態で始める | `aria-expanded` を持たせる |
| 48rem 未満のドロワー | `未確定`（決める段: 画面設計） | 案と推奨は要件の `## 要望` |
| モック | 文書の画面のモックに、サイドバーの開閉のボタン・幅のハンドル・group の開閉のボタンを追加する（`--sidebar-w` を変えられるようにする） | - |
| アクセシビリティ | 開閉のボタン・幅のハンドル・group の開閉のボタンを、キーボードで操作でき、読み上げ名を持つようにする | - |
| レスポンシブ対応 | 幅 390px で、文書の画面・メタデータの画面に横スクロールが出ない | - |
| 既存機能への影響 | 文書の一覧の現在地・変化のマーカー・ドロワーの開閉と、メタデータの表の編集・Esc での取り消しを今までどおりにする | - |
