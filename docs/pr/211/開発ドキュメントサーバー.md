## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の一覧の取得 | 付け替え口は `GET /sources/{source}/docs` に `common_keys=true` を常に付け、各文書の `metadata` を `LISTED_METADATA_KEYS` の値に `commonKeys` を重ねたものにする | `commonKeys` が `null` なら重ねない |
| 文書の取得 | `metadata` を `LISTED_METADATA_KEYS` の値に `metadata.commonKeys` を重ねたものにする | - |
| 共通のキーの組み立て | `with_row_metadata` と、画面の文書の取得の 2 か所の呼び出しを削除する | 使う所が無くなる `DocumentRow.metadata` も削除する。`DocumentRow.alias_type` はエイリアスの集めが使うため残す |
| 絞り込みの共通のキー | `METADATA_KEYS` を残す | 理由は `要件.md` の `## 要望` |
| 既存機能への影響 | 画面の API の入出力と、画面に出る共通のキーの値は変えない | 既存の結合テスト `tests/integration/server/` を回帰確認で回す |
| 外部 API 制約 | project-index#54 を含む project-index が端末で動いていることを前提にする | 2026-11-14 に端末の project-index が `commonKeys` を返すことを確かめ済み |
| 結合テストの project-index | 結合テストが起動する本物の project-index の commit（`PROJECT_INDEX_COMMIT`）と、模擬応答が沿う入出力を、`commonKeys` を返す最初の commit `42632c5`（shuhei1101/project-index#54）にする | - |
