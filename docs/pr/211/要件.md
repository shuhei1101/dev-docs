# 要件

## 要望

- 画面のサーバーの付け替え口は、文書の一覧を `common_keys=true` で呼び、各文書の `metadata` を、一覧のメタデータ（`id`・`kind`・`name`・`description`・`tags`・`visibility`）に `documents[].commonKeys` を重ねたものにする
- 文書の取得は、`metadata` を一覧のメタデータに `metadata.commonKeys` を重ねたものにする
- 共通のキーを自前で組み立てる処理（`features/documents/fields.py` の `with_row_metadata` と、それを呼ぶ `features/view/document.py` の 2 か所）を削除する
- 画面の API の入出力と、画面に出る共通のキーの値は変えない
- 端末で動いている project-index（127.0.0.1:8786）が、文書の一覧の `common_keys=true` に `commonKeys` を返すことを前提にする（2026-11-14 に確かめ済み）
- 絞り込みが共通のキーかを決める `METADATA_KEYS`（`features/filter/fields.py` の項目の値・使える項目）は残す。絞り込みの使える項目は文書ではなくスキーマと `METADATA_KEYS`（キーごとの型を含む）から作るため、`METADATA_KEYS` を削除しても dev-docs に共通のキーの一覧が残る
