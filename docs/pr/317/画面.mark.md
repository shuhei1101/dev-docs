## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 編集機能 | 配信元の編集中の変更の最初の 1 件を追加したときに、メタデータの取得の既定のブランチのコミットを、編集を始めたときのコミットとして編集中の変更と一緒にブラウザに保持する。編集中の変更が空になったら削除する | 記録の単位は要件の `未確定` に従う |
| 閲覧機能 | 編集中の変更がある間は、編集を始めたときのコミットの内容で一覧を表示する | ほかの変更が入っても、利用者が編集を始めた内容のまま表示する |
| 一括操作 | まとめて送信と差分確認で、編集を始めたときのコミットを開発ドキュメントサーバーへ送信する | - |
| 状態表示 | 衝突してブランチに残したときは、編集中の変更からその配信元の変更を除き、パネルに残したブランチの名前と、スクリプトが返却した PR の URL（リンク）を出す。スクリプトが失敗した・指定が無いときは、その旨と理由を出す | 表示の文言と位置はモック作成で決める |
| エラー表示 | 編集を始めたときのコミットが使用できないと断られたときは、今と同じく編集中の変更を残して理由を出す | - |
| 既存機能への影響 | 衝突しないときの送信・差分確認・取り消し・検査の違反・許可していない種類・リモートに接続できないときの表示は今のまま | SC-155-15 の既存のシナリオで確認する |
