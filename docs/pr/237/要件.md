# 要件

## 要望

- `docs/` の Markdown の今の書き方のマーカーを、`mdmark upgrade` で JSON の記載（`<!-- table: {"kind": "data"} -->`）へ移す
- 移行の報告（`{文書}:{行}: {マーカー}: {記載}: {理由}` の行）に出た記載を、JSON のキーで記載し直す
- 終わりの条件: `docs/` の Markdown を mdmark v0.13.0 の `check` で点検し、`legacy_mark` が 0 件
- 完了したら [shuhei1101/mdmark#478](https://github.com/shuhei1101/mdmark/issues/478) にその旨をコメントする

移行に使う mdmark は、画面が読む版と同じ v0.13.0 にする（Issue の本文の v0.11.0 以降で、今の書き方をまだ読む版）。
コードスパン・コードブロックの中の文字列はマーカーとして描かれないため書き換えない。

`mdmark upgrade`・`check` は、移行の間だけ `docs/mdmark.config.yaml`（`version: v0.10.0`・`build.include: ["**/*.md"]`・`check.suggestMarkExtension: false`）を置いて流し、流した後に削除する（commit しない）。
今のリポジトリは `mdmark.config.yaml` を持たず、置き続けると要望に無い決めごとが増えるため。

コードを変えないため、単体・結合テストは無い。
点検の結果は [テスト結果/20261116213527_9eb21e7_mdmark_check.log](./テスト結果/20261116213527_9eb21e7_mdmark_check.log)（移行の前は `legacy_mark` が 136 件、移行の後はずれ 0 件）。
