# 要件

## 要望

文書とソースコードの索引・検索・書き込みの MCP と配信元の読み込みを project-index へ移し、dev-docs をそれを使用する画面のサーバーにする。
配信元の設定の既定のファイル名を `project-index.yaml`・`project-index.local.yaml` にする。

| 要件 | 終わりの条件 |
| --- | --- |
| 索引・検索・書き込みの MCP の切り出し | 文書の MCP（`describe`・`search_docs`・`trace_related`・`list_changes`・`list_match_words`・`write_docs`・`delete_docs`）と、配信元の読み込み・検査・変換を project-index だけで提供でき、dev-docs から除外されている。dev-docs を入れずに project-index だけを入れた端末で、文書の MCP を使用できる |
| 画面のサーバーの付け替え | dev-docs の画面のサーバーが、配信元の文書・検索・リビジョンを project-index から取得し、今と同じ画面を表示する |
| 配信元の一覧の共有 | 端末の設定の `sources[]` を dev-docs と project-index の両方が同じ内容で参照する。設定画面で配信元を追加・停止・削除すると、project-index にも反映される |
| 既定のファイル名 | 雛形・設計書・使い方の例の既定のファイル名が `project-index.yaml`・`project-index.local.yaml` になっている。端末の設定の `config` でほかの名前も指定できる状態を保つ。管理の `write_nav` と、フォルダを渡す `check_project` などが探す名前（`CONFIG_FILE`）も同じ名前になっている |
| #119 の修正の引き継ぎ | #119 の修正（1 回の要求の中で ref の解決とスキーマの読み込みを繰り返さない）と、その所要時間を確認するテストを、処理と一緒に移行している |
| #119 の所要時間の測り直し | 移した後に、#119 の本文の表と同じ 3 つの要求（配信元 `ai-monitor` への name の絞り込み・`view: count`・body の正規表現）で所要時間を測り直し、この PR に記録している |

`未確定`: 今の各リポジトリの `dev-docs.yaml` の移行方法（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 移行の間は `project-index.yaml` を先に探し、無ければ `dev-docs.yaml` を探す | 各リポジトリを一斉に改名しなくてよい | 2 つの名前を探す処理と、移行を終える時期の判断が残る |
| B | `project-index.yaml` だけを探し、反映作業で各リポジトリの `dev-docs.yaml` を改名する | 探す名前が 1 つで済む | 改名を各リポジトリへ一斉に反映する必要があり、反映する前は管理の `write_nav` などが設定を見つけられない |

推奨: A

端末の設定の `config` で各リポジトリのファイルを直接指定するため配信は名前に依存せず、名前で探すのは管理の `write_nav`・`check_project` などに限られる。各リポジトリの改名はそれぞれの作業で進められる。

`未確定`: 端末の設定の `sources[]` を共有する仕組み（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `sources[]` を project-index が持ち、dev-docs の設定画面は project-index の API で参照・更新する | 原本が 1 つになる | 画面のサーバーが project-index の API に依存する |
| B | 両方が同じ端末の設定ファイルを直接参照・更新する | API が増えない | 書き込みの排他と、スキーマのバージョンの合わせ込みを 2 つで持つ |

推奨: A

Issue の参考の一案と同じで、project-index 側で配信元の行をバージョンつきで追加・変更・削除する API（[project-index#10](https://github.com/shuhei1101/project-index/issues/10)）も計画されている。
