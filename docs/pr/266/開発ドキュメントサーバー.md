## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 再起動のスクリプト | `scripts/` に bash のスクリプトを新規作成し、[要件](./要件.md) の `## 要望` の振る舞いにする | 名前と変わっていないときの扱いはモジュール構成設計で決める |
| モジュール構成 | 先例 MOD-192-1 と同じ種類で、スクリプトの定数（実行時に参照するファイル・記録のファイル・unit 名）と処理の順を記載する | - |
| 単体テスト | `tests/unit/scripts/` に、`git`・`uv`・`systemctl` を `PATH` の先頭のスタブへ差し替えて走らせるテストを作る | 変わった・変わっていない・記録が無い・入れ直しの失敗・起動し直しの失敗 |
| 開発コマンド | 管理作業に、呼び方（作業ディレクトリはリポジトリの直下）・効果・終了コード・確認した記録を追加する | - |
| アーキテクチャ図 | フォルダ構成の `scripts/` の説明に、常駐サーバーを起動し直すスクリプトを追加する | - |
| 既存機能への影響 | 管理の MCP の `restart`・`update` と `dev-docs-server-wait.sh` は変えない | - |
