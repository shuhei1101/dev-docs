## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レイアウト | サイドバーと本文を並べるコンテナの幅の上限を解除し、本文を画面の幅からサイドバー・余白・間隔を除いた幅まで広げる | 文・図・コードも本文の幅まで広げ、文の行の幅に上限を残さない |
| レスポンシブ対応 | 画面幅 48rem 未満のドロワーの並びと、トップバー・種類のタブ・サイドバー・目次の固定は変えない | - |
| 既存機能への影響 | コメントのパネル・差分の案内・はみ出す表の横のスクロールは、広がった本文の幅で今と同じに動く | - |
| モック | 文書の画面のストーリーで、本文と列の多い表を広い画面幅で表示する | - |
