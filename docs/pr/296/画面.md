## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| CSS の移動 | 2 ファイルを `git mv` で `frontend/src/shared/styles/` へ移し、中身は変えない | `index.css` の `@import "./preflight-outside-mdmark.css"` は同じフォルダのため変えない |
| 読み込み元 | `main.tsx` を `@/shared/styles/index.css`、`preview.tsx` を `../src/shared/styles/index.css` にする | - |
| 設定 | `components.json` の `tailwind.css` と `eslint.config.js` の `entryPoint` を `shared/styles/index.css` のパスにする | - |
| 管理用の YAML | `frontend/files.yaml` の 2 行の `path` を `src/shared/styles/` の下にする | 行の他のキーは変えない |
| モジュール構成 | `MOD-155-50`・`MOD-232-1` の `container` を `shared/styles/index.css`・`shared/styles/preflight-outside-mdmark.css` にする | `container` は `frontend/src/` からのパス（`MOD-155-52` の `routes/$source/$.tsx` と同じ） |
| ライブラリ・フォルダ構成 | `LIB-155-19`・`LIB-155-21` の `used_in` を移した後のパスにし、`LAY-275-1` の `preflight-outside-mdmark.css` のエントリを `shared/` の下の `styles/` のフォルダの下へ移す | - |
| 既存機能への影響 | 移す前後で `vite build` が出す CSS が同じであることを、出力の CSS の差分で確認する | Tailwind のクラスの検出元が CSS の配置先で変わらないことの確認を兼ねる |
