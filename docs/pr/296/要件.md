# 要件

## 要望

画面の CSS を、knowledge の規約『Tailwind』（`react-core-tailwind` の `token-01`）と『フォルダ構成』（`react-core-folder-structure` の `roles-01` の `shared/styles/`）のとおり `frontend/src/shared/styles/` へ移す。
画面のビルドが出す CSS と画面の見た目は変えない。

| 移すファイル | 移した後のパス | 移す理由 |
| --- | --- | --- |
| `frontend/src/index.css` | `frontend/src/shared/styles/index.css` | `:root` の 3 ティアのトークン・`@theme inline`・`@layer base` を持つ |
| `frontend/src/preflight-outside-mdmark.css` | `frontend/src/shared/styles/preflight-outside-mdmark.css` | Tailwind の Preflight（要素の既定）で、`shared/styles/` の役割に該当する。`index.css` が同じフォルダから相対パスで読み込む |

パスを持つ次の箇所を、移した後のパスに追随させる。

| 分類 | 箇所 |
| --- | --- |
| 読み込み元 | `frontend/src/main.tsx`、`frontend/.storybook/preview.tsx` |
| 設定 | 直下の `components.json` の `tailwind.css`、直下の `eslint.config.js` の `better-tailwindcss` の `entryPoint` |
| 管理用の YAML | `frontend/files.yaml` の 2 行の `path` |
| 設計書 | `MOD-155-50`・`MOD-232-1` の `container`、`LIB-155-19`・`LIB-155-21` の `used_in`、`LAY-275-1` の `preflight-outside-mdmark.css` のエントリ |

`frontend/src/` の CSS はこの 2 ファイルだけで、同じ規約から逸脱した箇所はほかに無い。
