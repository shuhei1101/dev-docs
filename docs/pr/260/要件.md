# 要件

## 要望

`project-index.yaml` の設計書の 12 行（`architecture`・`nonfunctional`・`scenario`・`interface`・`module`・`screen`・`component`・`config`・`api`・`library`・`test_procedure`・`dev_command`）の `metadata` に `tags: tags[].name`・`main_tags: tags[main].name` を追加する。
`docs/` の各種類のフォルダの設計書（`index.yaml` を除く）の全てに `tags` を記載し、`main: true` を 1 つ付ける。
タグは knowledge の規約『文書のタグと description の記載』『タグと用語の登録』と判定フローチャート『タグの付与』に従い、配信元で使用されているタグ（`group_by: tags`）を再利用する。

終わりの条件は、`search_docs`（`source: dev-docs`・`group_by: tags`）で設計書の 12 種類の文書に `（なし）` が 0 件になること。

種類ごとの主題（`main: true` のタグ）は次のとおり。

| 種類 | 主題 |
| --- | --- |
| `module` | 受け持つ機能の題材（`topic:`） |
| `library` | そのライブラリ（`tool:`） |
| `api` | その外部 API（`tool:`） |
| `interface`・`scenario` | 操作の対象の題材（`topic:`） |
| `screen`・`component` | 画面・部品の題材（`topic:`） |
| `architecture`・`nonfunctional`・`config`・`dev_command`・`test_procedure` | その設計書の種類の題材（`topic:`） |
