# 要件

## 要望

次の範囲の文言を、knowledge の AI slop の単語の対応表（`docs/word-list/word-list-ai-slop.yaml`）に合わせて修正する。

| 範囲 | 対象 |
| --- | --- |
| フックが返却する文言 | `plugins/dev-docs/hooks/session_start.py` が `additionalContext` へ返却する文と、文へ入る例外の文言 |
| 文言を共有する設計書 | 修正する文言を引用する、または文言の中身（`/mcp` の再接続の案内・`repeat_seen: true` で再取得できる案内）を指すインターフェース定義・モジュール構成・単一ユースケースのシナリオの項目 |
| 文言を照合するテスト | 修正する文言を照合する結合・E2E テスト |

終わりの条件は、上の範囲で対応表の `pattern` にヒットする箇所（`allow` の単語を除く）が 0 件になること。
置き換え先は PR #133 で決めた置き換え（`使用する`・`再接続する`・`読み込む`・`返却する`・`再取得する`）と統一する。

箇所ごとの修正前後は次のとおり。

| 箇所 | 修正前 | 修正後 |
| --- | --- | --- |
| `RECONNECT_GUIDE` | `このセッションで文書の MCP を使うには /mcp で dev-docs につなぎ直してください。` | `このセッションで文書の MCP を使用するには /mcp で dev-docs に再接続してください。` |
| `request_forget` の `ValueError` | `応答が読めません` | `応答を読み込めません` |
| `_forget_context` の失敗の文 | `dev-docs の返し済みの記録を削除できませんでした（{detail}）。` | `dev-docs の返却済みの記録を削除できませんでした（{detail}）。` |
| `_forget_context` の失敗の文 | `前に返した文書は repeat_seen: true で取り直せます。` | `前に返却した文書は repeat_seen: true で再取得できます。` |

`_unavailable` の `端末の設定を作ってください`・打ち切りの `{FORGET_TIMEOUT_SEC} 秒で打ち切りました`・`main` の `dev-docs のフックが失敗しました（{error}）。` と `dev-docs を起動しました。`・`dev-docs を起動できませんでした（{reason}）。` は、対応表の `pattern` にヒットしないため変えない。
