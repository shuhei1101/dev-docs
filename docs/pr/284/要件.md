`docs/generated/` を前提にする記載は 4 か所とも削除する。
dev-docs には `docs/generated/` へ出力するコマンド・コードが無く、残す理由が無い。

`tmp/` は、中身が `*` だけの `.gitignore` を `tmp/` に配置して Git の管理から除外し、直下の `.gitignore` の `tmp/storybook-static/`・`tmp/pages/` の行を削除する。
`tmp/.gitignore` 自身も `*` に該当するため、`git add --force` で追加する。
