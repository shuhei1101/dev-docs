# 既存の文書を mdmark の書き方と表し方の優先順位に移行する

## 概要

dev-docs の `docs/` の文書を、mdmark の書き方と「図 → 表 → 箇条書き → 文」の優先順位に統一し、タグ・エイリアス・用語・`description` を今の規約で付け直す。

## 背景

[Issue #95](https://github.com/shuhei1101/dev-docs/issues/95) の要望。
dev-docs への移行で文書の配信は統一したが、文書の中身は旧い書き方（Mermaid の図・文の羅列・古いタグ・AI slop の単語）のままのものが多い。
[Issue #93](https://github.com/shuhei1101/dev-docs/issues/93) から、`docs/` の文書の AI slop の修正を移管している。
