## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図 | YAML の設計書の手で記載した Mermaid は、dev-docs の変換（`render_mermaid`）が map の範囲で囲むため、元の文書は変えない。Markdown のガイドの Mermaid だけを map の範囲で囲む | 図の中のラベルに内部の ID を出さない |

| `lead` | 「何を定め、どんなときに読むか」の 1 文にし、Issue 番号を出さない | - |
| 本文の参照 | Issue 番号・文書のパスをタイトル付きのリンクへ移す | 設計書どうしの `{ID}#{項目のパス}` の参照は変えない |
