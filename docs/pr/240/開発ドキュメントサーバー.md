## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のキー | 端末の設定 `settings.yaml` の `mdmark_version`（既定 `develop`。タグ・commit を書くとそのバージョンに固定する） | CFG-155-2 |
| 設定のスキーマと雛形 | `src/dev_docs/schemas/settings.schema.yaml` に `mdmark_version`（CFG-155-2 の `allowed` のパターン: `^(develop|v\d+\.\d+\.\d+|[0-9a-f]{7,40})$`）を追加し、`templates/settings.yaml` に記載例（コメントで `develop`）を置く。`load_terminal_config` が値を `TerminalConfig` に渡す | MOD-155-146 |
| 画面への受け渡し | 画面の配信が `index.html` の `<head>` に `<meta name="mdmark-version" content="{値}">` を入れる | IF-155-18 |
| 公開ページのビルド | `build_pages.py` の `MDMARK_TAG` を `MDMARK_REF`（既定 `develop`）にし、`npx` の参照と `mdmark.config.yaml` の `version` に使う。固定するときは定数を書き換える | MOD-192-1。`version` の `develop` は mdmark#621 の要件 |
| 結合テストの mdmark の CLI | `devDependencies` から mdmark を外し、文書の取得の結合テスト（`test_get_document.py`）が実行時に `npx -y github:shuhei1101/mdmark#{MDMARK_REF}` で CLI を取る。`MDMARK_REF` はテストのファイルの先頭の定数（既定 `develop`）で、固定するときは書き換える | `build_pages.py` の `MDMARK_REF` と同じ取り方と名前。`package-lock.json` から mdmark の行が消える |
| 既存の設定 | キーを足しても今の `settings.yaml` はそのまま読める（必須にしない） | `SETTINGS_VERSION` を上げない |
