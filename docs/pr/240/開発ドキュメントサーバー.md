## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のキー | 端末の設定 `settings.yaml` の `mdmark_version`（既定 `develop`。タグ・commit を書くとそのバージョンに固定する） | CFG-155-2 |
| 画面への受け渡し | 画面の配信が `index.html` の `<head>` に `<meta name="mdmark-version" content="{値}">` を入れる | IF-155-18 |
| 公開ページのビルド | `build_pages.py` の `npx` の参照と `mdmark.config.yaml` の `version` を、既定で develop の最新にし、固定の値を受け取れるようにする | `version` に develop の最新を書けるかは mdmark#620 に合わせる |
| 結合テストの mdmark の CLI | `devDependencies` から mdmark を外し、文書の取得の結合テストが実行時に `npx -y github:shuhei1101/mdmark#{参照}` で CLI を取る。既定の参照は develop の最新 | `build_pages.py` と同じ取り方にし、固定の書き方を揃える。`package-lock.json` から mdmark の行が消える |
| 既存の設定 | キーを足しても今の `settings.yaml` はそのまま読める（必須にしない） | `SETTINGS_VERSION` を上げない |
