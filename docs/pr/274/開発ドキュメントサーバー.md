| 対象 | 方針 | 補足 |
| --- | --- | --- |
| シナリオ名・項目名 | `write_docs` の `update` で `title`・項目名を要件.md の表の名前にし、参照している側（`SC-155-13` の図のラベル・`click`・`refs`、`docs/scenario/index.yaml`）を `replace_text` で統一する | `README.md` は `index.yaml` から再生成する |
| `test_file` | 改名後のシナリオ名に合わせる（`test_{title}.py`） | - |
| モジュール構成・インターフェース定義 | `MOD-155-174`・`MOD-155-207` のクラス名、`MOD-155-214` の項目名、`IF-155-7`・`IF-155-10` の記載を `replace_text` で改名する | `MOD-155-207` の `click` のリンクのアンカーも合わせる |
| docstring | 改名後の設計書の項目名に合わせる | 挙動は変えない |
