## 要望

[docs/pr/210/反映作業/dev-docs のサーバーの再起動/確認.sh](https://github.com/shuhei1101/dev-docs/blob/f66052b/docs/pr/210/%E5%8F%8D%E6%98%A0%E4%BD%9C%E6%A5%AD/dev-docs%20%E3%81%AE%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC%E3%81%AE%E5%86%8D%E8%B5%B7%E5%8B%95/%E7%A2%BA%E8%AA%8D.sh) の文書の取得の判定を、次のとおりに修正する。

| 項目 | 要件 |
| --- | --- |
| 待ち | 文書の取得（`GET /_api/sources/dev-docs/docs/docs/interface/IF-155-19`）が HTTP 200 で空でない本文を返却するまで、上限つきで取り直す。上限の値は実装で規約『資源の値の決め方』から導く |
| 判定 | HTTP 200 で空でない本文を得たときだけ、`<!-- map: ` の個数と廃止した部品の範囲（`<!-- flow -->`・`<!-- sequence -->`・`<!-- er -->`）の個数で判定する |
| 失敗時の出力 | 上限まで HTTP 200 で本文を得られなかったときと、判定が通らなかったときは、`failed` の行の後に、実行したコマンドと最後の HTTP の状態・応答の先頭 200 字を出力する |
| テンプレートへの統一 | テンプレート『PRドキュメント/反映作業スクリプト』の `## 共通` の結果の行（`{手順}: {結果}`）と `failed` の行の後の出力、`## 確認` の参照だけで観測することに合わせる。前半の端末の設定の取得も同じ構造に統一する |

確認方法（[index.yaml](https://github.com/shuhei1101/dev-docs/blob/f66052b/docs/pr/210/%E5%8F%8D%E6%98%A0%E4%BD%9C%E6%A5%AD/index.yaml) の `確認方法`）とスクリプトのパスは変えない。
