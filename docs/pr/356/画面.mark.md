| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの参照 | `project-index.yaml` の `design-schemas/v9.2.2` を全て `design-schemas/v12.0.0` にする | 画面設計書・部品設計書を記載し直した commit と同じ commit で上げ、どの commit でも検査に合格させる |

| 要素の欄 | 要素の種類ごとに必須になった欄を埋め、アイコン・狭い幅・保持する状態・閉じ方とフォーカス・押した後の振る舞い・URL の履歴・ショートカットを今の実装から記載する | 値はテンプレート『画面設計』の `x-rules` と、そこが参照する規約（レイアウト・キーボード操作・入力と文言 等）で決める |

| 気づいた漏れの修正 | 記載する値が今の実装の振る舞いと規約で食い違う箇所は、規約に合う側で設計を決め、実装・単体テスト・結合テストまで修正する | 修正した箇所の一覧を、この計画書の `## 実装` に記載する |
