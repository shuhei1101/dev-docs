# 要件

## 要望

トップバーの配信元のメニューとリビジョンのメニューを、開いたボタンの幅に合わせず、中身の幅で開く。

- 項目（配信元の ID と権限、ブランチ名、タグ名、commit と題名、「別のリビジョンと比較」）を 1 行で表示し、折り返さない
- 一覧の幅はボタンより広くなってよい
- 一覧の幅は、メニューを開いた位置から使用できる画面の幅を超えない。超える長さの項目は、末尾を省略して 1 行に収める
- 幅 390px の画面でも横スクロールが出ない

幅の指定はトップバーの 2 つのメニューの `DropdownMenuContent` にだけ指定し、shadcn から追加した共通の部品の既定は変えない。
