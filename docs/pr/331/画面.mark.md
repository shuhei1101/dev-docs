## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| メニューの幅 | 配信元・リビジョンのメニューを中身の幅（`w-auto`）で開き、上限を Base UI の Positioner が渡す使用できる幅（`max-w-(--available-width)`）にする | 指定はトップバーの 2 つのメニューの `DropdownMenuContent` だけにする。任意値（`max-w-[calc(...)]`）は規約『Tailwind』で禁止のため使用しない |
| 項目の折り返し | 項目の文字列に `whitespace-nowrap` を付け、上限を超える項目は `truncate` で末尾を省略する | commit の題名は今の `truncate` を保つ |
| レスポンシブ対応 | 幅 390px で開いても一覧が画面の外へはみ出さず、横スクロールが出ない | - |
| ストーリー | 長い配信元の ID・ブランチ名・commit の題名を持つ状態を部品設計に追加し、ストーリーにする | - |
| 結合テスト | メニューを開き、一覧の幅がボタンの幅以上であること・項目が 1 行であること・幅 390px で横スクロールが出ないことを確かめる | 既存の `noHorizontalScroll` を使用する |
