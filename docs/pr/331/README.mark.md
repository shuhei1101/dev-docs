# トップバーの配信元とリビジョンのメニューを、項目が折り返さない幅で開く

## 概要

利用者が、トップバーの配信元・ブランチ・タグ・最近の commit の一覧を、項目が折り返さない幅で読めるようにする。

## 背景

[Issue #326](https://github.com/shuhei1101/dev-docs/issues/326) の不具合。
トップバーの配信元のメニューとリビジョンのメニューが、共通の部品 `DropdownMenuContent` の `w-(--anchor-width)`・`min-w-32` で開いたボタンと同じ幅になり、配信元の ID・ブランチ名・commit の題名が何度も折り返す。
配信元のボタンは ID を切り詰めて細いため、一覧も 8rem 前後で開く。
