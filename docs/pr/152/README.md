# 今ある E2E のテストと、E2E だけが使う部品を develop から削除する

## 概要

develop から、今ある E2E のテストと E2E だけが使う部品を削除する。設計書のシナリオは残す。

## 背景

[Issue #145](https://github.com/shuhei1101/dev-docs/issues/145) の要望（決定 D-311 A）。
0.x の間は E2E を回さず修正もしない（D-307 A）ため、今ある E2E は仕様の変更で古くなり、エージェントが参照して誤解するノイズになる。
E2E はメジャーのリリースの前に、全体の仕様が固まった状態でまとめて作り直す。
