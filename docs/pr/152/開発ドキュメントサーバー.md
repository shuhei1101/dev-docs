## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| E2E のテスト | `tests/e2e/` を丸ごと削除する | ほかのテストから参照されていない |
| 開発用の依存 | `pyproject.toml` の `[dependency-groups] dev` から `playwright` を外し、`uv lock` で `uv.lock` を作り直す | npm の Playwright は結合テスト（フロント）が使うため残す |
| `.gitignore` | `.e2e/` の行を削除する | - |
| テスト実行方法 | E2E テストの層は `name` を残し、`run_all` を `未確定` にして他のキーを削除する | 外部疎通テスト・非機能要件テストと同じ形 |
| 外部ライブラリ playwright | `lead`・`purpose` を結合テスト（フロント）の用途に直し、`used_in` を `tests/integration/frontend/playwright.config.ts` と `tests/integration/frontend/` にする | `index.yaml`・`README.md` の概要も合わせる |
| 確認 | 単体テスト・結合テスト（バック・フロント）の全件と lint を流す | - |
