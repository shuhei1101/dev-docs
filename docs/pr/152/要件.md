# 要件

## 要望

develop から、今ある E2E のテストと、E2E だけが使う部品を削除する。

| 対象 | 扱い |
| --- | --- |
| `tests/e2e/`（`conftest.py`・単一ユースケース 12 本・複合ユースケース 1 本） | 削除する |
| `pyproject.toml` の開発用の依存の Python の `playwright` と `uv.lock` の対応する行 | 削除する（E2E だけが import する） |
| `.gitignore` の `.e2e/` | 削除する（E2E の結果の退避先） |
| 設計書『テスト実行方法』の E2E テストの層 | 実行方法を削除し、`run_all` を `未確定` にする |
| 設計書『外部ライブラリ』の playwright | 用途と `used_in` を結合テスト（フロント）に合わせる |
| シナリオと `test_file` | 残す（作り直すときの対応の印） |

終わりの条件は、`tests/e2e/` が無い状態で単体テスト・結合テスト（バック・フロント）の全件と lint が通ること。
