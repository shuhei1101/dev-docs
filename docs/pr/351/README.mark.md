# 上部バーの「編集中」を「レビュー中」にし、文書の画面のパンくずに入れ子のグループを全て並べる

## 概要

利用者が、溜めた変更を確認してコミットするパネルを「レビュー中」のボタンとパネルとして見分けられ、入れ子のグループの中の文書を開いたときにパンくずで外側から内側までのグループをたどれるようにする。

## 背景

[Issue #350](https://github.com/shuhei1101/dev-docs/issues/350) の束（[#346](https://github.com/shuhei1101/dev-docs/issues/346)・[#349](https://github.com/shuhei1101/dev-docs/issues/349)）の要望。
トップバーの変更を溜めるパネルを開くボタンとパネルの見出しが「編集中」で、利用者から何のボタンか分かりづらいと指摘があった。
[#347](https://github.com/shuhei1101/dev-docs/pull/347) でサイドバーのグループを入れ子にしたが、文書の画面のパンくずは `nav.ts` の `findPage` が入れ子の group へ降りるたびに名前を上書きし、いちばん内側のグループしか出さない。
