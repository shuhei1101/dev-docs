## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| トップバーのボタン | 表示を `レビュー中`、読み上げ名を `レビュー中 {件数} 件`（0 件は `レビュー中`）にする。アイコン・件数・狭い幅で文言を除く振る舞いは変えない | - |
| パネル | 見出し（読み上げ名）を `レビュー中` にし、部品の名前を「レビュー中のパネル」にする | パネルの中の「編集中の変更」の文言は残す |
| 開いているページの取得 | `ActivePage.group` を、タブの直下から開いている文書までの group の名前を外側から順に並べた配列（group に入っていなければ空）にする | 名前の変更はモジュール構成設計で決める |
| パンくず | 配信元の ID・タブ名の後ろに group の並びを外側から順に並べ、末尾に文書の名前を並べる。group はリンクにしない | 文書の無いタブを選んだときの表示は変えない |
| ストーリー | ボタン・パネルの名前を合わせ、入れ子の group の中の文書を開いた文書の画面のストーリーを追加する | - |
| テスト | ボタン・パネルを探す名前を `レビュー中` にし、パンくずの入れ子の group の単体テスト・結合テストを追加する | - |
| アクセシビリティ | パンくずの読み上げ名 `パンくず` と末尾の `aria-current="page"` を保つ | - |
| 既存機能への影響 | サイドバーの開閉・現在地の表示は `findPage` と別の処理で、変えない | - |
