# 要件

## 要望

トップバーの変更を溜めるパネルを開くボタンとパネルの名前を「レビュー中」にし、文書の画面のパンくずに入れ子のグループを外側から内側まで全て並べる。

| Issue | 終了の条件 |
| --- | --- |
| [#346](https://github.com/shuhei1101/dev-docs/issues/346) | ボタンとパネルの名前が「レビュー中」になり、画面の文言・設計書（部品設計・画面設計など）・用語集・テストの同じ意味の「編集中」が合わせてある |
| [#349](https://github.com/shuhei1101/dev-docs/issues/349) | 入れ子のグループの中の文書を開いたとき、パンくずに外側から内側までのグループが全て並ぶ |

- トップバーのボタンの表示を `レビュー中`、読み上げ名を `レビュー中 {件数} 件`（0 件のときは `レビュー中`）にし、パネルの見出し（読み上げ名）を `レビュー中` にする
- ボタン・パネルの名前を指す箇所（部品設計・画面設計・モジュール構成・シナリオ・利用者向けのガイド・用語集・単体テスト・結合テスト・ストーリー）を同じ名前に合わせる
- パンくずは `{配信元の ID}` / `{タブ名}` / `{外側の group の名前}` / … / `{内側の group の名前}` / `{文書の名前}` の順に並べる。group はリンクにせず、group の階層の数を制限しない
- group に入っていない文書のパンくずは今のまま `{配信元の ID}` / `{タブ名}` / `{文書の名前}` にする

溜めた変更そのものを指す用語「編集中の変更」は残し、ボタンとパネルの名前だけを「レビュー中」にする（[確認事項](https://github.com/shuhei1101/dev-docs/pull/351#discussion_r4726529558)）。
