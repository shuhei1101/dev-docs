# 要件

## 要望

直下の `project-index.yaml` の `nav` を、knowledge の規約 [開発ドキュメントのナビゲーション](https://docs.shuhdev.com/knowledge/docs/rule/dev-docs-navigation.yaml) と判定フローチャート [サイドバーのグループの分け方](https://docs.shuhdev.com/knowledge/docs/flowchart/flowchart-sidebar-group-split.yaml) に従って入れ子にする。

- 名前を `/` で区切って並べたグループを、上の階層の `group` の子の `group` にする
  - タブ「設計書」: `モジュール構成` の下に `画面`・`開発ドキュメントサーバー`・`管理用プラグイン・開発用のスクリプト`
  - タブ「コード」: `テスト` の下に `単体`・`結合・E2E`
- 他のグループも判定フローチャートで分けるかと分ける軸を判定し、分けると判定したグループは入れ子にする
- 入れ子は 2 階層まで、上の階層は利用者の作業か機能の単位にする
- 目次（`kind: index`）をタブとサイドバーに並べない
- 修正した後、dev-docs の画面で配信元 dev-docs の各タブのサイドバーをスクリーンショットで撮り、入れ子のグループが 2 階層までで、修正前に並んでいた文書が全てサイドバーに残っていることを確認する
