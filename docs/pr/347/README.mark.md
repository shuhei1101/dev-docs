# 開発ドキュメントのサイドバーで、名前を / で区切って並べたグループを入れ子にする

## 概要

dev-docs の画面のサイドバーで、利用者が入れ子のグループから文書を探せるようにする。

## 背景

[Issue #345](https://github.com/shuhei1101/dev-docs/issues/345) の要望。
project-index の `nav` の `group` は子の `items[]` に `group` を持てるようになったが、この配信元の `project-index.yaml` の `nav` は 1 段のグループだけで、`モジュール構成 / 画面`・`テスト / 単体` のように名前を `/` で区切って階層を表している。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.mark.md) | 要望の整理と変更箇所の由来 |
| [画面](./画面.mark.md) | 画面のサイドバーに出す配信元の設定の計画書 |
