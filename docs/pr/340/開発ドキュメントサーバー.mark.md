## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 横断の検索 | 配信中の全ての配信元を検索し、結果の行に配信元の ID と名前を付けて返却する。配信できない配信元は結果から除き、除いた配信元を応答で示す | `未確定`。取得の方法は `要件.mark.md` の論点（インターフェース定義設計で決める） |
| 並び順の根拠 | 結果の行に一致した行の数を持たせ、その多い順に並べて返却する | project-index が返却しない場合は dev-docs で数える |
| 既存の配信元ごとの検索 | `GET /_api/sources/{source}/search` の入出力と、`include_excluded`・`excludedCount` の振る舞いを保つ | - |
| タイムアウト | project-index への問い合わせの制限時間（非機能要件）を、横断の検索の全体にも適用する | 値は非機能要件の既存の値を使用する |
