## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 横断の検索 | 横断のエンドポイントは持たない。画面が配信中の配信元ごとに `GET /_api/sources/{source}/search` を `ref` を指定せずに呼んでまとめる | 配信していない配信元は端末の設定の状態（`not_served` と理由）から画面が出す |
| 並び順の根拠 | 結果の行に一致した行の数（`items[].matchCount`）を持たせる。数えるのは project-index で、dev-docs はそのまま返却し、無いときは `null` にする。並べ替えは画面で行う | 契約は [shuhei1101/project-index#299](https://github.com/shuhei1101/project-index/issues/299)、本物につなぐ作業は [#341](https://github.com/shuhei1101/dev-docs/issues/341) |
| 既存の配信元ごとの検索 | `GET /_api/sources/{source}/search` の入出力と、`include_excluded`・`excludedCount` の振る舞いを保つ | - |
| タイムアウト | 配信中の全ての配信元へ同時に送信し、全体を待つ上限は設けず配信元ごとに打ち切る（非機能要件『配信元の横断の検索の問い合わせ』） | 1 つの配信元を待つのは project-index への問い合わせの制限時間の 2 回分 |
| 配信中の配信元の検索の失敗 | 配信元ごとの検索が失敗・時間切れになったときは、その配信元の応答（503・404 の `detail`）を画面が「検索できなかった配信元」に理由つきで出し、ほかの配信元の結果は出す | サーバーの応答の構造は変えない |
