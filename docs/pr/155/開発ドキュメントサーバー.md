## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の移動 | [要件](./要件.md) の対応表のとおり、種類のフォルダへフラットに移し、ファイル名を `{ID}.yaml`（モジュール構成は `{ID}.py.yaml`）にする | ID の振り方は [要件](./要件.md) |
| 分類 | モジュール構成のサブフォルダ（`features/{機能}/` など）は持たない。分類は今の title（`{サブシステム} / {分類} / {ファイル}`）に残る | 目次の `group` は使用しない |
| 参照 | 設計書どうしの参照（`dev/設計書/...#{項目のパス}`）と本文のリンクを `{ID}#{項目のパス}`・`[名前](id:{ID})` に書き換える | 書き換えの漏れは設計書の検証で確認する |
| 既存機能への影響 | コードとテストを変えないため、配信・読み書きの振る舞いは変わらない | - |
