### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| バージョンの送信 | 取得の応答の `version` を記録し、保存の要求に `expectedVersion` として含めて送信する。保存の 200 の応答の `version` で記録を更新する | 追加・編集・削除・配信の停止のどの保存も同じ |
| 409 の扱い | 保存が 409 を返却したら、端末の設定を取得し直し、ほかの書き換えが入ったことを利用者に示す | 示し方は [要件](./要件.md) の `未確定`（決める段: モック作成） |
| outsideRead の表示 | 配信元の一覧の行に、`outsideRead` が `false` の配信元を区別できる表示を出す | 表示の形状はモック作成で決める |
| outsideRead の変更 | 配信元のダイアログに `outsideRead` の入力欄を追加し、保存の要求の `sources[].outside_read` に入れる。既定は `true` | 入力欄の形状はモック作成で決める |
| 既存機能への影響 | 422・502・503 の表示と、配信元の追加・編集・削除の操作は変えない | - |
