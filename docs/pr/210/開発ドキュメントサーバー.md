### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 取得の応答 | GET `/_api/settings/sources` が、project-index の GET `/settings/sources` の内容のバージョンを `version` で返却する | - |
| 保存の要求 | PUT `/_api/settings/sources` が任意の `expectedVersion` を受け、project-index の PUT `/settings/sources` の `expectedVersion` に指定する。指定しない要求はこれまでどおり照合せずに保存する | - |
| 保存の応答 | 200 の応答に、保存した後の内容のバージョンを `version` で返却する | 続けて保存するときに取得し直さずに済む |
| 409 の返却 | project-index が 409 を返却したら、`application/problem+json` の 409 と、project-index の今の内容のバージョン（`current`）を返却する。端末の設定は変わらない | 422・502 の扱いは変えない |
| outsideRead の保存 | `sources[].outside_read` の `status: planned` を解除し、`false` の行だけ project-index へ `outside_read` で送信する今の実装をインターフェース定義に合わせる | 送信するキーは [#203](https://github.com/shuhei1101/dev-docs/issues/203) と同じく本物の project-index の `outside_read` |
| 外部 API | API-155-1 の GET・PUT `/settings/sources` に内容のバージョン・`expectedVersion`・409 の `current` を記載する | PUT の行のキー（`outside_read`）の修正は #203 が持つ |
| 結合テストの project-index | 本物の project-index を起動する結合テストの commit を `7177d39`（shuhei1101/project-index#29 の後）にする。409 は project-index のモックで確かめる | `version` を返す版が要る |
| 既存機能への影響 | `expectedVersion` を指定しない保存（`dev-docs migrate` 以外の呼び出しを含む）の入出力は変えない | - |

### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ER 図 | `x-diagram: er` の値を、実体をテーブル・列を列の行（キー・名前・型・説明）・関連を多重度つきの線にした `erDiagram` にし、`<!-- map: {"title": …} -->` 〜 `<!-- /map -->` の範囲で出す。列の説明・関連の `label` は補足（`<!-- map-data -->`）の `notes` に入れる。関連の線を `er.relations` の端の列につなぐため、FK の側の列の Mermaid のコメントを `参照: {相手のテーブル}.{相手の列}` にする（mdmark は関連の端の列を、このコメントを持つ FK の列から先に選ぶ）。端の列が実体の列に無い関連は `erDiagram` に出さず、図の元データの表にだけ残す | 多重度の値と Mermaid の記号の対応はモジュール構成設計で決める |
| 状態遷移図 | `x-diagram: state` の値を `stateDiagram-v2` にし、`<!-- map -->` の範囲で出す。`initial` は `[*] -->`、`final` は `--> [*]`、`ALL_STATES`・`PREVIOUS_STATE` は今と同じく `representative` の状態へ置き換える。遷移のラベルは `{trigger} [{condition}]` のまま | 遷移の再生は補足に `walkthroughs` を記載せずに mdmark の既定（記載順に 1 本ずつ）にする |
| フロー系の図 | `x-diagram` の `flowchart`・`dataflow`・`architecture` と手で書く Mermaid の `flowchart` を、`flowchart` のまま `<!-- map -->` の範囲で出す。ノードの種類は Mermaid のクラス、線の種類は補足の `layout` の `line`、ノードの `hint` と線の `tip` は補足の `notes`、`frame` は `subgraph` にする | mdmark の `retired-diagrams` の移行と同じ対応 |
| シーケンス図 | 手で書く Mermaid の `sequenceDiagram` を、そのまま `<!-- map -->` の範囲で出す | - |
| 座標の配置 | map が自動で配置するため、`flow_layout.py`・`ER_LAYOUT` と、手で書く Mermaid を中間データにする読み取りのうち使用されなくなる部分を削除する | 削除の範囲はモジュール構成設計で決める |
| 図の見出し | `DiagramHead` の `title` を map の `title` にする。`scope`・`updated` は map に対応するキーが無い | 移行で写さない値（mdmark の移行の報告と同じ） |
| ノードと線の種類の設定 | mdmark はノードと線の種類を持たないため、dev-docs が使用するクラス名と線の名前の `map.kinds`・`map.lines` を、画面が `mount` に指定する設定と、結合テストの点検・公開ページのビルドの設定に記載する | 配置先はモジュール構成設計で決める |
| mdmark のバージョン | `package.json` の `devDependencies` と `scripts/build_pages.py` の `MDMARK_TAG` を `v0.13.0` にする | 画面の `MDMARK_URL` は [画面](./画面.md) |
| 外部ライブラリ | LIB-155-9 の採用バージョンを `v0.13.0` にし、`<!-- flow -->` の記法の行を `<!-- map -->` の記法の行に置き換え、`verification` を `v0.13.0` で確認した結果にする | - |
| 既存機能への影響 | 図の元データの表と、`converters[]` で変換する種類の Markdown は変えない | - |
