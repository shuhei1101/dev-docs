### #348 画面の表・コメントの置き換え

次の箇所を mdmark の部品のカスタム要素に置き換え、置き換えた画面の画面設計・部品設計・モジュール構成を合わせる。

| 箇所 | 今の部品 | 置き換え先 |
| --- | --- | --- |
| メタデータの画面の種類ごとの表 | `metadata-table.tsx`（shadcn の `Table` と行の中の編集・追加・削除） | `<mdmark-table>` |
| 設定画面の配信元の一覧 | `source-table.tsx`（tanstack-table と shadcn の `Table`） | `<mdmark-table>` |
| 文書の画面の YAML の項目の表のセル | `doc-field-editor.tsx` の表 | `<mdmark-table>` |
| 文書の画面のコメントのパネル | `comment-panel.tsx`（溜めたコメントの一覧・コピー・起票） | `<mdmark-comments>` か、置き換えられる部分だけ |

- 上の一覧は調べた範囲で、設計の中でほかに置き換えられる箇所（ボード・グラフ・図）が見つかれば含める
- 置き換えで増える機能（ピン止め・列の幅の変更・テーブル設定など）は使用する
- 置き換えの前に、今の部品の機能（列の固定・並べ替え・絞り込み・行の選択・行の中の編集・追加・削除・キーボード操作・狭い幅での出し分け・独自の列の描き方・コピー・起票 など）を箇所ごとに洗い出し、カスタム要素の機能で全てが保てるかを突き合わせる
- 1 つでも保てない機能があれば、その箇所の置き換えを進めず、`議論中` で利用者と mdmark 側の対応（オプションの機能として追加する・既定で持たせる）を決める

### #352 用語集の「編集中の変更」

用語集の「編集中の変更」の行の説明を、メタデータの画面で編集した行と、文書の画面で編集した文書の本文の両方の、まだコミットしていない変更とする。
用語「編集中の変更」とボタンの名前 `レビュー中` はそのまま残す。
