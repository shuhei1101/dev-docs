## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 機能の突き合わせ | 置き換える箇所ごとに今の部品の機能を洗い出し、`<mdmark-table>`・`<mdmark-comments>` のプロパティ・イベント・キーボード操作で全てが保てるかを表にする | 保てない機能が 1 つでもある箇所は置き換えを進めず、`議論中` で利用者と mdmark 側の対応を決める |
| メタデータの種類の表 | `<mdmark-table>` に列の定義と行のデータを指定し、行の中の編集を `columns[].editable` と `mdmark-cell-edit`、行の追加を `features.add` と `mdmark-row-add` で受ける | 行の削除・編集中の行のマーカーは `columns[].render` で描けるかを突き合わせで確認する |
| 配信元の一覧の表 | `<mdmark-table>` に置き換え、行の押下を `mdmark-row-click`、状態のバッジと操作のボタンを `columns[].render` で描く | tanstack-table を使用しなくなれば依存と外部ライブラリの設計書を削除する |
| YAML の項目の表のセル | 表の項目を `<mdmark-table>` にし、セルの修正を `mdmark-cell-edit` で受ける | スキーマの型から選んだ入力欄（選択肢・真偽など）を保てるかを突き合わせで確認する |
| コメントのパネル | 溜めたコメントの一覧・コピー・起票のうち、`<mdmark-comments>` が受け持てる部分を置き換える | `<mdmark-comments>` は本文へコメントを付ける要素で、一覧・コピー・起票は持たない。置き換えられる部分が無ければ、その判断を突き合わせの表に残す |
| 増える機能 | ピン止め・列の幅の変更・テーブル設定（列の表示・並べ替え）・件数を付ける | 画面設計の表の要素の振る舞いに記載する |
| mdmark の読み込み | カスタム要素は今の `use-mdmark.ts` の読み込みで登録されるものを使用し、要素を描く前に読み込みを待つ | 読み込めないときの表示は今の本文と合わせる |
| 設計書 | 画面設計の表・パネルの要素の `component`・振る舞いと、モジュール構成を置き換え後の部品に合わせる | 外部ライブラリの設計書『mdmark』に部品のカスタム要素の利用方法を追加する |
| 既存機能への影響 | 編集中の変更への溜め方・差分確認・直コミットの流れは変えない | 単一 UC シナリオは変えず、結合テストで回帰を確認する |
| アクセシビリティ | 行のフォーカス・↑↓・Enter・F2・Esc の操作をカスタム要素に統一する | 今のショートカットの一覧と重ならないかを確認する |
| レスポンシブ対応 | 狭い幅で今の出し分け（列を隠す・カードにする など）を保つ | 保てなければ突き合わせの表に記載する |
