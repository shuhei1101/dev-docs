## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文字色 | `alert.tsx` の `destructive` の variant で、説明文（`AlertDescription`）の文字色を `text-destructive/90` から `text-card-foreground` にする。見出し・アイコン・枠線と、`AlertDescription` を通らない 1 文だけの中身は `text-destructive` のまま | 短い見出しと 1 文は axe の基準を満たす状態色のまま残し、説明文・一覧・ボタンは本文の色にする。コントラストは明 17.9:1・暗 17.2:1 |
| 使用する側の上書き | `project-index-unreachable.tsx` の説明文・一覧・ボタンの `text-foreground` の上書きを削除する | variant と同じ役割になるため（規約『デザインスタイル』の「使用する側のクラスで上書きしない」） |
| 見た目の方向 | 状態色 `--destructive` の役割（削除・エラー）を保ち、デザイン方針の色の役割を変えない | - |
| アクセシビリティ | 対象の 4 つの表示の Storybook のストーリーで、a11y アドオンの `color-contrast` の違反を 0 件にする | - |
| 既存機能への影響 | 文言・要素・操作は変えない | - |
