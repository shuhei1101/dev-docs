## 要望

shadcn の `Alert` の `destructive` の variant で描くエラーの表示の説明文・一覧・ボタンの文字色を、明暗の両方で axe の `color-contrast`（文字の大きさに応じて 4.5:1 か 3:1）の違反が 0 件になる色にする。

対象は同じ variant を使用する次の表示で、同じ型の逸脱としてまとめて修正する。

| 共通 | project-index から受け取れなかったことの警告 | [project-index-unreachable.tsx](https://github.com/shuhei1101/dev-docs/blob/4e9542d7c7a7f425dd0b270d8ec756feac1a8f37/frontend/src/shared/components/project-index-unreachable.tsx#L67) |
