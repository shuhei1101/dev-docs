# 要件

## 要望

共有の UI 部品（`frontend/src/shared/components/ui/`）の `destructive` の文字と背景のコントラストを axe の `color-contrast` の基準に合わせ、高さを含む transition の指定を Impeccable の `layout-transition` に該当しない指定にする。

| Issue | 終わりの条件 |
| --- | --- |
| [#165](https://github.com/shuhei1101/dev-docs/issues/165) | バッジ「配信停止」（`badge.tsx` の `destructive`）と、同じ指定を持つボタンの `destructive`（`button.tsx`）が、axe の `color-contrast` の基準を満たす |
| [#166](https://github.com/shuhei1101/dev-docs/issues/166) | 設定の画面で高さを transition で動かしている部品が、Impeccable の `layout-transition` に該当しない transition の指定になる |

明暗の両方で、`detect_screen_issues` の 1280x800・768x1024・390x844 に上の 2 つのルールが当たらないことを確かめる。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `badge.tsx`・`button.tsx` の `destructive` の variant と、`badge.tsx`・`button.tsx`・`switch.tsx`・`tabs.tsx` の `transition-all` | [58048a5](https://github.com/shuhei1101/dev-docs/commit/58048a5)（`画面（文書・設定・見つからない画面）を React（Vite + shadcn/ui）の SPA で作る (#36)`） | shadcn の CLI が追加した部品の既定の指定のまま置いた（コントラストと transition の対象を検討して決めた値ではない） | 1 回 | 指定を直してもこの目的を壊さない。`index.css` の `--destructive` を変える場合は、`alert.tsx`・`dropdown-menu.tsx`・入力欄の `aria-invalid` の色も変わる |
