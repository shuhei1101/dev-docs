## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `destructive` のコントラスト | `badge.tsx`・`button.tsx` の `destructive` の文字と背景が、明暗の両方で axe の `color-contrast`（小さい文字の 4.5:1）を満たす指定にする | variant だけを直すか `--destructive` の値を直すかは設計で決める。`--destructive` を直す場合は同じトークンを使う `alert.tsx` などの表示も確かめる |
| transition の指定 | `transition-all` を、色・影・枠など変わるプロパティだけを動かす指定（`transition-colors` など）にし、高さ・幅を transition の対象から外す | 検出したストーリーで、どの部品が `layout-transition` に当たったかを確かめてから対象を決める |
| 確認 | 設定画面のストーリーと画面を `detect_screen_issues` にかけ、`color-contrast` と `layout-transition` が当たらないことを確かめる | - |
