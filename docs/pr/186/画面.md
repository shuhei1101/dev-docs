## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `destructive` のコントラスト | `index.css` に `--destructive-foreground`（ライトは `--palette-white`、ダークは `--palette-gray-950`。`--primary-foreground` と同じ組み方）と Tailwind への割り当てを足し、`badge.tsx`・`button.tsx` の `destructive` を `bg-destructive text-destructive-foreground` の塗りにする。ホバーは背景色だけを変える | モックの `.btn--destructive`（`--destructive` の塗りと `--destructive-foreground` の文字）に揃える。`--destructive` の値は変えず、`alert.tsx` などの表示は変えない |
| transition の指定 | `badge.tsx`・`button.tsx`・`switch.tsx`・`tabs.tsx` の `transition-all` を、Tailwind の `transition`（色・透明度・影・transform だけを動かす）にする | 高さ・幅を transition の対象から外す |
| 確認 | 設定画面のストーリーと画面を `detect_screen_issues` にかけ、`color-contrast` と `layout-transition` が当たらないことを確かめる | - |
