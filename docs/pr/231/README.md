# 文書の画面をスクロールしても、mdmark の右側の目次をトップバーと種類のタブの下に配置する

## 概要

利用者が文書の画面をスクロールしても、mdmark の右側の目次がトップバーと種類のタブに隠れずに読める。

## 背景

[Issue #226](https://github.com/shuhei1101/dev-docs/issues/226) の要望。
文書の画面を下へスクロールすると、mdmark の右側の目次（縦の帯とパネル）が画面の上から 14px の位置に固定され、上から約 86px までのトップバー（`sticky`・48px）と種類のタブの帯に隠れる。
mdmark は目次の固定の位置を CSS 変数 `--mdmark-sticky-top` で受けるが、dev-docs の画面はこの変数を設定していない。
利用者は、この重なりがスクリーンショットでの確認で見つからなかったことも問題にしている。
