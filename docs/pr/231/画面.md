## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 目次の固定の位置 | 文書の画面で mdmark の CSS 変数 `--mdmark-sticky-top` を、トップバーと種類のタブの帯の高さ（サイドバーの固定の位置 `top-24` と同じ値）にする | mdmark v0.13.0 の右側の目次は `inset-block-start: calc(var(--mdmark-sticky-top, 0px) + var(--mdmark-space))` で固定し、縦の帯の高さも同じ変数を引く |
