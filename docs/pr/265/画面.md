### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 保存の組み立て | `toSourceInput` が取得した行の `storage` をそのまま送信し、`fromValues` がダイアログの値の `storage` を編集した行にだけ適用する | 他の行の `storage` は取得した値のまま |
| ダイアログ | `storage.type` を選ぶ項目を追加し、編集で開くと保存済みの値を選んだ状態にする。`storage` を持たない行は `disk` / `git` / 省略、`storage` を持つ行は `disk` / `git` から選ぶ | セレクトで「自動」・「Git」・「ディスク」。「範囲の外からの参照」と「書き込みの範囲」の間 |
| 文書の画面 | 変更しない。`disk` の配信元で `GET /refs` の `git` が `false` になり、リビジョンの切り替えを出さずに文書を表示することを結合テストで確認する | - |
