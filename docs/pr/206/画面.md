## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| コメント | 対応表の `ng` の単語を `ok` の単語へ置き換える。文の意味と対象の識別子は変えない | 置き換えると不自然になる文は、同じ意味で文を組み直す。コメントの中でバッククォートで囲んだ画面の文言（`配信元を追加` など）は画面の文言のまま残す。`消す` の `pattern` が当たる「取り消し線」は、画面設計（`docs/screen/SCR-155-1.yaml`）と部品の設計（`docs/module/MOD-155-14.tsx.yaml`）と同じ呼び名のまま残す |
| 洗い出しの漏れの確認 | 実装後、上の表のファイルのコメントに対応表の `pattern` を適用し、`allow` と画面の文言の引用を除いてヒットが 0 件であることを確認する | - |
| 既存機能への影響 | テストの処理・識別子・照合する文字列を変えない | ESLint・tsc と、画面の単体テストの全件実行・コメントを修正した結合テスト（`tests/integration/frontend/`）の実行で回帰を確認する |
