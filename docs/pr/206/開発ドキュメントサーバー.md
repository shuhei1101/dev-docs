## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| コメント・docstring | 対応表の `ng` の単語を `ok` の単語へ置き換える。文の意味と対象の識別子は変えない | 置き換えると不自然になる文は、同じ意味で文を組み直す |
| 洗い出しの漏れの確認 | 実装後、上の表のファイルのコメント・docstring に対応表の `pattern` を適用し、`allow` を除いてヒットが 0 件であることを確認する | - |
| 既存機能への影響 | テストの処理・識別子・照合する文字列を変えない | lint・型検査と、単体テストの全件実行・コメントを修正した結合テスト（`tests/integration/server/`）の実行で回帰を確認する |
