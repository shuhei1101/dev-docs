# 要件

## 要望

`tests/` と `plugins/dev-docs/` のコメントと docstring を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)に合わせて修正する。
`tests/` は Python のテストに加え、画面を検証する TypeScript のテスト（`tests/unit/frontend/`・`tests/integration/frontend/`）のコメントも対象にする。

置き換え先は [PR #133](https://github.com/shuhei1101/dev-docs/pull/133)・[PR #143](https://github.com/shuhei1101/dev-docs/pull/143)・[PR #148](https://github.com/shuhei1101/dev-docs/pull/148)・[PR #175](https://github.com/shuhei1101/dev-docs/pull/175)・[PR #188](https://github.com/shuhei1101/dev-docs/pull/188) の置き換え（`参照する`・`使用する`・`返却する`・`指定する` など）と統一する。

終わりの条件は、`tests/` と `plugins/dev-docs/` のコメント・docstring に対応表の `pattern` を適用したヒット（`allow` に該当するものと、コメントの中で引用した画面の文言を除く）が 0 件で、lint・型検査・単体テストと、コメントを修正した結合テストが全て pass すること。

Issue の本文のヒットの数（`tests/` 48 ファイル・305 箇所）は [d850016](https://github.com/shuhei1101/dev-docs/commit/d850016) の Python だけを数えたもので、[31e27e3](https://github.com/shuhei1101/dev-docs/commit/31e27e3) では Python が 50 ファイル・378 箇所、TypeScript が 12 ファイル・70 箇所になる（計画書の `## 現状`）。
