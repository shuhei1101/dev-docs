## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 移す行の保存 | `GET /settings/sources` で今の行と内容のバージョンを取得し、移す行を加えて `PUT /settings/sources`（`expectedVersion` つき）で 1 回で保存する。1 行ずつの `POST` は使用しない | - |
| 保存の応答が制限時間を超えたとき | `GET /settings/sources` で取得し直し、移す行が全て同じ内容であれば保存したとして続ける。無ければ終了コード 7 で止め、やり直す案内を出す | - |
| project-index が保存を受け付けないとき | 400・409・422 などは終了コード 4 で止める。保存は 1 回なので project-index には何も書き込まれない | - |
| 文書の取得の制限時間 | `PROJECT_INDEX_TIMEOUT_SEC`（45 秒）と、それから決まる画面のサーバーの停止の待ちは変えない | - |
| `切り戻し.sh` | 控えの YAML を develop の `.venv` にある `ruamel.yaml` で参照する。`実行.sh` が移し替えの前に dev-docs の端末の設定を `settings.yaml.bak-pr183` へ退避し、`切り戻し.sh` はその控えだけを書き戻す。控えが無ければ書き戻さず `failed` を出す。project-index への書き戻しの `PUT` が打ち切られても、取得し直して控えの行と同じなら `changed` にする | 作業名の付いた控えなので、別 PR の控えを取得しない |
