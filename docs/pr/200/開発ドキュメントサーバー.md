## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き込みの応答が遅いとき | 要件の 1 つ目の論点で決めた方法で、`POST /settings/sources` の応答が 45 秒を超えても移し替えを続ける | `未確定`（決める段: インターフェース定義設計。案は [要件](./要件.md)） |
| 途中で失敗したとき | `sources` を移す手順が終了コード 0 以外で止まったら、その実行で追加した行を project-index から取り除き、実行の前の行の集まりへ戻す。戻せなかったときは、戻せなかった行の id を stderr に出す | `未確定`（決める段: インターフェース定義設計。案は [要件](./要件.md)） |
| 文書の取得の制限時間 | `PROJECT_INDEX_TIMEOUT_SEC`（45 秒）と、それから決まる画面のサーバーの停止の待ちは変えない | - |
| `切り戻し.sh` | 控えの YAML を develop の `.venv` にある `ruamel.yaml` で参照する。`実行.sh` が `dev-docs migrate` の出力から控えのパスを記録し、`切り戻し.sh` はそのパスの控えだけを書き戻す。記録が無ければ書き戻さず `failed` を出す | 実行の前に記録したパスなので、別 PR の控えを取得しない |
