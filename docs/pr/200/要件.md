# 要件

## 要望

`dev-docs migrate --project-index` の `sources` を移す手順で、次を満たす。

| 要件 | 終わりの条件 |
| --- | --- |
| 書き込みの応答が 45 秒を超えても止まらない | project-index の端末の設定の保存の応答に 45 秒を超えてかかっても、保存が済んでいれば移し替えが終了コード 0 で終わり、dev-docs の端末の設定から移した行が除かれる |
| 途中で失敗しても食い違いを残さない | project-index が保存を受け付けずに移し替えが終了コード 4 で止まったとき、project-index の端末の設定の `sources` が実行の前と同じ行の集まりになっている。保存を確認できずに終了コード 7 で止まったとき、やり直せば揃う案内が標準エラーに出る（dev-docs の端末の設定はどちらも書き換えない） |
| `切り戻し.sh` が動く | [#183](https://github.com/shuhei1101/dev-docs/pull/183) の反映作業「端末の設定の移し替え」の `切り戻し.sh` が、`yaml` を参照できる Python で控えを参照し、その作業の実行で `dev-docs migrate` が作った控えだけを dev-docs の端末の設定へ書き戻す |

移す行は、project-index の端末の設定の今の行に加え、取得したときの内容のバージョンを添えて `PUT /settings/sources` で 1 回で保存する。
保存の応答が制限時間を超えたら、端末の設定を取得し直し、移す行が全て同じ内容であれば保存したとして続ける。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `src/dev_docs/integrations/project_index/client.py` の `PROJECT_INDEX_TIMEOUT_SEC` | [2731c0c](https://github.com/shuhei1101/dev-docs/commit/2731c0ca9f85e56ae05edcfe0b14ee4d75815018)（`文書とソースコードの索引・検索・書き込みの MCP を project-index へ切り出し… (#163)`） | 45 秒にした。根拠は非機能要件『project-index への問い合わせの制限時間』で、文書の取得で project-index が `converters[]` のスクリプトを動かす間（下流の制限時間 30 秒）を待つため 50% を乗せた値。端末の設定の書き込みの後の読み直しは根拠に入っていない | 1 回 | 書き込みの待ちを読み取りと分けるか、書き込みを確認する手順を追加する修正は、文書の取得を待つ目的を壊さない。同じ commit で、画面のサーバーの停止の待ち（`SHUTDOWN_WAIT_FACTOR` 倍）もこの値から決まる |
