# 要件

## 要望

公開ページのビルドが受け付ける分類を、モジュール構成 `MOD-192-1.py.yaml` の定数 `CATEGORIES`・`FLOWCHART_CATEGORY` のとおり `はじめに`・`使用方法`・`リファレンス` にする。
完了の条件は、develop と同じ `docs/guide/files.yml` で `uv run --frozen python scripts/build_pages.py --out _site` が終了コード 0 で終わること。

| 対象 | 修正 |
| --- | --- |
| `scripts/build_pages.py` | `CATEGORIES`・`FLOWCHART_CATEGORY` の `使い方` と、docstring・コメントの `使い方` を `使用方法` にする |
| `tests/unit/scripts/test_build_pages.py` | テストデータと期待値の分類 `使い方` を、`MOD-192-1.py.yaml` のテストの行のとおり `使用方法` にする |
| `project-index.yaml` | `nav` のタブの `title: 使い方` を、`docs/guide/README.md` の分類と同じ `使用方法` にする |
