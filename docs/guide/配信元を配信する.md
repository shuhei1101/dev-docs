# 配信元を配信する

project-index.yaml を記載して project-index に配信元を登録し、dev-docs の画面で読む手順

配信元の読み込み・検査と、ソースコード・プロンプトの配信は project-index が持ちます。
配信元の設定のキー・ソースコードとプロンプトの配信・設定を変えたときの確かめ方は、project-index の [設定](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E8%A8%AD%E5%AE%9A.md) と [管理のMCP](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E7%AE%A1%E7%90%86%E3%81%AEMCP.md) にあります。

## 手順

<!-- steps -->

1. 配信元のフォルダに `project-index.yaml` を置く。
   配信する文書の行を `documents[]` に記載する。
   Git 管理外にしたい設定は `project-index.local.yaml` に分ける。
   ```yaml
   version: "3"
   name: knowledge
   description: どのプロジェクトでも使うコーディング規約
   documents:
     - id: rules
       paths: [docs/rule/*.yaml]
       title: 規約
       schema: schemas/rule.schema.yaml
   ```
2. 配信元を project-index の端末の設定に追加する。
   dev-docs の設定画面の「配信元を追加」か、project-index のスキル・端末の設定で追加する（[画面で読む](./画面で読む.md)）。
3. dev-docs の管理の MCP の `status` で、配信元が `serving` であることを確かめる。
4. ブラウザで `http://127.0.0.1:8781/` を開き、配信元の文書を読む。

<!-- /steps -->

## 今の dev-docs.yaml から移る

配信元の設定の既定のファイル名は `project-index.yaml`・`project-index.local.yaml` です。
今の各リポジトリの `dev-docs.yaml` の移し替え（改名と、名前で探す処理の移行の間の扱い）は、project-index の [project-indexを更新する](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/project-index%E3%82%92%E6%9B%B4%E6%96%B0%E3%81%99%E3%82%8B.md) にあります。
端末の設定の `sources[].config` でほかの名前も指定できます。

## 画面

dev-docs を起動したら、ブラウザで `http://127.0.0.1:{port}/` を開きます（既定は `http://127.0.0.1:8781/`）。
`/` は配信中の配信元の先頭のトップへ移り、配信中の配信元が無ければ設定画面へ移ります。
使い方は [画面で読む](./画面で読む.md) にあります。
このサーバーは、画面が使う API（`/_api/` の入口）を配り、配信元の文書・検索・リビジョンは要求ごとに project-index から取得します。
project-index が読み直した配信元は、dev-docs を再起動せずに次の要求から画面に出ます。

## 文書の MCP で読み書きする

文書の MCP は project-index が持ちます。
引数・既定値・上限・エラーは [文書のMCP](./文書のMCP.md) から案内する project-index のリファレンスにあります。
