# 配信元と権限

配信元と、dev-docs の画面の入口・読むリビジョン。権限と設定のマージは project-index

## dev-docs と project-index の分担

| 持つもの | dev-docs | project-index |
| --- | --- | --- |
| 文書の画面・設定画面・画面の API | ✓ | |
| スキーマ駆動の Markdown への変換・タブとサイドバー・差分 | ✓ | |
| 管理の MCP の `status`・`restart`・`update` | ✓ | |
| 配信元の読み込み・検査・`converters[]` の変換 | | ✓ |
| 文書の MCP（検索・書き込み） | | ✓ |
| 端末の設定の `sources[]`・配信元の設定 `project-index.yaml` | | ✓ |

dev-docs は project-index の読み取り API を呼び、project-index は dev-docs に依存しません。
文書の MCP だけを使う端末は project-index だけを入れます。

## 配信元

配信元は、`project-index.yaml` を置いたフォルダ 1 つで、文書を配る単位です。
Git のリポジトリの直下のほか、リポジトリの中の任意のフォルダや、Git 管理外のフォルダも配信元にできます。

配信元の読み込み・検査と、端末の設定の `sources[]` の配信元の一覧は project-index が持ちます。
dev-docs の画面は、project-index が配信している配信元を、project-index の読み取り API で要求ごとに取得して表示します。
dev-docs は配信元のフォルダを読みません。

| 入口 | 持つもの | 内容 |
| --- | --- | --- |
| 文書の MCP | project-index | 配信元は引数 `source` で指す |
| 画面の API | dev-docs | `/_api/sources/{配信元の id}/docs`（文書の取得）・`/_api/settings/sources`（端末の設定の取得）など。JSON のキーは camelCase（`defaultRef`・`updatedAt` など）で、エラーは `application/problem+json`。画面（文書の画面・設定画面・見つからない画面）はこの API を呼び、同じポートの `/` で開く |

project-index につながらないとき、画面の API は 503 と、つながらなかった project-index のアドレスと理由を返します。

## 作業場所と権限

作業場所（`cwd`）による作業中の配信元・`scope` による権限・作業範囲の外の参考の読み取り・ワークツリーへの読み替え・書き込みの先は、文書の MCP の仕組みで、project-index が持ちます。
仕組みは project-index の [コアコンセプト-配信元と権限](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E3%82%B3%E3%82%A2%E3%82%B3%E3%83%B3%E3%82%BB%E3%83%97%E3%83%88-%E9%85%8D%E4%BF%A1%E5%85%83%E3%81%A8%E6%A8%A9%E9%99%90.md) にあります。

dev-docs の画面は `127.0.0.1` だけで待ち受け、作業場所で絞らずに全ての配信元を表示します。

## 読むリビジョン

画面が読むリビジョンは次のとおりです。

| 読み方 | リビジョン |
| --- | --- |
| `ref` を省く | 配信元の `default_ref`（既定 `develop`） |
| `ref` を指す（画面の API の `ref` クエリ） | 指したブランチ・コミット・タグ |
| Git 管理外の配信元 | フォルダをそのまま読む。`ref` は使えない |

## 設定のマージ

1 つの配信元の設定は、複数の YAML に分けられます。
マージの仕方は project-index の [コアコンセプト-配信元と権限](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E3%82%B3%E3%82%A2%E3%82%B3%E3%83%B3%E3%82%BB%E3%83%97%E3%83%88-%E9%85%8D%E4%BF%A1%E5%85%83%E3%81%A8%E6%A8%A9%E9%99%90.md) にあります。
