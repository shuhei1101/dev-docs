# 文書のMCP

文書の MCP のリファレンスの案内

文書の MCP（`describe`・`search_docs`・`trace_related`・`list_changes`・`list_match_words`・`write_docs`・`delete_docs`）は project-index が持ちます。
ツールの引数・既定値・上限・エラーは、project-index のリファレンス [文書のMCP](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E6%96%87%E6%9B%B8%E3%81%AEMCP.md) にあります。

dev-docs が持つ MCP は、[管理のMCP](./管理のMCP.md) の `status`・`restart`・`update` だけです。
