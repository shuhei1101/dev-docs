# 文書のメタデータ

dev-docs の画面が使う共通のメタデータ。メタデータの解決は project-index

文書の索引と、メタデータの解決（列名の対応・ID と名前の既定・管理用の YAML・ずれの検出）は project-index が持ちます。
仕組みは project-index の [コアコンセプト-文書のメタデータ](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/%E3%82%B3%E3%82%A2%E3%82%B3%E3%83%B3%E3%82%BB%E3%83%97%E3%83%88-%E6%96%87%E6%9B%B8%E3%81%AE%E3%83%A1%E3%82%BF%E3%83%87%E3%83%BC%E3%82%BF.md) にあります。

dev-docs の画面は、project-index が解いた共通のメタデータを次のように使います。

| キー | 画面での使い方 |
| --- | --- |
| `name` | サイドバー・パンくず・タブのタイトルと、検索の結果の名前 |
| `tags` など共通のキー | `nav` の `auto` の `filter` で、サイドバーに並べる文書を絞る |
| エイリアスのキー（`alias_type`・`aliases`・`avoid` など） | 本文の語に当てる用語と文書の別名のツールチップ |
