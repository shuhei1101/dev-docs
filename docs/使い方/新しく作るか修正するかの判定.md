# 新しく作るか修正するかの判定

文書を記載する前に、同じ話題の文書を検索で引き、新しく作るか既存の文書を修正するかを決める判定フローチャート

## 判定フローチャート

```mermaid
flowchart TD
  START([文書を記載したい])
  Q1{Q1 話題のタグ※1で引いて、同じ話題の文書が見つかるか?}
  Q2{Q2 話題の語をエイリアス※2で引いて、同じ話題の文書が見つかるか?}
  Q3{Q3 話題の語で全文※3を引いて、同じ話題の文書が見つかるか?}
  Q4{Q4 見つかった文書のどれかは、主題※4が書きたい内容と同じか?}
  Q5{Q5 見つかった文書のどれかの一部が、書きたい内容と重なるか?}
  Q6{Q6 重なる部分は、その文書のセクションとして収まるか?}

  R1([既存の文書を修正する])
  R2([既存の文書にセクションを追加する])
  R3([新しい文書を作り、関連（related）で既存の文書を指す])
  R4([新しい文書を作る])

  START --> Q1
  Q1 -->|YES| Q4
  Q1 -->|NO| Q2
  Q2 -->|YES| Q4
  Q2 -->|NO| Q3
  Q3 -->|NO| R4
  Q3 -->|YES| Q4
  Q4 -->|NO| Q5
  Q4 -->|YES| R1
  Q5 -->|NO| R4
  Q5 -->|YES| Q6
  Q6 -->|YES| R2
  Q6 -->|NO| R3
```

- **※1 タグ**: 文書の `tags`。`search_docs` の `filter` で `tags` を指して引く。配信元のタグは `group_by: tags` で一覧できる
- **※2 エイリアス**: 文書の別名。`search_docs` の用語の検索で、`alias_type` を持つ文書の `name` と `aliases` の値を照合して引く（[#11](https://github.com/shuhei1101/dev-docs/issues/11) の仕様）
- **※3 全文**: 文書の本文。`search_docs` の `filter` で `body` を指して引く
- **※4 主題**: 文書が説明する対象 1 つ

新しい文書を作るときは、続けて [documentsの行の判定](./documentsの行の判定.md) で入れる行を決めます。
